# 전략 미니맵 UI 계획

현재 지도 화면의 **우측 하단**, 기존 보고 팔레트 및 우측 상단 성 요약과 겹치지 않는 위치에 접이식 미니맵을 둔다. 기본 크기는 화면 폭의 약 16%, 높이는 18% 이내로 제한하고, 작은 창에서는 자동 축소하거나 접는다. 모달·대화 카드가 열리면 미니맵은 입력을 받지 않는다. 이 문서는 계획이며 아직 구현하지 않았다.

| 상태 | 단계 | 표시·동작 | QA |
| --- | --- | --- | --- |
| ⬜ | 1. 지도 윤곽 | 육지·바다·이동 불가 지형의 단순 색면과 전체 지도 경계 | 맵 크기·좌측 바다 확장 대응 |
| ⬜ | 2. 거점 | 성·항구의 점과 세력색, 미확인 지역은 전장의 안개로 마스킹 | 시야 밖 소유권·성 정보 누설 없음 |
| ⬜ | 3. 카메라 연동 | 현재 카메라 시야를 얇은 사각형으로 표시; 미니맵 클릭·드래그로 카메라 이동 | 줌·해상도 변경·가장자리 클램프 |
| ⬜ | 4. 접기·갱신 | 접기 버튼, 점령/안개/연도 변화 시 갱신; 전체 지형은 캐시 | 진행 중 프레임 지연 없음 |

병력, 보급 범위, 시설, 유적, 야전 건축물은 표시하지 않는다. 미니맵 클릭은 카메라 이동 전용이며 부대 목적지 지정이나 지도 명령으로 처리하지 않는다. `진행` 중에는 카메라 시야 표시만 실시간 갱신하고 소유권/안개는 확정 상태에 맞춰 갱신한다. 실제 화면 크기·우측 하단 버튼과의 간섭은 `run-maptest.bat`에서 시각 QA한다.
