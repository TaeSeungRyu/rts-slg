# 전략 미니맵 UI 계획

좌측 상단 군주 정보 옆의 지도 아이콘 버튼으로 우측 하단 전략 지도를 연다. 지도 아이콘은 코드 친화적인 SVG 에셋이다. 지도에는 지형·해역·시야·위치가 알려진 성·항구·카메라 영역만 표시한다. 모달이 열린 동안 지도 버튼은 새 입력을 받지 않으며 지도 클릭은 카메라 이동 전용이다. 실제 게임 화면의 배치·색감은 사용자 실기기 QA가 남아 있다.

| 상태 | 단계 | 표시·동작 | QA |
| --- | --- | --- | --- |
| ✅ | 1. 지도 윤곽 | 육지·바다·이동 불가 지형의 단순 색면 | 맵 경계에서 좌표 계산 |
| ✅ | 2. 거점 | 성·항구의 점과 세력색, 미확인 지형 암전 | 확인 가능한 거점만 표시 |
| ✅ | 3. 카메라 연동 | 카메라 지면 투영 사각형 표시; 클릭·드래그로 카메라 이동 | 모달·진행 중 카메라 명령 차단 |
| ✅ | 4. 접기·갱신 | 상단 지도 버튼·닫기 버튼, 0.12초 간격 갱신 | 정적 지형 데이터 재사용 |
| ⬜ | 5. 실기기 QA | 작은 해상도·줌·시야·점령 후 표현 | `run-maptest.bat`로 사용자 확인 |

병력, 보급 범위, 시설, 유적, 야전 건축물은 표시하지 않는다. 미니맵 클릭은 카메라 이동 전용이며 부대 목적지 지정이나 지도 명령으로 처리하지 않는다. `진행` 중에는 카메라 시야 표시만 실시간 갱신하고 소유권/안개는 확정 상태에 맞춰 갱신한다. 실제 화면 크기·우측 하단 버튼과의 간섭은 `run-maptest.bat`에서 시각 QA한다.
