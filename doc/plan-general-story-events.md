# Phase 20A — 장수 대화와 전장 사건

상태: 계획. Phase 21의 AI 조정 전에 장수의 존재감과 사건의 맥락을 강화한다.

## 목표와 화면 흐름

현재 장수 초상과 대사는 명령 확인창과 일부 결과 화면에서 보인다. 교전·담당 업무·성장·도시 변화가 장수 간 대화로 이어지는 장면은 드물다. 실제로 일어난 일을 참여 장수의 얼굴과 말로 보여준다.

1. 진행 중 주요 행동이 일어나면 해당 장수의 초상과 짧은 한마디가 부대 또는 도시 부근에 나타난다. 이동·공격 연출과 지도 입력을 막지 않는다.
2. 7일 진행 재생이 끝나면 가장 중요한 사건 최대 1개를 화면 하단 대화 모달로 보여준다. 실제 참여 장수 1~2명의 초상·이름·역할과 2~4줄의 대사를 표시한다. 사건이 없으면 모달을 띄우지 않는다.
3. 보고에는 사건 요약과 결과를 남기고 전체 보고에서 지난 장면을 다시 읽을 수 있게 한다. 카드를 닫아도 이미 확정된 결과는 바뀌지 않는다.
4. 장수 사진이 없으면 기존 공용 아이콘을 사용한다. 나중에 사진을 추가하면 같은 장수 ID로 자동 교체한다.

## 사건 우선순위

| 우선 | 계기 | 화자 | 첫 단계의 효과 |
|---:|---|---|---|
| 1 | 성·항구 함락, 세력 멸망 | 점령 부대 선봉·부관 | 결과 설명 |
| 2 | 신수 출현·처치, 유적 최초 점령 | 탐색·처치·점령에 실제 참여한 장수 | 기존 보상 표시 |
| 3 | 부대 전멸·큰 피해·보급 위기 | 실제 참여 장수 | 결과 설명 |
| 4 | 장수 레벨·병종 적성·패시브 승급 | 성장한 장수와 같은 부대의 동료 | 기존 성장 결과 표시 |
| 5 | 담당 업무·생산·연구 완료 | 해당 수행 장수 | 기존 수치 요약 |
| 6 | 동맹·선전포고·도시 계략 결과 | 실제 수행 장수와 참여 군사 | 기존 명령 결과 표시 |

첫 구현은 1~4순위를 우선한다. 첫 콘텐츠 묶음은 아래 대화형 이벤트 10종, 유형별 대사 변형 3개 이상을 목표로 한다. 기존 주요 장수 약 8명에게 전용 말투를 시범 적용하고 나머지는 범용 대사를 사용한다. 역사 인물의 실제 발언처럼 인용하지 않는다.

## 대화형 이벤트 10종 제안

모두 사건이 확정된 **7일 진행 종료 후** 발생한다. 표의 수치는 최초 밸런스 제안이며 구현 단계에서 기존 회복·수리·성장 상한에 맞춰 검증한다. 선택지를 누르기 전에는 자원과 상태를 바꾸지 않는다.

| ID | 이벤트·실제 발생 조건 | 대화 상대 | 선택지와 결과 |
|---|---|---|---|
| 01 | **승전 논공**: 선봉·부관이 함께 교전해 적 부대를 괴멸시킴 | 선봉 ↔ 부관 | 선봉을 치하 / 부관을 치하 → 선택한 장수에게 전투 경험치 +20 |
| 02 | **패전 뒤 부상자**: 교전 후 부대가 생존하고 부상병이 남음 | 선봉 ↔ 부관, 부관 없으면 선봉 단독 | 간호 / 군량 보존 → 간호 시 부대 휴대 군량 50을 소비하고 부상병 최대 25명을 기존 회복 규칙으로 복귀. 군량 부족 시 선택 불가 |
| 03 | **수성 뒤 성벽 점검**: 성이 공격을 버텼고 성벽이 손상됨 | 수성 지휘관 ↔ 같은 성의 장수 | 즉시 보수 / 상황 관찰 → 보수 시 해당 도시 금 50을 소비하고 성벽 내구도 최대 100 회복. 현재 최대 내구도 초과 금지 |
| 04 | **새 성의 첫날**: 성·항구 점령이 확정됨 | 점령 부대 선봉 ↔ 부관 | 주민 지원 / 재정 보존 → 지원 시 점령 도시 금 100을 소비하고 치안 +2. 기존 함락 치안 페널티가 계산된 뒤 적용 |
| 05 | **보급 부족 회의**: 출전 부대의 남은 군량이 3일 이하 | 선봉 ↔ 부관 | 보급 준비 / 행군 유지 → 보급 준비는 해당 부대를 선택한 상태의 보급 관련 화면으로 연결. 군량을 즉시 만들어내거나 기존 이동 명령을 자동 변경하지 않음 |
| 06 | **치안과 병력의 갈등**: 같은 도시에서 병력 생산이 진행되고 7일 결산 치안이 하락 | 치안 담당 ↔ 병력 담당, 한쪽 없으면 기존 담당 단독 | 민심 지원 / 현상 유지 → 지원 시 해당 도시 금 50을 소비하고 치안 +1. 담당 업무·병력 생산량은 변경하지 않음 |
| 07 | **연구 완수 토론**: 전투교리·일반연구·계략연구가 완료됨 | 연구 수행 장수 ↔ 같은 도시 군사/태수 | 후속 연구 보기 / 보고 마치기 → 첫 선택은 연구 화면으로 연결. 완료한 연구의 비용·기간을 다시 결제하거나 명령을 자동 접수하지 않음 |
| 08 | **생산 귀환**: 500명 생산 부대가 시설 작업을 끝내고 복귀함 | 생산 주최 장수 ↔ 같은 도시 내정 담당 | 현장 경험을 기록 / 결과만 보고 → 기록 시 생산 주최 장수의 내정 경험치 +10. 기존 생산 보상과 별도로 1회만 지급 |
| 09 | **신수 흔적에 대한 의견**: 탐색으로 대호·용·봉황 단서가 확정됨 | 탐색 수행 장수 ↔ 같은 도시의 다른 장수 | 단서 위치 확인 / 나중에 보기 → 첫 선택은 단서 보관함과 알려진 위치로 연결. 출현 장소를 미리 공개하지 않음 |
| 10 | **신수 사냥 뒤의 대화**: 실제 피해 기여가 있는 부대가 신수를 처치함 | 처치 기여 부대 선봉 ↔ 부관 | 보상 내역 보기 / 보고 마치기 → 첫 선택은 이미 확정된 보상 내역으로 연결. 기존 보물 3종 중 1종 선택을 먼저 완료하고 추가 보물·경험치를 만들지 않음 |

01·03·04·06·08의 소액 보상은 해당 사건 인스턴스당 1회만 적용한다. 02의 회복은 실제 부상병 수를 넘지 않는다. 필요한 자원·화자·도시 소유 조건이 사라졌으면 관련 선택지를 비활성화하고 이유를 표시한다. 단순 화면 연결 선택지는 취소해도 원래 대화로 돌아올 수 있다. 01처럼 두 명이 필수인 이벤트는 한 명만 참여했다면 만들지 않는다.

### 콘텐츠 제작 방법

1. 각 이벤트를 별도 데이터 레코드로 관리한다. ID, 발생 조건 코드, 우선순위, 화자 역할, 대사 페이지, 선택지 2개, 효과 코드와 값, 반복 제한, 보고 요약을 포함한다. 장수 이름·도시명·병종명·실제 수치는 실행 시 안전하게 채운다.
2. 범용 대사 3개 이상을 사건별로 쓰고, 첫 검수 장수 약 8명은 동일한 사건에 말투만 다른 짧은 변형을 둔다. 동탁·여포·촉·오처럼 시나리오에 없는 관계를 임의로 단정하는 대사는 쓰지 않는다.
3. 효과는 기존 전투 경험치·내정 경험치·치안·도시 금·휴대 군량·부상병·성벽 내구도만 사용한다. 자원 차감과 보상 적용은 한 번의 확정 작업으로 처리하고, 중복 클릭·저장 재개에도 재적용되지 않도록 사건 인스턴스 ID를 보존한다.
4. UI는 위 하단 대화 모달 하나를 재사용한다. 대화 2~4페이지 → 두 선택지 → 결과 한 줄 → 보고 기록 흐름이다. 효과 없는 화면 연결 선택지는 실제 대상 화면만 연다. 닫기·Esc·우클릭으로 선택을 건너뛰면 수치 효과 없이 종료하고, 보고에서 다시 보는 장면은 읽기 전용으로 둔다.
5. 자동 QA는 각 10종의 참·거짓 발생 조건, 화자 부재, 자원 부족, 상한, 중복 선택, 7일 다중 사건 우선순위, 저장/불러오기, 안개 정보 누설을 검증한다. 실기기에서는 전투·도시·탐색 이벤트를 최소 1개씩 확인한다.

## 발생과 선택 규칙 제안

- 확정된 WorldEvent, 교전/공성/점령 결과, 명령 완료, 성장 결과에서만 생성한다. 날짜가 지났다는 이유로 가짜 전투나 보상을 만들지 않는다.
- 화자는 실제 기여자 우선, 선봉→부관, 장수 ID 순으로 선정한다. 두 화자는 사건에 함께 참여했거나 같은 도시에 있을 때만 등장한다.
- 7일 진행당 지도 위 한마디는 최대 2회, 종료 후 대화 카드는 최대 1회다. 다른 유효 사건은 보고에 기록한다. 성 함락·신수 처치가 일상 업무보다 우선한다.
- 같은 사건 유형·장수 조합·대사 변형은 최근 60일 동안 반복하지 않는다. 변형을 모두 사용했으면 보고에만 기록할 수 있다.
- 시드 기반 난수와 안정된 사건 순서를 사용한다. 저장/불러오기·재진행 뒤 같은 사건의 대사가 바뀌거나 중복 표시되지 않아야 한다.
- 대화 선택은 위 10종에 정의한 소액 효과 또는 관련 화면 이동만 수행한다. 기존 전투·탐색·영입 보상과 중복 지급하지 않으며 새로운 자원 종류나 관계도 수치는 만들지 않는다.
- 사건별 반복 제한은 기본 60일, 같은 도시·장수에서 발생하는 일상형 05~08은 28일을 추가로 적용한다. 큰 사건 01~04·09~10은 실제 새로운 사건 인스턴스가 있을 때만 후보가 된다.

## 하단 대화 모달 레이아웃

- 화면 하단에 고정된 가로형 모달로 연다. 1280×720 기준 화면 폭의 약 88~92%, 높이의 약 25~30%를 시작값으로 삼고 상단 전장을 보이게 둔다. 화면 밖으로 넘어가지 않도록 안전 여백을 둔다.
- 모달 내부는 **왼쪽 장수 사진 약 30%, 오른쪽 대사·선택지 약 70%**로 나눈다. 사진은 정해진 영역 안에서 비율을 유지해 잘라 보여주며 원본 이미지 크기가 모달을 늘리지 못하게 한다. 오른쪽이 항상 더 넓다.
- 왼쪽에는 현재 말하는 장수의 세로 초상과 이름·역할을 배치한다. 두 번째 화자가 말하면 같은 사진 자리를 전환하며, 작은 화자 표식으로 등장 인물 둘을 구분한다. 사진이 없는 장수는 공용 아이콘을 사용한다.
- 오른쪽 위에 사건 제목과 화자 이름, 가운데에 2~4줄 대사, 아래에 다음/선택지 및 닫기 버튼을 둔다. 대화형 이벤트는 두 선택지를 표시한다. 긴 문장은 페이지를 나누고 모달 전체 세로 스크롤은 만들지 않는다.
- 하단 보고 패널과 겹치는 동안 보고 패널을 잠시 숨기고 모달을 닫으면 원래 표시 상태로 되돌린다. 다른 확인창·보상 선택창 위에 겹쳐 열지 않고 순서대로 보여준다.

```text
┌───────────────────── 화면 하단 대화 모달 ────────────────────────────┐
│  장수 세로 초상  │  사건 제목 · 화자 이름                          │
│     약 30%      │  대사 2~4줄                         약 70%     │
│ 이름 · 역할     │  [선택 1] [선택 2]       [다음/닫기]            │
└──────────────────────────────────────────────────────────────────────┘
```

## UI와 경계 조건

- 하단 모달 왼쪽에 현재 화자의 세로 초상, 오른쪽에 대사와 사건 결과를 둔다. 카드 전체의 세로 스크롤을 피한다.
- 다음 버튼으로 문답을 넘기고 닫기·Esc·우클릭으로 종료한다. 선택 보상 모달이 있다면 보상 선택이 끝난 뒤 대화를 표시한다.
- 한마디와 액티브 스킬 토스트가 겹치면 전투 수치·스킬 효과를 먼저 보여준다.
- 장수 사진 없음, 긴 이름·대사, 1280×720, 다른 화면 비율, 화자 1명/2명, 보고 패널 복귀, 복수 도시를 QA한다.
- 내 편이 관여하지 않은 적 내부 대화는 보여주지 않는다. 정찰 정보가 없으면 안개 속 적 정보를 대사로 누설하지 않는다.

| ⬜ | 5 | 선택지 효과·화면 연결·결과 보고, 업무/외교 후속 장면 | 자원 부족·상한·중복 적용·저장 재개·다수 도시 QA |

각 단계는 독립적으로 검증하고 커밋·푸시한다. 첫 실기기 확인은 run-maptest.bat에서 장수 두 명을 출전시켜 교전 → 진행 종료 카드 → 보고 다시 보기 순서로 진행한다. 이어서 신수/유적과 레벨업 장면을 확인한다. Phase 21의 AI도 같은 사건을 생성하되 플레이어가 알 수 없는 적 내부 사건은 화면에 띄우지 않는다.
