# Phase 21 후속 — AI 유적 공략

상태: 계획. 야생 신수 사냥은 제외한다. 이 문서는 [전쟁 우선순위](plan-phase21-ai-combat-priority.md)와 [전쟁 판단 상세](plan-phase21-ai-war-simplification.md)의 공세 실패 후 행동을 보완한다.

## 우선순위와 공존

1. 방어·지원 임무에 병력과 장수를 먼저 배정한다. 진행 중이거나 예약된 거점 공세가 있으면 신규 유적 공략을 시작하지 않는다.
2. 세력의 30~60일 전략 판단일에는 신규 거점 공세를 먼저 평가하고, 공세가 성립하지 않을 때 유적 공략을 평가한다. 유적도 불가능하면 기존 건설 조건을 평가한다.
3. 이미 시작한 유적 공략은 나중에 방어·지원이 발동해도 자동 취소하지 않는다. 남은 전력으로 방어·지원한다. 세력당 동시 유적 공략은 한 곳으로 제한한다.
4. 임무의 목표 유효성·복귀는 매일 확인한다. 신규 후보 선정은 전략 판단일에만 한다. 출발 성 함락 또는 목표 무효화 시 기존 복귀 규칙으로 정리한다.

## 후보와 출전

1. 아군 성을 ID순으로 검사한다. 각 성에서 도달 가능한 미등록·보호 종료·수비 병력 잔존 유적을 **수비 병력 오름차순 → 실제 이동 거리 오름차순 → 유적 ID순**으로 검토한다. 하나가 실패하면 같은 성의 다음 유적, 그 뒤 다음 성으로 넘어간다.
2. 육상 성은 육상 유적만, 해상 유적은 선박·출항·해상 경로가 가능한 항구만 고려한다.
3. 방어용 최소 잔류 20%와 이미 출전·예약·건설에 투입된 전력을 제외한 **실제 편성 가능 병력**이 유적의 현재 수비 병력의 **2배 이상**이어야 한다. 장수·병종·출구·경로·편도 군량/보급도 확인한다.
4. 첫 합법 후보에 기존 부대 편성·출전·이동·전투 서비스를 사용한다. 유적 전용 피해 공식은 만들지 않는다. 목표 유적과 출발 성을 임무로 보존해 중복 출전을 막는다.
5. 이미 등록한 유적은 재공략하지 않는다. 보호 변경, 타 세력 선점, 수비대 소멸, 부대 괴멸 등을 정리한다. 모든 성에서 실패하면 공략을 건너뛴다.

## 단계별 구현·QA

| 단계 | 상태 | 작업 | 핵심 QA |
|---|---|---|---|
| R1 | ✅ | 우선순위와 후보 정책 | 공세·방어·지원 시 신규 공략 없음, 약한 유적→거리순, 성 순회, 등록·보호·경로 제외. 정책 단위 테스트 통과 |
| R2 | ✅ | 실제 병력 2배·잔류·장수·경로와 기존 출전 연결 | 1.99/2.00배, 예약 병력 제외, 실패 시 다음 유적·성, 중복 방지. 관련 Core 테스트 통과 |
| R3 | ✅ | 임무 추적·목표 소멸/함락/복귀·건설 자원 중복 방지 | 출전 후 방어·지원 공존, 점령 직후 당일 복귀 명령, 저장 왕복, 중복 편성 방지 관련 Core 테스트 통과 |
| R4 | ⬜ | `run-aitest` 세력별 최약 유적 배치·통합 QA | 병력 3모드, 공격·등록·복귀, 실제 화면 검수 |

자동 테스트와 게임 빌드는 별도로 수행한다. 실제 화면·모션은 `run-aitest`로 사용자 확인을 받는다.
