# 이벤트 사냥 — Phase 19 대호

상태: 2026-10-13 1차 구현·자동 QA 완료. 실제 대호 이동/공격 모습과 화면 구성은 사용자 플레이 검수 항목이다.

2026-10-13 1차 구현 기준. 일반 캠페인의 신수 흔적 발견 확률은 1%다. 고대유물 단서의 해석·장착 효과와 용·봉황 보상은 후속 작업이다.

## 출현과 행동

- 임시 테스트 설정: `run-maptest.bat`의 탐색 신수 흔적 확률은 `data/maptest-exploration.json`에 따라 50%다. 일반 캠페인은 1%를 유지한다. 추가 확률은 무성과에서만 가져오며 다른 보상·정치 보정과 발견 후 7일 대기는 유지한다. 테스트 종료 시 JSON 값을 1로 되돌린다.

- `divine_beast_trace` 발견 이력 하나당 대호 출현 예약 하나를 저장한다. 발견 7일 후부터 출현하며 지도 전체에 활동 중인 대호는 최대 1마리다. 후속 예약은 대기한다.
- 발견한 도시 주변 2~6칸의 숲·산지를 우선한다. 해당 범위에 적합한 숲·산지가 없으면 `fallback_spawn_terrains`의 평지를 사용한다(항구·평야 도시의 무기한 대기 수정). 도시·시설·유적·건축물·부대와 겹치지 않으며, 지형 우선순위→거리→q→r 순으로 고른다. 빈 육상 장소가 전혀 없으면 예약을 유지한다. 기존 저장의 미출현 예약에도 적용한다.
- 중립 적대 세력으로 플레이어와 AI 모두 공격할 수 있다. 이동 3칸/일, 탐지 2칸, 사거리 1칸. 전투 체력은 병력 환산 20,000, 공격 18·방어 12·적성 A다. 단일 대호 모델로 표시한다.
- 매일 이동 전에 탐지 범위의 육상 부대 중 현재 병력이 가장 적은 부대를 추격한다. 건물 주둔·출전 대기·해상 부대는 제외한다. 부대가 없으면 대기하며 성·시설·유적을 스스로 공격하지 않는다.
- 기존 이동턴→공격턴, 피해·부상·반격·괴멸 표현을 재사용한다. 대호는 장수·액티브·패시브·군량 소모가 없다.
- 수치는 `data/event-units.json`에 둔다. 이벤트 전용 목록으로 일반 생산·연구·출전 병종 목록에 섞지 않는다.

## 처치 보상

- 처치 공격턴의 실제 대호 교전 부대 중 피해를 가한 부대를 대상으로, 명령 순번→부대 ID 순으로 처치 기여 세력을 결정한다. 근처에 있다는 이유만으로 보상을 지급하지 않는다.
- 일반 교전 성장에 더해 처치 부대의 선봉·부관 각각 전투 경험치 250, 사용 병종 숙련 10을 지급한다. 집단군은 보병·궁병·공성에 적용한다. 기존 숙련 상한은 유지한다.
- 해당 세력 창고에 `호부` 1개를 등록한다. 호부는 사냥 증표이며 이번 단계에서 장착·능력치 보정은 부여하지 않는다.
- 동시 괴멸·재진행·저장 재개에도 처치 기록과 보물 지급은 한 번만 발생한다. 전투 기여가 확인되지 않은 소멸은 보상을 지급하지 않는다.
- 낙뢰·화계의 실제 대상/인접 범위에 포함된 대호는 시전 기여를 기록한다. 지속피해 처치는 저장된 최근 교전 기여자를 사용한다.
- 탐색 단서, 출현 예약, 활동 부대 ID, 처치일·보상 세력, 실제 보물 목록을 캠페인 저장에 보존한다. 기존 세이브에서 누락된 목록은 빈 목록이다.

## 화면과 QA

- 신수 흔적 결과에서 대호 사냥으로 이어지는 설명을 표시한다. 출현·처치는 보고에 표시하고 처치 후 보상 모달에서 사진·장수 경험치·숙련·호부를 안내한다.
- 대호 정보에서 위협도·공방·행동·보상을 확인한다. 기존 `troop-great-tiger.glb`와 `great_tiger.png`를 사용한다.
- 시스템의 단서·보물 보관함은 실제 호부 목록을 표시한다. 단서와 획득 보물은 별개다.
- 보관함의 대호 예약은 남은 일수·다른 대호 활동·빈 장소 대기를 구분하고, 활동 중인 대호의 좌표를 표시한다. 디버그 로그에는 예약 도시·예정일·실제 위치·배치 후보를 기록한다.
- `run-maptest.bat --event-hunt-sample`은 확정 출현 예약 샘플을 추가한다. 샘플 인자 자체는 탐색 확률을 변경하지 않으며, maptest 임시 확률 설정은 위 JSON을 따른다.
- Core: 데이터 검증, 구 저장 호환, 출현 중복·부적합 장소, 활동 상한, 약한 부대 추격·건물 무시, 실제 처치·동시 괴멸·무기여 보상 금지, 저장 재개를 검사한다.
- Game: 빌드·Godot 헤드리스 로딩 및 대호 모델·카드·보고·보상 모달·보관함 연결 자동 QA. 실제 모션·화면 품질은 사용자 `run-maptest.bat` 검수로 구분한다.

실기기 확인: `run-maptest.bat --event-hunt-sample` → 진행 → 장안 주변 대호 출현 → 출전 부대로 공격 → 처치 보상 모달 → 시스템의 단서·보물 보관함에서 호부 확인. 샘플 인자는 최초 1회 출현 예약만 추가하고 탐색 확률은 변경하지 않는다.

## 후속 계획: 신수 장착 아이템과 대호 성장 보상

아래는 **미구현 계획**이다. 위의 대호 처치 경험치 250·숙련 10·호부 자동 지급은 현재 동작을 설명하며, 후속 구현 때 아래 규칙으로 교체한다. 아이템은 각 신수마다 3종의 선택지를 준비하되 **처치 1회당 한 종류 1개만** 획득한다. 처치 기여 세력이 선택하고 세력 공용 창고에 넣는다. AI는 현재 편성 장수에게 유효한 효과를 우선하고 동률이면 아래 표의 순서로 고른다. 선택 전 저장·종료해도 보상 선택 상태를 저장하여 중복 지급하거나 잃지 않는다.

| 신수 | 아이템 선택지 | 장착 효과 | 적용 범위 |
|---|---|---|---|
| 대호 | 호부 | 장착 장수가 편성된 부대의 일반 공격 피해 +5% | 육상 전투부대만. 건물·유적에는 효과 없음 |
| 대호 | 호아 | 장착 장수가 편성된 근접 부대의 일반 공격 피해 +8% | 도검병·극병·기병·철기병·남만병·등갑병 등 근접 병종. 원거리·공성·해상 제외 |
| 대호 | 대호의 새끼 | 대호 1기를 소환하는 명령 해금 | [소환 공통 규칙](#소환-아이템-공통-규칙) 적용 |
| 용 | 용린 갑옷 | 장착 장수가 편성된 부대의 받는 병력 피해 −8% | 일반 교전·전투 액티브 피해. 상태 피해에는 효과 없음 |

| 용 | 용의 알 | 용 1기를 소환하는 명령 해금 | [소환 공통 규칙](#소환-아이템-공통-규칙) 적용 |
| 봉황 | 봉황 깃 | 장착 장수의 **모든 병종 적성 중 A 미만을 A로 보정** | A·A+·S·SS·SSS 등은 유지. 원본 등급·숙련 경험치 변경 없음 |
| 봉황 | 봉황옥 | 장착 장수가 편성된 부대의 전투 사망 병력 10%를 부상병으로 전환 | 실제 사망자 중에서만 전환. 기존 병력 총량 증가·괴멸 부대 부활 없음 |
| 봉황 | 봉황의 알 | 봉황 1기를 소환하는 명령 해금 | [소환 공통 규칙](#소환-아이템-공통-규칙) 적용 |

- 장수당 장착 슬롯은 1개다. 출전·생산 등 현장 임무 중에는 장착·해제·교체할 수 없고, 대기 중인 장수만 세력 창고에서 변경한다. 해제한 아이템은 소모되지 않고 창고로 돌아간다. 같은 아이템 인스턴스를 두 장수가 동시에 장착할 수 없다.
- 선봉·부관 모두 착용할 수 있다. 같은 부대에서 동일한 보정 대상에 두 아이템이 걸리면 높은 효과 하나만 적용하며, 다른 대상에 주는 효과는 각각 적용한다. 장수나 부대가 사라지는 경우의 아이템 회수 규칙과 세력 멸망 시 이전 규칙도 구현 전에 명시한다.
- 전투 피해 계산에서 아이템 보정은 기존 전투 공식이 산출한 피해에 적용한다. 동일한 피해를 중복 가산하지 않도록 피해 종류별 적용 지점을 하나로 고정하고 UI에 적용/미적용 사유를 보여준다.
- 기존에 획득한 호부는 장착 시스템 출시 후 같은 코드의 장착 아이템으로 전환한다. 저장된 획득일·보유 세력·처치 이력은 보존한다. 이미 완료한 대호 처치에 대해 두 번째 선택 보상은 소급 지급하지 않는다.

### 소환 아이템 공통 규칙

- 세 알/새끼 아이템은 장수의 **장착 슬롯 1개**를 사용한다. 소유 자체로 신수를 생성하지 않는다. 장착 장수가 육상 부대의 선봉 또는 부관으로 출전하면 부대 명령 팔레트의 `신수 소환`을 사용할 수 있다. 소환수에게는 장수·장비·보상·액티브/패시브 성장·재소환 능력이 없다.
- 소환 명령은 인접한 통행 가능 빈 육상 위치를 지정하고 장수 확인창에서 승인한다. 다음 이동턴 시작 시 위치·장착·대기 기간을 다시 검사하여 소환한다. 부대가 괴멸하거나 출전하지 않은 상태면 소환하지 않고 사용 횟수도 소모하지 않는다. 소환을 수행한 부대는 그날 능동 공격을 하지 않는다. 소환수는 다음 공격턴부터 교전할 수 있다.
- 소환수는 **7일간 활동**한 뒤 전장에서 사라진다. 전멸하면 즉시 사라진다. 소환한 날부터 **아이템 인스턴스별 60일 재사용 대기**가 시작되며 아이템을 해제·양도·저장/불러오기해도 남는다. 같은 세력은 신수 종류별로 동시에 **1기만** 유지할 수 있다. 다른 알 아이템을 얻어도 같은 종류의 활성 소환수를 추가 생성할 수 없다.
- 소환수는 아군 전투부대로 취급하되 성·항구·보루 주둔, 수송·보급·생산·건축·점령, 아이템 지급과 영입 포인트 획득은 하지 않는다. 소환수의 공격/방어/체력은 야생 신수와 분리된 `data` 정의를 사용한다. 초안 병력 환산 체력은 대호 5,000·용 8,000·봉황 6,000으로 하고 전투 QA로 조정한다. 이동 방식은 우선 육상 경로와 충돌 규칙을 사용한다. 용·봉황의 비행/수상 통과는 별도 확정 전까지 허용하지 않는다.
- 소환수를 명령 목록·지도·보고에 `소환된 대호/용/봉황`, 남은 활동일, 아이템 재사용 가능일로 구분해 표시한다. 사용자와 AI 모두 같은 소환 조건·기간·상한을 따른다. 저장 파일에는 아이템 인스턴스 ID, 장착자, 마지막 사용일, 소환수 소유/원본 아이템 ID, 남은 활동일을 보존한다.

### 대호 처치 성장 보상 재설계

- 대호 체력 20,000에 비해 현행 **전투 경험치 250·병종 숙련 10**은 보상 체감이 약하다. 전투 레벨의 다음 단계 필요 경험치는 현재 레벨에 따라 `100 + 레벨×25`, 병종 숙련 승급 필요 경험치는 500이다.
- 후속 보상은 **실제 누적 피해 기여율** `p = 해당 부대가 대호에 준 유효 피해 / 처치까지 모든 아군 부대가 대호에 준 유효 피해 합계`를 사용한다. 유효 피해는 남은 병력까지만 인정하여 초과 피해로 기여율을 올릴 수 없다. 지속 피해·액티브 피해는 원 시전자 부대에 귀속한다. 피해를 주지 않은 부대는 보상 대상이 아니다.
- 기여 부대의 선봉·부관 **각각** `전투 경험치 = 200 + round(400×p)`, `사용 병종 숙련 = 10 + round(40×p)`를 받는다. 반올림 방식은 `0.5 올림`으로 고정한다. 단독 처치는 경험치 600·숙련 50, 동등한 2부대 협공은 부대당 경험치 400·숙련 30이다. 기존 장수 레벨 50·병종 적성 승급 상한은 유지한다. 집단군은 현재와 같이 보병·궁병·공성 각각에 숙련을 지급한다.
- 피해 기여도는 날짜를 넘어 누적·저장한다. 마지막 타격 부대만 보상하는 방식은 사용하지 않으며, 처치 판정 1회에만 경험치·숙련·아이템을 지급한다. UI에는 각 기여 부대의 피해 비율과 지급 수치를 표시한다.
