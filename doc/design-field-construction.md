# 야전 건축 설계 — 출전 육상 부대

작성일: 2026-10-01. 상태: 계획 수립, 코드·에셋 미구현.
실행 단계는 [Phase 18C](./plan-v2-implementation-roadmap.md#phase-18c-야전-건축)에 기록한다.
기준: [지형](./design-terrain.md), [이동](./design-movement.md), [전투](./design-combat.md),
[부대 군량](./design-unit-state.md), [효과](./design-effect.md).

## 1. 사용자 확정 규칙

출전한 육상 부대의 명령 팔레트에 `건축`을 추가한다. 비용은 해당 부대의 휴대 자원으로 지불한다.
모든 건축 명령은 시작 시 병력 1,000명 이상이어야 한다.
건축 중에는 이동·공격·반격을 포함한 모든 행동을 멈춘다. 부대 위에 작업 연장도구 모양 표시를 띄운다.
명령 승인 후 취소는 불가능하며, 완공일은 진행의 일 단위 시계로 계산한다.

건물은 모두 1타일을 차지한다. 이미 건물이 있는 타일에는 추가 건축할 수 없다.
일반 건물 설치 지형은 `plains`(평야), `forest`(숲), `desert`(사막)만 허용한다.
아군은 건물 타일을 통행할 수 있고 적군은 통행할 수 없다. 정찰대는 아래의 별도 예외를 따른다.
적 건물은 적 성과 같은 공격 대상으로 인식하되 정찰대는 공격 대상으로 취급하지 않는다.
건물 수리는 불가능하다. 건물 클릭 → `철거` → 확인창 승인 시 즉시 제거한다.
모든 건축물의 에셋은 Blender로 제작하고 GLB 및 생성 Python을 저장소에 함께 보관한다.

| 건축물 | 휴대 금 | 추가 비용 | HP | 기간 | 효과 |
|---|---:|---|---:|---:|---|
| 목책 | 100 | 없음 | 500 | 7일 | 설치 위치 주변 1칸 전체 이동력 −1, 건물 DF 적용 |
| 정찰대 | 10 | 병력 10명·군량 5 | 전투 대상 아님 | 7일 | 가까운 숲 또는 산악 배치, 3×3 시야 60일, 적 통과 시 철수·소멸 |
| 감시탑 | 150 | 없음 | 500 | 7일 | 3×3 안 아군 시야 +1, 건물 DF 적용 |
| 보루 | 300 | 없음 | 1,000 | 14일 고정 | 3×3 안 아군 군량 소비 40% 감소, 아군 1부대 주둔·건물 HP 우선 보호 |
| 진법 | 300 | 없음 | 500 | 14일 | 2×2 안 적 도착 시 30% 확률로 해당 부대 병력 1%를 부상병으로 전환, 아군 1부대 주둔·건물 HP 우선 보호 |

보루는 장수 능력치와 무관하게 14일이다. 다른 건물도 현재 명세의 7/14일을 그대로 사용하며
별도 능력치 단축은 정의하지 않는다. 건물 DF의 구체 수치는 구현 전 확정한다.

## 2. 공통 규칙의 예외와 구현 전 확정 항목

아래 권장안은 아직 확정 규칙이 아니다. 1단계에서 확정하여 이후 단계의 입력으로 사용한다.

| 항목 | 충돌 또는 미정 사항 | 권장안 |
|---|---|---|
| 정찰대 지형 | 공통 3지형과 정찰대 산악 허용이 충돌 | 정찰대만 숲/산악 예외. 산악은 지형 카탈로그의 실제 코드 목록으로 지정하며 얼음벽 등은 자동 포함하지 않음 |
| 정찰대 통행 | 적 통행 금지와 적 통과 시 철수가 충돌 | 정찰대는 양측 통행 허용·공격 표적 제외. 적의 실제 도착 직후 제거 |
| 설치 거리 | '근처' 거리와 부대 이동 여부 미정 | 건축 부대 현재 위치 또는 인접 1칸. 산악은 부대가 진입하지 않고 인접 타일에서 작업 |
| 3×3 / 2×2 | 헥사 타일에는 정사각형 범위가 없음 | 3×3은 중심 포함 헥사 반경 1(7칸) 권장. 2×2는 방향을 선택하는 axial 4칸 마스크 권장. 실제 범위 미리보기 후 확정 |
| DF | '건물 df'의 값 미정 | 기존 건물 방어 계산 경로를 사용하고 5종 정의에 DF 필드 저장. 성 태수·수성 적성 보정을 자동 상속하지 않음 |
| 목책 대상 | 주변 전체의 소속과 중첩 미정 | 양측 영향, 중복 목책은 최대 −1. 하루 이동력 예산에서 차감할지 진입 비용 +1로 할지 이동 엔진과 함께 확정 |
| 군량/시야 중첩 | 동일 건물 여러 개 및 패시브 중첩 미정 | 동일 건물 효과 중복 금지. 보루는 다른 소비 보정에 0.6 곱 적용, 감시탑은 최대 +1 |
| 작업 중 피격 | 공격/반격은 금지이나 피격 처리 미정 | 피격 가능, 액티브 발동·게이지 충전 중지. 최소 병력은 시작 시 검사; 진행 중 1,000명 미만과 괴멸 처리 별도 확정 |
| 건축 실패 | 작업 부대 괴멸·건물 파괴 시 비용/장수 처리 미정 | 비용 환불 없음, 미완성 건물 제거, 기존 패배 장수 귀환 규칙 사용. 사용자 취소 UI는 제공하지 않음 |
| 철거 권한 | 적 건물 철거 방지 및 주둔 부대 처리 필요 | 소유 세력만 가능. 주둔 부대가 있으면 먼저 출성, 출구가 막히면 철거 불가 |
| 건물 파괴 | 주둔 부대 출현 위치·초과 피해 미정 | 건물 타일에 부대를 다시 표시. 파괴 공격의 잔여 피해 처리·동일 교전 재타격 여부를 확정 |
| 주둔 중 공격 | 보호는 명시됐으나 내부 부대 공격/반격은 미정 | 성과 유사하게 내부 부대가 공격/반격하는 안을 검토. 빈 건물 자동 공격 능력은 부여하지 않음 |
| 정찰대 10명 | 사망 여부·철수 시 귀환 미정 | 사망이 아닌 파견 비용으로 구분해 사망 통계에 넣지 않음. 철수 후 병력 반환 여부 확정 |
| 진법 반복 | 멈춰 있는 적·중첩 진법·여러 부대·부상 반올림 | 실제 이동 도착 때만 부대별 1회, 같은 이동 단계 중복 피해 방지. 현역의 1% 내림·현역 감소=부상 증가, 사망 없음 |
| 대상 부대 | 수송/보급/집단군의 건축 허용 여부 | 우선 전투 가능한 육상 부대. 수송은 제외 권장, 보급/집단군은 1단계에서 확정 |
| 동맹 | 아군의 범위가 동일 세력인지 동맹 포함인지 미정 | 기본 동일 세력. 동맹 통행/오라/진법 면역은 외교 규칙과 함께 확정 |

## 3. 실행 흐름과 UI

1. 육상 부대 선택 → 부대 명령 팔레트 `건축` → 5종 카드. 비용·기간·지형·효과 설명을 표시한다.
2. 병력/금/군량 부족, 진행 재생 중, 건축 중, 부대 상태로 불가할 때 버튼을 비활성하고 이유를 표시한다.
3. 건물 선택 후 지도 호버에 반투명 GLB와 단일 설치 타일·영향 범위를 표시한다.
4. 허용 위치는 녹색, 중복 건물·도시/항구 발자국·유적·생산시설·지형/거리 불가는 붉게 표시한다.
5. 클릭 시 수행 장수 초상과 대사가 있는 확인창에 비용·건축물·완료일·행동 중단·취소 불가를 표시한다.
6. 승인 시 Core가 자원/병력/타일/부대 상태를 다시 검사하고 한 번만 차감·예약한다. 실패는 모달 안에서 안내한다.
7. 공사 중 부대 위 작업 도구 표시와 남은 일수, 해당 타일 공사 상태를 표시한다.
8. 완공 시 도구 표시를 제거하고 건축물 모델·HP·효과를 활성화한다. 부대의 기존 이동 명령 재개 여부는 1단계에서 확정한다.
9. 건물 정보는 기존 지형정보 팔레트 스타일로 소유 세력·HP/DF·효과·범위·주둔 장수/병력·정찰 남은 날을 표시한다.
10. 철거 확인창은 소유자만 사용 가능하며 승인 직전에 소유권·주둔 상태를 재검사한다.

미리보기 취소는 승인 전까지만 우클릭/Esc로 가능하다. 시야 밖 설치·안개 속 숨은 부대 유출 여부도 검증한다.

## 4. 코드 영향 범위와 설계 방향

현재 출전 `CombatUnit`은 `LootGold`/`CarryingGold`, 군량, 장수·원 소속 성을 가진다.
건축 비용은 이 자원에서 결제한다. 도시 금이나 세력 전체 금을 대신 차감하지 않는다.
기존 시설 공사장 회귀 테스트가 실패하는 상태이므로 그 동작을 그대로 재사용하지 않고 원인을 먼저 점검한다.

| 영역 | 예상 작업 |
|---|---|
| Domain/데이터 | `FieldBuilding` 독립 모델: ID, 소유 세력, 종류, 좌표, HP, 시작/완료일, 만료일, 건축/주둔 부대 ID. 건물 정의 JSON에 비용·기간·DF·반경·모델 코드 |
| GameState/저장 | 건물·공사·주둔 관계 저장, 구버전 빈 목록 기본값, 로딩 후 참조 유효성 검사. 공사 재개 시 이중 결제 금지 |
| 명령 서비스 | 순수 Core 건축/철거/입성/출성 검증, 원자적 자원 차감, 동일 타일 공사 예약 충돌 차단 |
| Movement/Passability | 소유 세력별 동적 통행, 목책 이동 페널티, 정찰대 통과, 아군 건물 통행과 실제 주둔 명령 구분 |
| Campaign/전투 | 성과 동일한 건물 표적 분류·건물 피해 배수, 건축 부대 행동 잠금, 보루/진법 HP 우선 보호. 도시 점령/장수 획득/수입 로직과 분리 |
| 시야/군량 | 정찰대 시야 원천과 만료, 감시탑 범위 아군 보너스, 보루 소모 보정. 파괴/철거/이동 시 즉시 재계산 |
| 턴 순서 | 이동 결과 확정 → 정찰 철수·진법 판정 → 병력/부상/시야 반영 → 다음 이동 또는 공격. 진행 끝에 몰아서 처리하지 않음 |
| Game/UI | 명령·5종 카드·설치 미리보기·장수 컨펌·작업 표시·정보/철거·주둔 부대 숨김/복원 |
| AI | 정찰대 제외 적 건물 표적, 동적 장애물 길찾기, 아군 건물 통과. AI의 능동 건축은 별도 확정 후 도입 |

중간 이상 규모의 변경이다. 공사 상태·길찾기·표적·시야·군량·주둔·저장이 서로 연결되므로
로드맵의 8단계를 독립 커밋·QA 단위로 유지한다. 성/항구를 새로운 도시 데이터로 가장해 재사용하면
함락·연구·자동생산 같은 도시 기능이 섞일 수 있으므로 독립 건물 모델에 필요한 전투 인터페이스만 연결한다.

## 5. Blender 에셋 계획

| 모델 | 표현 | 생성 스크립트/파일 예정 |
|---|---|---|
| 목책 | 헥사 1칸 안 낮은 목재 말뚝·차단 울타리 | `make_field_palisade.py` / `field-palisade.glb` |
| 정찰대 | 소수 정찰병·작은 위장 초소 | `make_field_scout.py` / `field-scout.glb` |
| 감시탑 | 목조 고상 망루 | `make_field_watchtower.py` / `field-watchtower.glb` |
| 보루 | 낮은 토루·성책과 주둔 공간 | `make_field_fort.py` / `field-fort.glb` |
| 진법 | 낮은 진형 표식·깃발·방호 기둥 | `make_field_formation.py` / `field-formation.glb` |

스크립트는 `tools/blender/`, GLB는 `SanguoSLG.Game/assets/models/`에 저장한다.
작업 도구 표시도 작은 망치/곡괭이 모양으로 제작하고 부대 머리 위 UI와 겹치지 않게 배치한다.
노말·면 컬링·1타일 크기·모델 높이·입출성 시 숨김·파괴/철거 후 잔존 노드를 QA한다.
Blender는 `--background --python-exit-code 1`로 생성 검증하고 `design-effect.md`에 사용처를 등록한다.

## 6. 완료 전 필수 QA

- 병력 999/1,000 경계, 비용 정확/부족, 정찰 병력 10·군량 5 차감, 중복 승인과 타일 동시 예약.
- 평야/숲/사막 허용, 다른 지형 거부, 정찰 산악 예외, 성/항구 전체 발자국·유적·시설 중복 거부.
- 공사 중 이동/공격/반격/액티브 금지, 피격·괴멸, 완료 전날/당일 및 저장 재개.
- 아군 통과/적군 우회, 정찰대 적 통과 제거, 목책 중첩·좁은 출구·출격 관제와 병목 회귀.
- 7일/14일 완공, 정찰 완공 기준 59/60일 시야 만료, 감시탑 이동·철거·파괴 즉시 시야 반영.
- 보루 1부대만 수용, 입성 후 모델 숨김, 출성 후 복구, HP 우선 손실, 철거/파괴 시 부대 중복·소실 없음.
