# 야전 건축 설계 — 출전 육상 부대

작성일: 2026-10-01. 상태: Phase 18C 8/8단계 구현·통합 QA 완료.
실행 단계는 [Phase 18C](./plan-v2-implementation-roadmap.md#phase-18c-야전-건축)에 기록한다.
기준: [지형](./design-terrain.md), [이동](./design-movement.md), [전투](./design-combat.md),
[부대 군량](./design-unit-state.md), [효과](./design-effect.md).

## 1. 사용자 확정 규칙

출전한 해상부대 외 모든 부대의 명령 팔레트에 `건축`을 추가한다. 일반 전투부대, 보급부대,
수송부대, 집단군도 건축할 수 있다. 비용은 해당 부대의 휴대 자원으로 지불한다.
모든 건축 명령은 시작 시 병력 1,000명 이상이어야 한다. 시작 이후 병력이 1,000명 미만으로
감소해도 부대가 괴멸하지 않는 한 건축은 그대로 진행한다.
건축 중에는 이동·공격·반격을 포함한 모든 행동을 멈춘다. 부대 위에 작업 연장도구 모양 표시를 띄운다.
명령 승인 후 취소는 불가능하며, 완공일은 진행의 일 단위 시계로 계산한다.

건물은 모두 1타일을 차지한다. 이미 건물이 있는 타일에는 추가 건축할 수 없다.
일반 건물 설치 지형은 `plains`(평야), `forest`(숲), `desert`(사막)만 허용한다.
아군은 건물 타일을 통행할 수 있고 적군은 통행할 수 없다. 정찰대는 아래의 별도 예외를 따른다.
적 건물은 적 성과 같은 공격 대상으로 인식하되 정찰대는 공격 대상으로 취급하지 않는다.
건물 수리는 불가능하다. 건물 클릭 → `철거` → 확인창 승인 시 즉시 제거한다.
모든 건축물의 에셋은 Blender로 제작하고 GLB 및 생성 Python을 저장소에 함께 보관한다.
지도에서 정찰대·보루·감시탑은 원본 모델의 70% 크기로 표시한다. 유적 역시 기존 지도 표시 대비 30% 축소한다. 타일 점유·시야·전투 범위는 유지한다.

완공된 목책·감시탑·보루·진법은 주둔 부대 없이도 소유 세력에 자체 시야 반경 1칸을 제공한다.
정찰대는 기존 반경 2칸을 유지한다. 공사 중·철거·파괴·만료된 건축물은 시야를 제공하지 않는다.
정찰대 지도 표시는 공사 중 `건축 N일`, 완공 후 `정찰 N일`이며 진행 중에도 하루마다 갱신한다.
남은 정찰 기간은 완공일부터 60일이며 만료 시 표시를 제거한다. 지도 안개 가시성 규칙을 따른다.

| 건축물 | 휴대 금 | 추가 비용 | HP | 기간 | 효과 |
|---|---:|---|---:|---:|---|
| 목책 | 100 | 없음 | 500 | 7일 | 설치 위치 주변 1칸 전체 이동력 −1, 건물 DF 적용 |
| 정찰대 | 10 | 병력 10명·군량 5 | 전투 대상 아님 | 7일 | 가까운 숲 또는 산악 배치, 반경 2칸 시야 60일, 적 통과 시 철수·소멸 |
| 감시탑 | 150 | 없음 | 500 | 7일 | 반경 2칸 안 아군 시야 +1, 건물 DF 적용 |
| 보루 | 300 | 없음 | 1,000 | 14일 고정 | 반경 2칸 안 아군 군량 소비 40% 감소, 아군 1부대 주둔·건물 HP 우선 보호 |
| 진법 | 300 | 없음 | 500 | 14일 | 반경 1칸 안 적 도착 시 30% 확률로 해당 부대 병력 1%를 부상병으로 전환, 아군 1부대 주둔·건물 HP 우선 보호 |

보루는 장수 능력치와 무관하게 14일이다. 다른 건물도 현재 명세의 7/14일을 그대로 사용하며
별도 능력치 단축은 정의하지 않는다. 공격 가능한 야전 건축물의 공통 DF는 현재 최저 시설 방어력인 4다.

## 2. 확정된 세부 규칙

### 범위 표기

- 사용자 정의 `3×3`은 설치 건물로부터 상·하·좌·우·대각선을 포함해 **2칸 이내**를 뜻한다.
  헥사 좌표에서는 중심을 포함한 `HexCoord.Distance <= 2`, 총 19타일로 계산한다.
- 사용자 정의 `2×2`는 같은 방향 기준 **1칸 이내**를 뜻한다. 헥사 좌표에서는 중심을 포함한
  `HexCoord.Distance <= 1`, 총 7타일로 계산한다.
- 정찰대 시야·감시탑·보루는 반경 2칸, 진법은 반경 1칸을 사용한다. 설치 미리보기에서
  실제 영향을 받는 헥사 전체를 표시하여 명칭과 범위의 오해를 막는다.
- 완공된 건축물을 지도에서 선택하면 기존 성·보급부대의 보급 범위 표시와 같은 방식으로
  실제 영향 타일을 강조한다. 목책은 반경 1칸, 정찰대·감시탑·보루는 반경 2칸,
  진법은 반경 1칸을 표시한다. 공사 중인 건축물은 영향 범위를 표시하지 않는다.
- 범위 표시는 동시에 하나만 유지한다. 다른 부대·성·건축물·지형을 선택하거나 빈 곳 클릭,
  우클릭, Esc로 선택을 해제하면 즉시 제거한다. 안개 속 미탐지 적 건축물과 범위를 노출하지 않는다.

### 설치·통행·효과

- 설치 위치는 건축 부대의 현재 위치 또는 인접 1칸이다. 정찰대 산악 설치는 부대가 산악에
  진입하지 않고 인접 타일에서 수행할 수 있다.
- 일반 건물은 평야·숲·사막만 허용한다. 정찰대만 숲과 `design-terrain.md`의 산악 코드에
  설치할 수 있으며 얼음벽 같은 별도 통행 불가 지형을 자동 포함하지 않는다.
- 정찰대는 양측 통행을 허용하고 공격 표적에서 제외한다. 적이 실제로 타일에 도착하면 즉시 제거한다.
- 목책 영향 범위에 진입하는 양측 부대의 이동 비용을 +1한다. 여러 목책 범위가 겹쳐도 최대 +1이다.
- 같은 종류의 시야·군량 효과는 중첩하지 않는다. 보루는 다른 군량 소비 보정에 0.6을 곱하고,
  감시탑 시야 증가는 여러 개가 겹쳐도 최대 +1이다.
- 건물 효과의 `아군`은 동일 세력만 뜻한다. 동맹 세력은 통행 허용·오라·진법 면역 대상이 아니다.

### 공사·방어·파괴

- 공사 중 부대는 적의 공격을 받을 수 있지만 이동·공격·반격·액티브 발동·스킬 게이지 충전을 하지 않는다.
  병력 1,000명은 시작 시에만 검사하며 공사 중 1,000명 미만이 되어도 계속 진행한다.
- 미완성 공사장은 완성 건물 HP의 50%와 최저 건물 DF를 사용하며 정찰대 외에는 적의 공격 대상이다.
- 작업 부대가 괴멸하거나 공사장이 파괴되면 미완성 건물을 제거하고 자원은 반환하지 않는다.
  장수는 기존 패배·귀환 규칙을 따른다. 사용자 취소 기능은 제공하지 않는다.
- 완공한 부대는 기존 경로를 자동 재개하지 않고 해당 위치에서 명령대기로 전환한다.
- 완성 건물은 현재 게임의 최저 건물 방어력을 공통 DF로 사용한다. 태수·수성 적성 보정은 받지 않는다.
- 보루·진법 내부 부대는 공격과 반격을 할 수 있다. 적 피해는 건물 HP가 먼저 전부 받고,
  건물이 파괴된 공격의 초과 피해는 내부 부대에 넘기지 않는다. 다음 공격부터 노출된 부대가 피해를 받는다.
- 건물 파괴 시 내부 부대를 같은 타일에 다시 표시한다. 빈 건물은 스스로 공격하거나 반격하지 않는다.

### 정찰대·진법·철거

- 정찰대의 병력 10명은 파견 비용으로 영구 소비하며 만료·철수 때 반환하지 않는다. 사망 통계에는 넣지 않는다.
  60일 지속 기간은 완공일부터 계산한다.
- 진법은 적 부대가 범위 타일로 실제 이동을 마친 순간 부대별 1회 판정한다. 멈춰 있는 부대에는
  매 진행마다 재판정하지 않고, 같은 이동 단계에서 여러 진법 범위에 들어가도 한 번만 판정한다.
- 진법 발동 시 현역 병력의 1%를 내림 계산해 현역에서 빼고 부상병에 더한다. 병력이 100명 이상이면
  최소 1명을 전환하며 사망자는 발생하지 않는다.
- 소유 세력만 철거할 수 있고 장수 없이 일반 확인창 승인 직후 제거한다. 철거 비용과 자원 반환은 없다.
  적 건물은 공격으로만 파괴할 수 있다. 보루·진법에 부대가 있으면 먼저 출성해야 하며,
  출성 가능한 타일이 없으면 철거할 수 없다.

## 3. 실행 흐름과 UI

1. 육상 부대 선택 → 부대 명령 팔레트 `건축` → 5종 카드. 비용·기간·지형·효과 설명을 표시한다.
2. 병력/금/군량 부족, 진행 재생 중, 건축 중, 부대 상태로 불가할 때 버튼을 비활성하고 이유를 표시한다.
3. 건물 선택 후 지도 호버에 반투명 GLB와 단일 설치 타일·영향 범위를 표시한다.
4. 허용 위치는 녹색, 중복 건물·도시/항구 발자국·유적·생산시설·지형/거리 불가는 붉게 표시한다.
5. 클릭 시 수행 장수 초상과 대사가 있는 확인창에 비용·건축물·완료일·행동 중단·취소 불가를 표시한다.
6. 승인 시 Core가 자원/병력/타일/부대 상태를 다시 검사하고 한 번만 차감·예약한다. 실패는 모달 안에서 안내한다.
7. 공사 중 부대 위 작업 도구 표시와 남은 일수, 해당 타일 공사 상태를 표시한다.
8. 완공 시 도구 표시를 제거하고 건축물 모델·HP·효과를 활성화한다. 부대는 기존 경로를 재개하지 않고 명령대기한다.
9. 완공 건축물을 클릭하면 건물 종류별 실제 영향 범위를 성·보급부대 범위와 같은 지도 오버레이로 표시한다.
10. 건물 정보는 기존 지형정보 팔레트 스타일로 소유 세력·HP/DF·효과·범위·주둔 장수/병력·정찰 남은 날을 표시한다.
11. 철거 확인창은 소유자만 사용 가능하며 승인 직전에 소유권·주둔 상태를 재검사한다.

미리보기 취소는 승인 전까지만 우클릭/Esc로 가능하다. 시야 밖 설치·안개 속 숨은 부대 유출 여부도 검증한다.

## 4. 코드 영향 범위와 설계 방향

현재 출전 `CombatUnit`은 `LootGold`/`CarryingGold`, 군량, 장수·원 소속 성을 가진다.
건축 비용은 이 자원에서 결제한다. 도시 금이나 세력 전체 금을 대신 차감하지 않는다.
기존 시설 공사장 회귀 테스트가 실패하는 상태이므로 그 동작을 그대로 재사용하지 않고 원인을 먼저 점검한다.

| 영역 | 예상 작업 |
|---|---|
| Domain/데이터 | `FieldBuilding` 독립 모델: ID, 소유 세력, 종류, 좌표, HP, 시작/완료일, 만료일, 건축/주둔 부대 ID. 건물 정의 JSON에 비용·기간·DF·반경·모델 코드 |
| GameState/저장 | 건물·공사·주둔 관계 저장, 구버전 빈 목록 기본값, 로딩 후 참조 유효성 검사. 공사 재개 시 이중 결제 금지 |
| 명령 서비스 | 순수 Core 건축/철거/입성/출성 검증, 원자적 자원 차감, 동일 타일 공사 예약 충돌 차단 |
| Movement/Passability | 소유 세력별 동적 통행, 목책 이동 페널티, 정찰대 통과, 아군 건물 통행과 실제 주둔 명령 구분 |
| Campaign/전투 | 성과 동일한 건물 표적 분류·건물 피해 배수, 건축 부대 행동 잠금, 보루/진법 HP 우선 보호. 도시 점령/장수 획득/수입 로직과 분리 |
| 시야/군량 | 정찰대 시야 원천과 만료, 감시탑 범위 아군 보너스, 보루 소모 보정. 파괴/철거/이동 시 즉시 재계산 |
| 턴 순서 | 이동 결과 확정 → 정찰 철수·진법 판정 → 병력/부상/시야 반영 → 다음 이동 또는 공격. 진행 끝에 몰아서 처리하지 않음 |
| Game/UI | 명령·5종 카드·설치 미리보기·장수 컨펌·작업 표시·완공 건물 선택 범위·정보/철거·주둔 부대 숨김/복원 |
| AI | 정찰대 제외 적 건물 표적, 동적 장애물 길찾기, 아군 건물 통과. AI의 능동 건축은 별도 확정 후 도입 |

중간 이상 규모의 변경이다. 공사 상태·길찾기·표적·시야·군량·주둔·저장이 서로 연결되므로
로드맵의 8단계를 독립 커밋·QA 단위로 유지한다. 성/항구를 새로운 도시 데이터로 가장해 재사용하면
함락·연구·자동생산 같은 도시 기능이 섞일 수 있으므로 독립 건물 모델에 필요한 전투 인터페이스만 연결한다.

## 5. Blender 에셋 계획

| 모델 | 표현 | 생성 스크립트/파일 예정 |
|---|---|---|
| 목책 | 기존 대비 38% 크기의 X자 통나무 방벽 3개를 지그재그 배치 | `make_field_palisade.py` / `field-palisade.glb` |
| 정찰대 | 암석 아치 동굴·입구 한쪽의 작은 등불·올리브색 위장막·보급 상자 (눈 표현 제거) | `make_field_scout.py` / `field-scout.glb` |
| 감시탑 | 기단·기둥·가새·연결 계단·난간을 갖춘 목조 망루 | `make_field_watchtower.py` / `field-watchtower.glb` |
| 보루 | 네 귀퉁이 망루·성벽·성문·중앙 내성을 갖춘 작은 동양식 석성 | `make_field_fort.py` / `field-fort.glb` |
| 진법 | 석주 4개·중앙 돌무더기·기둥 위 구름 7개·이동 주기별 페이드 인/아웃 | `make_field_formation.py` / `field-formation.glb` (`FormationCloudDrift`) |

스크립트는 `tools/blender/`, GLB는 `SanguoSLG.Game/assets/models/`에 저장한다.
작업 도구 표시도 작은 망치/곡괭이 모양으로 제작하고 부대 머리 위 UI와 겹치지 않게 배치한다.
손잡이와 머리는 연결되어 있으며 단일 `ConstructionWork` 애니메이션에서 망치·곡괭이가 함께 반복 작업한다.
노말·면 컬링·1타일 크기·모델 높이·입출성 시 숨김·파괴/철거 후 잔존 노드를 QA한다.
보루 곡선 지붕은 위쪽을 향하는 면과 실제 두께가 있는 폐곡면으로 내보낸다. GLB 재수입 후
12개 지붕 조각의 면 연결·양의 체적·8방향 상부 광선의 앞면 충돌을 검사한다.
Blender는 `--background --python-exit-code 1`로 생성 검증하고 `design-effect.md`에 사용처를 등록한다.
진법 GLB의 구름 애니메이션은 건축물 지도 모델과 정보 카드 미리보기에서 자동 반복 재생한다.

`run-maptest.bat`은 아군과 적군에 건축물 5종을 각각 하나씩 완공 상태로 배치한다. 적 표적형 건축물
4종과 통과 시 철수하는 정찰대를 한 화면에서 공격·이동·시야 회귀 테스트에 사용할 수 있어야 한다.

## 6. 완료 전 필수 QA

- 병력 999/1,000 시작 경계, 착수 후 1,000 미만 계속 진행, 비용 정확/부족, 정찰 병력 10·군량 5 차감,
  중복 승인과 타일 동시 예약.
- 평야/숲/사막 허용, 다른 지형 거부, 정찰 산악 예외, 성/항구 전체 발자국·유적·시설 중복 거부.
- 공사 중 이동/공격/반격/액티브 금지, 피격·괴멸, 완료 전날/당일 및 저장 재개.
- 아군 통과/적군 우회, 정찰대 적 통과 제거, 목책 중첩·좁은 출구·출격 관제와 병목 회귀.
- 반경 2의 19타일·반경 1의 7타일 경계, 7일/14일 완공, 정찰 완공 기준 59/60일 시야 만료,
  감시탑 이동·철거·파괴 즉시 시야 반영.
- 완공 건물별 범위 타일 수와 중심 일치, 공사 중 범위 미표시, 다른 선택·빈 곳·우클릭·Esc 해제,
  성·보급부대 범위와 전환 시 이전 오버레이 제거, 미탐지 적 건물 정보 비노출.
- 보루 1부대만 수용, 입성 후 모델 숨김, 출성 후 복구, HP 우선 손실, 철거/파괴 시 부대 중복·소실 없음.
- 진법 동일 시드 동일 결과, 부대별 도착 판정, 현역 감소량과 부상 증가량 일치, 사망 0, 다음 공격 전에 반영.
- 군량 절감 중첩·경계·이동/철거 즉시 해제, 정찰대 공격 AI 제외, 건축물을 도시로 잘못 점령하지 않음.
- run-maptest 5종 샘플, 장수 컨펌·설치 취소/승인·금 부족 알림·작업 표시·모달 줌 차단 확인.

Phase 18C 1단계에서 `data/field-buildings.json`, `FieldBuildingDefinition`, 독립 `FieldBuilding` 상태와
세이브 스키마 v3를 구현했다. 이전 v1/v2 봉투 및 봉투 없는 원시 저장은 건축물 빈 목록으로 호환한다.

Phase 18C 3단계에서 부대 팔레트의 `건축` 명령, 5종 선택 카드, 현재/인접 타일 배치 미리보기,
선봉 장수 확인창과 착공 연결을 구현했다. 5종 건축물과 망치·곡괭이 작업 표시는 Blender 생성 스크립트와
GLB를 함께 보관하며, 공사 중 잔여 일수와 완공 건축물의 실제 영향 범위를 지도에 표시한다.

Phase 18C 4단계에서 완공 여부와 관계없이 표적 가능한 적 건축물 타일은 이동 경로를 차단하고,
아군은 같은 타일을 통과하도록 했다. 완공 목책의 반경 1칸 이동 비용 +1과 완공 감시탑 반경 2칸 안
아군 부대 시야 +1은 여러 건물이 겹쳐도 한 번만 적용한다. 표적 가능한 건물은 정의된 DF와 HP로 피해를
받고 반격하지 않으며, HP 0이면 즉시 제거된다. 아군 건축물은 정보 카드의 철거 확인 후 즉시 제거되고
수리 명령은 제공하지 않는다.

Phase 18C 5단계에서 정찰대는 숲·산악에만 배치하고 양측 통행을 허용하며 공격 표적에서 제외했다.
완공일부터 59일까지 반경 2칸(19타일) 시야를 제공하고 60일째 제거해 안개를 복원한다. 적 부대가
하루 이동 중 정찰대 타일을 실제로 밟으면 진행 종료를 기다리지 않고 그 이동 정산에서 철수시키며,
공사 중 철수라면 건축 부대도 명령대기로 해제한다. 건물 정보에는 남은 정찰 유지일을 표시한다.

Phase 18C 6단계에서 완공된 보루를 명시적으로 목표 지정해 도착한 동일 세력 부대 한 개만 주둔시킨다.
주둔 부대의 지도 모델·병력 라벨·게이지는 숨기고 보루 정보 카드에서 장수와 병력을 확인·출성할 수 있다.
주둔 중에는 철거를 막으며, 적 공격은 보루 HP를 먼저 소모하고 파괴 공격의 초과 피해는 내부 부대로
넘기지 않는다. 완공 보루 반경 2칸 안 같은 세력 부대의 군량 소모에는 0.6을 곱하고 여러 보루가
겹쳐도 한 번만 적용한다.

Phase 18C 7단계에서 적 부대가 이동 경로상 진법 반경 1칸에 범위 밖에서 실제 진입한 순간을 판정한다.
한 이동 단계에 여러 진법 범위가 겹쳐도 부대당 첫 진법으로 한 번만 30% 판정하며, 성공하면 현역의
1%를 내림 계산해 부상병으로 옮긴다. 현역 100명 이상은 최소 1명이고 사망자는 발생하지 않는다.
이미 범위 안에 멈춘 부대는 다음 진행에 재판정하지 않으며, 전환 결과는 액티브·일반 공격보다 먼저
반영된다. 난수 공급자를 주입해 동일 시드와 입력의 결과가 같고, 보고 로그에서 전환 인원을 확인한다.

Phase 18C 8단계에서 공격 모드 AI는 적 성과 표적 가능한 야전 건축물을 거리순으로 함께 비교하되
정찰대는 제외한다. 건축 부대가 괴멸해 사라지면 연결된 미완성 공사장도 같은 일 단위 정산에서 제거한다.
저장 왕복은 건축/완공일·만료일·건축 부대·주둔 부대를 보존하며, `run-maptest.bat`에는 목책·정찰대·
감시탑·보루·진법 완공 샘플을 각각 한 개씩 배치했다. Core 통합 테스트와 Godot 헤드리스 UI QA에서
5종 모델·진법 반복 애니메이션·범위 7/19타일·지도 노드 생성을 함께 검증한다.
