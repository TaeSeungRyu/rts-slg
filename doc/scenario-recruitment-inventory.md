# 기본 시나리오 세력·거점 장수 및 영입 후보 현황

기준: `SanguoSLG.Game/assets/scenarios/*.json`, `data/generals.json`, `data/hero_unlocks.json` (2026-10-30).
아래 `선행 충족 후보`는 시작 장수가 영입 선행 조건을 이미 충족하지만 아직 주둔하지 않는 장수다. `연쇄 후보`는 이들을 영입한 뒤 추가로 조건이 충족되는 장수다. 두 범주는 서로 겹치지 않는다. 조건 없는 공통 후보는 시나리오별로 따로 적었다.
실제 영입에는 영입 포인트와 금도 필요하다. 현재 코드의 영입 조건은 출생 연도·역사적 소속을 검사하지 않으므로, 아래 명단은 역사적 연도별 등장 보장이 아니라 **현 구현 기준의 후보**다. 다른 세력에 이미 배치된 장수는 제외한다.
표의 `거점별 장수`에는 소유 성·항구를 **0명까지 모두** 표시한다. 관문은 별도 열에 표시한다.
