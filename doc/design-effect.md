# 설계 노트 — 효과 정의 (2026-08-06)

> 사용자 정의 원본을 기준으로 관리하는 효과 카탈로그.
> 신규 효과는 이 문서에 먼저 정의하고 구현한다.
> 부서진 **형태**는 [design-terrain.md](./design-terrain.md)의 "부서진 형태" 절이 담당한다 —
> 이 문서는 형태 위에 얹는 **연출**만 다룬다.

## 범위와 원칙

- 효과는 **Game(표현) 계층 전용**이다. `SanguoSLG.Core`는 효과를 모른다.
- 효과는 **건물(지물 타일)과 캐릭터(부대 토큰) 양쪽에** 붙는다. 대상별로 따로 만들지 않고
  하나의 효과를 임의의 `Node3D`에 부착할 수 있어야 한다.
- 효과는 시뮬레이션 결과에 영향을 주지 않는다. 난수를 쓰는 효과도 표현용 시드를 따로 쓴다.
- **발동 규칙(어떤 상황에서 어떤 효과가 붙는지)은 아직 정의하지 않았다.** 설계자 영역이며
  임의로 정하지 않는다. 이 문서는 "무엇을 그릴 것인가"까지만 확정한다.

## 표기 규약

- **구현**: O = 현재 코드에 존재, △ = 일부만 존재(비고 참조), X = 미구현
- **분류**: `파티클`(CpuParticles3D) · `노드`(메시를 코드로 배치·애니메이션) · `재질`(셰이더/재질 변조) · `후처리`(화면 전체)
- **부착**: `대상` = 건물/캐릭터 노드에 자식으로 붙음, `화면` = 카메라·환경 단위

## 구현 메모

### 현재 상태의 한계

기존 효과 4종(7·9·10·11)은 **특정 지형에 붙박이로 하드코딩**되어 있다. 굴뚝 연기는 마을 2의 굴뚝
위치를 상수로 알고 있고, 구름은 산 정상 높이를 인자로 받는다. 효과를 "건물과 캐릭터 아무 곳에나
붙이는" 체계로 쓰려면 지형 코드에서 분리해야 한다.

### 필요한 공통 구조

- 임의의 `Node3D`에 효과를 붙이고 떼는 진입점 하나
- 효과별 파라미터(크기·세기·색)는 대상 크기에 비례해 정해지도록 — 타일 반경이 0.5774인
  작은 월드라 엔진 기본값이나 미터 단위 상수를 그대로 쓰면 안 된다
- 여러 효과가 한 대상에 동시에 붙을 수 있어야 한다(예: 부서진 건물에 `Fire` + `Smoke`)

### 신규 에셋이 필요한 효과

- `Skulls` — 회색 해골 메시
- `Confusion` — 물음표 메시
- `Daze` — 점·별 메시 (별은 저폴리 평면으로 충분할 듯)

## 미결 사항

1. **`Desaturate`의 범위** — "톤이 전체 회색"이 *대상 하나*가 회색이 되는 것인지, *화면 전체*가
   회색이 되는 것인지. 목록의 다른 항목이 모두 대상 단위라 대상 단위로 적어두었으나 확인 필요.
2. **발동 규칙** — 각 효과가 어떤 게임 상황(상태 이상, 전투, 재해, 내정 등)에 대응하는지.
3. **지속 방식** — 상시 반복인지, 1회 재생 후 사라지는지, 턴 단위로 유지되는지.
4. **캐릭터 적용 시점** — 부대 토큰 위에 붙는지, 부대 소속 무장 개별로 붙는지.
