# 설계 노트 — 효과 정의 (2026-08-06)

> 사용자 정의 원본을 기준으로 관리하는 효과 카탈로그.
> 신규 효과는 이 문서에 먼저 정의하고 구현한다.
> 부서진 **형태**는 [design-terrain.md](./design-terrain.md)의 "부서진 형태" 절이 담당한다 —
> 이 문서는 형태 위에 얹는 **연출**만 다룬다.

## 범위와 원칙

- 효과는 **Game(표현) 계층 전용**이다. `SanguoSLG.Core`는 효과를 모른다.
- 효과는 **건물(지물 타일)과 캐릭터(부대 토큰) 양쪽에** 붙는다. 대상별로 따로 만들지 않고
  하나의 효과를 임의의 `Node3D`에 부착할 수 있어야 한다.
- 효과는 시뮬레이션 결과에 영향을 주지 않는다. 난수를 쓰는 효과도 표현용 시드를 따로 쓴다.
- **발동 규칙·지속 방식·적용 시점은 나중에 정의한다.** 설계자 영역이며 임의로 정하지 않는다.
  이 문서는 "무엇을 그릴 것인가"까지만 확정한다.
- **1차 검수는 테스트 유닛에 지속표시**로 한다. 규칙 없이 항상 켜둔 상태로 눈으로 확인한 뒤,
  발동 규칙은 그다음 단계에서 붙인다.

## 표기 규약

- **구현**: O = 현재 코드에 존재, △ = 일부만 존재(비고 참조), X = 미구현
- **분류**: `파티클`(CpuParticles3D) · `노드`(메시를 코드로 배치·애니메이션) · `재질`(셰이더/재질 변조) · `후처리`(화면 전체)
- **부착**: `대상` = 건물/캐릭터 노드에 자식으로 붙음, `화면` = 카메라·환경 단위

## 구현 메모

### 현재 상태의 한계

기존 효과 4종(7·9·10·11)은 **특정 지형에 붙박이로 하드코딩**되어 있다. 굴뚝 연기는 마을 2의 굴뚝
위치를 상수로 알고 있고, 구름은 산 정상 높이를 인자로 받는다. 효과를 "건물과 캐릭터 아무 곳에나
붙이는" 체계로 쓰려면 지형 코드에서 분리해야 한다.

### 필요한 공통 구조

- 임의의 `Node3D`에 효과를 붙이고 떼는 진입점 하나
- 효과별 파라미터(크기·세기·색)는 대상 크기에 비례해 정해지도록 — 타일 반경이 0.5774인
  작은 월드라 엔진 기본값이나 미터 단위 상수를 그대로 쓰면 안 된다
- 여러 효과가 한 대상에 동시에 붙을 수 있어야 한다(예: 부서진 건물에 `Fire` + `Smoke`)

### 신규 에셋이 필요한 효과

- `Skulls` — 회색 해골 메시
- `Confusion` — 물음표 메시
- `Daze` — 점·별 메시 (별은 저폴리 평면으로 충분할 듯)

## 구현 계획 (미착수)

### 1단계 — 검수 뼈대

- `EffectView` 진입점 하나: 임의의 `Node3D`에 효과를 붙이고 뗀다
- 크기 파라미터는 **대상 크기 비례**로 받는다 — 타일 반경 0.5774짜리 월드라 엔진 기본값이나
  미터 단위 상수를 그대로 쓰면 안 된다([[project-godot-meter-scale-defaults]]와 같은 함정)
- 한 대상에 여러 효과가 동시에 붙을 수 있어야 한다
- 빈 행(현재 맵 `r=5`가 완전히 비어 있음)에 효과 수만큼 테스트 유닛을 세우고 각각 하나씩
  지속표시한다. 어느 것이 어느 효과인지 알 수 있게 이름표를 함께 띄운다

### 2단계 — 신규 소품 제작 (Blender)

전용 메시가 필요한 것만. 나머지는 코드에서 만드는 기본 도형으로 충분하다.

| 소품 | 쓰이는 효과 | 비고 |
|---|---|---|
| 해골 | `Skulls` | 회색, 눈구멍은 불리언으로 파냄 |
| 물음표 | `Confusion` | |
| 별 | `Daze` | 점은 코드에서 구체로 |
| 파리 | `Flies` | 몸통 + 날개 |

### 3단계 — 효과 구현

- 파티클 계열(`Fire` `Flies` `Skulls` `Smoke` `Burst` `Clouds` `Waterfall`): 기존
  `CpuParticles3D` 방식과 같은 틀. 이 중 `Smoke` `Clouds` `Waterfall`은 지형에 붙박이로
  하드코딩된 기존 구현을 떼어내 범용화하는 작업이다
- 노드 계열(`Flood` `Daze` `Villagers` `Confusion`): 메시를 코드로 배치하고 애니메이션.
  `Villagers`는 기존 `VillagerAmbience`를 그대로 재사용
- `Desaturate`는 별도 취급이 필요하다. 대상 하나만 회색으로 만들려면 재질을 바꿔야 하는데,
  **재질은 인스턴스 간에 공유되는 리소스**라 그냥 고치면 같은 모델을 쓰는 다른 대상까지
  전부 회색이 된다. 대상별로 재질을 복제해야 한다

## 미결 사항 (나중에 정의)

1. **발동 규칙** — 각 효과가 어떤 게임 상황(상태 이상, 전투, 재해, 내정 등)에 대응하는지.
2. **지속 방식** — 상시 반복인지, 1회 재생 후 사라지는지, 턴 단위로 유지되는지.
3. **적용 시점** — 부대 토큰 위에 붙는지, 부대 소속 무장 개별로 붙는지.
