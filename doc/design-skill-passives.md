# 설계 노트 — 전투 패시브 스킬 목록 (초안, 2026-08-10)

> 스킬 메커니즘·슬롯 규칙은 [design-skill.md](./design-skill.md),
> 산출 순서(③ 가산 버킷)는 [design-combat.md](./design-combat.md) 참조.
> **수치는 초안이다** — Sandbox 1000턴 시뮬레이션으로 튜닝 후 확정(미결).

## 적용 규칙

- 패시브는 **발동 판정 없이 상시** 산출 ③ **가산 버킷**에 들어간다. 공격형은 공격 가산,
  방어형은 방어 가산. **선봉·부관 두 장수의 패시브가 모두** 합산된다.
- 값은 **정수 퍼센트 포인트**다(예: +12 → ×112÷100). 곱을 전부 먼저, 나눗셈은 맨 끝 한 번
  — 부동소수를 쓰지 않아 결정론이 지켜진다([design-combat.md](./design-combat.md) 피해 공식).
- **조건부 패시브는 조건이 성립할 때만** 가산한다. 조건은 전부 결정론적으로 판정 가능한
  상태(병력비·포위 여부·지형·상대 모드·주둔 여부·교전 사거리)만 쓴다 — 난수 없음.
- 같은 버킷의 여러 패시브는 **서로 더한다**. 트레이드오프의 `-`도 같은 방식으로 더해져
  base 아래로 내려갈 수 있다.

## 경험 단계 (1·2·3)

- 모든 패시브는 **1·2·3단계** 값을 갖는다. **3단계가 최대(설계치)**이고 1·2단계는 축소값이다.
- **표기 규칙**: `1단계 = round(최대×1/3)`, `2단계 = round(최대×2/3)`, `3단계 = 최대`.
  (아래 표에는 계산 결과를 직접 적어둔다.)
- **조건·임계치는 단계와 무관하게 고정**이다 — 병력 50% 기준, 지형, 사거리 조건은 그대로.
  단계는 **효과 크기(%)만** 키운다.
- **트레이드오프는 `+`와 `-`가 함께 스케일**한다(1단계는 이득도 손해도 작다). 단,
  이동력 `-1`처럼 정수 페널티는 쪼갤 수 없어 **모든 단계에서 고정**이다.
- **나중에 추가할 "전투경험"이 유닛별로 이 단계를 올린다**(미결) — 같은 패시브라도 갓 뽑은
  유닛은 1단계, 백전노장 부대는 3단계로 효과가 다르다. 경험 누적 규칙은 별도 설계.
