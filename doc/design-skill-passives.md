# 설계 노트 — 전투 패시브 스킬 목록 (초안, 2026-08-10)

> 스킬 메커니즘·슬롯 규칙은 [design-skill.md](./design-skill.md),
> 산출 순서(③ 가산 버킷)는 [design-combat.md](./design-combat.md) 참조.
> **수치는 초안이다** — Sandbox 1000턴 시뮬레이션으로 튜닝 후 확정(미결).

## 적용 규칙

- 패시브는 **발동 판정 없이 상시** 산출 ③ **가산 버킷**에 들어간다. 공격형은 공격 가산,
  방어형은 방어 가산. **선봉·부관 두 장수의 패시브가 모두** 합산된다.
- **조건부 패시브는 조건이 성립할 때만** 가산한다. 조건은 전부 결정론적으로 판정 가능한
  상태(병력비·포위 여부·지형·상대 모드·주둔 여부·교전 사거리)만 쓴다 — 난수 없음(CLAUDE.md 규칙 4).
- 같은 버킷의 여러 패시브는 **서로 더한다**(하이브리드 결합). 트레이드오프의 `-`도 같은 방식으로
  더해져 base 아래로 내려갈 수 있다.
- 트레이드오프 중 이동력에 걸리는 것(중장)은 [design-movement.md](./design-movement.md) 이동
  보정으로 처리한다.
