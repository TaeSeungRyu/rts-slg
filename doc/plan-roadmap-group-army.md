## 🆕 집단군 시스템 (2026-09-03 계획)

전투 중심 v2의 대규모 부대 운용 기능으로 **집단군**을 추가한다.

### 확정 규칙

-   [ ] 보병 + 궁병 + 공성 병기를 하나의 집단군으로 편성
-   [ ] 공성 병기는 투석기 또는 벽력거 중 선택
-   [ ] 최대 총병력 **30,000**
-   [ ] 월드맵에서 **1개 부대**로 운용
-   [ ] 이동속도 **1칸/일 고정**
-   [ ] 유닛/건물/성 공격 사거리 **모두 1**
-   [ ] 유닛 대상 공격 능력은 **성(城)** 기준
-   [ ] 건물/성 대상 공격 능력은 **공성탑(`SiegeTower`)** 기준
-   [ ] 방어 DF는 **공성탑(`SiegeTower`)** 기준
-   [ ] 집단군 편성 중 **액티브 스킬 미발동**

### 구현 단계

1.  [ ] Core 집단군 도메인 모델 및 최대 병력 30,000 규칙
2.  [ ] 보병/궁병/공성 병기 혼성 편성 검증
3.  [ ] Deploy 계층에 집단군 편성/출전 명령 추가
4.  [ ] 이동속도 1 및 사거리 1 고정 규칙 연결
5.  [ ] Combat 계층에 집단군 전용 능력치 참조 규칙 연결
6.  [ ] 액티브 스킬 발동 차단
7.  [ ] Game 집단군 편성 UI
8.  [ ] 월드맵 집단군 표시 방식
9.  [ ] AI 집단군 편성·운용
10. [ ] Sandbox 밸런스 시뮬레이션 및 Core 테스트 잠금

### 밸런스 검증

-   [ ] 일반 10,000 부대와 집단군 30,000의 전투력 차이 검증
-   [ ] 다대일 전투에서 집단군의 생존력 검증
-   [ ] 성 인접 공격 시 반격을 받는 공성 밸런스 검증
-   [ ] 액티브 미발동 페널티가 대규모 병력 이점을 충분히 상쇄하는지 검증
-   [ ] 패시브 스킬 적용 유지 여부 최종 확정
-   [ ] 내부 병종별 병력 비율 및 피해 배분 규칙 최종 확정
