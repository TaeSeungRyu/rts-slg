# 전투 중심 리디자인 v2

작성일: 2026-08-31  
목표: 삼국지 11/13식 내정 확장 방향에서 벗어나, “전투·공성·보급·장수 성장·이벤트 사냥”이 중심인 색다른 헥사 전술 캠페인으로 재정의한다.

## 1. 새 핵심 컨셉

> 장수와 부대를 편성해 보급선을 유지하며 성을 공략하고, 전장 이벤트와 강적을 사냥해 장수와 세력을 성장시키는 헥사 전술 캠페인.

이 방향은 기존 삼국지식 틀을 완전히 버리지는 않는다. 장수, 성, 병종, 공성, 계략이라는 맛은 살린다. 다만 플레이의 중심을 도시 내정이 아니라 전투 지도 위의 선택으로 옮긴다.

플레이어가 매번 고민해야 하는 질문은 다음과 같다.

- 이번 공세에 어떤 장수를 선봉으로 세울까?
- 보급이 끊기기 전에 성을 뚫을 수 있을까?
- 공성 병기를 보호할 것인가, 기동 부대로 우회할 것인가?
- 적장을 잡아 경험치를 먹일 것인가, 안전하게 후퇴할 것인가?
- 용·봉황 같은 강적 이벤트를 지금 사냥할 수 있을까?
- 얻은 아이템이나 특수부대를 어느 장수에게 줄 것인가?

즉, 새 방향의 핵심 감정은 “왕국 운영”보다 “전장 판단과 성장”이다.

## 2. 새 플레이 루프

## 2-1. 자동 내정 축소안

전투 중심 리디자인의 핵심은 내정을 없애는 것이 아니라, 플레이어가 매번 수동으로 누르는 내정 명령을 없애는 것이다.

도시 내정은 “담당자를 배치하면 알아서 오른다”는 자동 운영 구조로 축소한다. 플레이어는 매 턴 세율, 시장, 모병, 징병, 훈련 버튼을 누르지 않는다. 대신 도시마다 네 가지 담당 슬롯만 둔다.

| 담당 | 담당 능력치 | 자동 효과 |
|---|---|---|
| 치안 담당 | 무력 | 치안 유지·회복 |
| 내정 담당 | 정치 | 금과 식량 생산 |
| 병력 담당 | 무력 | 도시 병력 자동 생산 |
| 훈련 담당 | 무력 | 대기 병력 훈련도 자동 증가 |

담당자가 없으면 해당 항목은 오르지 않는다. 단, 치안은 담당자가 없으면 서서히 떨어진다. 이 구조는 “내정 버튼 클릭”을 “장수를 어느 도시/전선에 둘 것인가”로 바꾼다.

### 추천 기본 수치

아래 수치는 첫 구현용 추천값이다. 밸런스가 아니라 체감 검증이 목적이다.

| 항목 | 공식 초안 |
|---|---|
| 치안 | 담당자 무력 60 미만: +0 / 60~79: +1월 / 80~99: +2월 / 100 이상: +3월 |
| 치안 자연 하락 | 치안 담당자 없음: -2월 |
| 금 생산 | 기본 100 + 내정 담당 정치 × 2 |
| 식량 생산 | 기본 300 + 내정 담당 정치 × 5 |
| 병력 생산 | 기본 200 + 병력 담당 무력 × 5 |
| 훈련도 증가 | 담당자 무력 60 미만: +1월 / 60~79: +2월 / 80~99: +3월 / 100 이상: +4월 |

치안은 0~100, 훈련도는 0~100으로 둔다. 담당자가 없으면 병력·훈련·금·식량은 현상 유지, 치안만 하락한다.

### 도시별 병종 특색

모병과 징병은 하나의 “병력 생산”으로 통합한다. 플레이어가 매번 모병/징병을 누르지 않고, 도시가 매월 자기 특색 병종을 자동 생산한다.

예:

| 도시 특색 | 자동 생산 |
|---|---|
| 도검 도시 | 도검병 |
| 궁병 도시 | 궁병 |
| 기병 도시 | 기병 |
| 공성 도시 | 공성 병기 |
| 수군 도시 | 선박/수군 |
| 상병 도시 | 상병 |

병종 특색은 시나리오 데이터에 둔다. 도시는 한 가지 기본 생산 병종을 갖고, 특수 거점이나 이벤트 보상으로 추가 병종을 열 수 있다.

### 제거 대상 확정

| 기능 | 처리 |
|---|---|
| 인구수 | 제거 |
| 세율 | 제거 |
| 시장 | 제거 |
| 모병/징병 구분 | 하나의 병력 생산으로 통합 |
| 충성 | 제거 |
| 도시 계략 “이간” | 제거 |

### 유지 대상 확정

| 기능 | 처리 |
|---|---|
| 병종 연구 | 기존 시스템 유지 |
| 도시 계략 | 유지하되 “이간”만 제거 |
| 보급 시스템 | 기존 중요도 유지 |
| 부대 편성 | 전투 중심으로 강화 |

## 2-2. 함락과 장수 획득 규칙

충성 시스템을 제거하는 대신, 함락과 멸망 시 장수 획득을 확률 이벤트로 단순화한다.

| 상황 | 처리 |
|---|---|
| 성 함락 | 해당 성 소속 장수를 30% 확률로 획득 |
| 세력 멸망 | 남은 장수를 70% 확률로 획득 |
| 세력 멸망 후 미획득 장수 | 70% 확률로 다른 세력에 자동 편입 |

이 규칙은 충성도, 급여, 배신, 포로교환 같은 복잡한 인사 관리를 제거하면서도 “성을 먹으면 장수를 얻을 수 있다”는 삼국지식 보상을 남긴다.

권장 처리:

- 함락 시 획득 실패 장수는 일단 재야 또는 탈출 상태
- 세력 멸망 시 획득 실패 장수는 70% 확률로 타 세력 편입, 나머지는 재야
- 중요 장수는 이벤트 보정이나 고유 규칙을 둘 수 있지만 첫 구현에서는 일반 확률만 사용

## 2-3. 생산 명령: 전투 지도 위 채집

논·밭·마을은 더 이상 새로 건설하지 않는다. 게임 시작 시 배치된 곳에서 그대로 존재한다. 대신 장수와 병력을 보내 자원을 얻는 “생산” 명령을 추가한다.

이 기능은 기존 내정 버튼과 다르다. 전투 지도 위에 병력을 보내고, 그 병력이 실제로 위험에 노출되는 채집형 작전이다.

### 생산 명령 흐름

1. 도시에서 “생산” 선택
2. 대상 논·밭·마을 선택
3. 담당 장수 선택
4. 투입 병종 선택
5. 명령 대기 등록
6. 진행 시 500명 부대가 대상까지 이동
7. 대상에 도착하면 “채집” 상태로 전환
8. 화면에서 부대는 사라짐
9. 논·밭·마을 클릭 시 진행 정보 표시
10. 14일 또는 단축된 기간 후 자동 복귀
11. 성에 돌아오면 금/식량 획득

### 생산 명령 규칙

| 항목 | 규칙 |
|---|---|
| 투입 병력 | 무조건 500명 |
| 병종 | 사용자가 선택 |
| 장수 | 반드시 선택 |
| 시작 조건 | 해당 병력과 장수가 명령 대기 상태에 있어야 함 |
| 취소 | 시작 후 취소 불가능 |
| 이동 | 선택 병종의 실제 기동력 사용 |
| 채집 상태 | 대상 시설에 들어가면 화면에서 부대 숨김 |
| 피격 | 외부 공격을 받으면 500명 전부 소실 |
| 완료 | 채집 종료 후 이동턴에 자동 복귀 |
| 복귀 | 복귀도 병종 기동력 그대로 사용 |
| 기간 | 기본 14일, 정치가 높으면 단축 |

### 생산 기간 추천 공식

기본 14일에서 담당 장수 정치에 따라 줄인다.

| 정치 | 소요일 |
|---|---|
| 0~59 | 14일 |
| 60~79 | 12일 |
| 80~99 | 10일 |
| 100 이상 | 8일 |

정치는 직접 전투 능력은 아니지만, 이런 방식으로 작전 효율에 연결할 수 있다.

### 생산 보상 추천

| 대상 | 기본 보상 | 정치 80 이상 | 정치 100 이상 |
|---|---|---|---|
| 마을 | 금 250 | 금 350 | 금 500 |
| 논 | 식량 800 | 식량 1,100 | 식량 1,500 |
| 밭 | 식량 500 | 식량 700 | 식량 1,000 |

보상은 “월 수입”이 아니라 “위험을 감수한 작전 보상”이므로 기존 시설 수입보다 크게 잡는다. 단, 500명이 전부 소실될 수 있으므로 공짜 내정이 아니다.

### 생산 UI

논·밭·마을을 클릭했을 때 표시할 정보:

- 시설 이름
- 현재 상태: 비어 있음 / 채집 중 / 복귀 중
- 수행 장수
- 투입 병력 500
- 병종
- 남은 일수
- 예상 보상

채집 중인 부대는 지도에서 보이지 않는다. 대신 시설 위에 작은 아이콘이나 숫자로 진행 중임을 표시한다.

### 생산의 전투적 의미

생산은 단순 내정이 아니라 작은 군사 작전이다.

- 안전한 후방 시설은 안정적 보상
- 전선 근처 시설은 큰 위험
- 적 기병이 급습하면 채집 병력 전멸
- 플레이어는 호위 부대를 둘지 말지 고민
- 적 시설 근처를 견제하면 상대 생산을 방해 가능

이 방식이면 내정이 전투 지도를 떠나지 않는다.

## 2-4. 보급부대 편성

보급은 기존 시스템의 중요도를 유지한다. 전투부대 주변에 보급부대가 없으면 승패에 큰 영향을 주는 구조를 그대로 살린다.

다만 출전 UI에서 “보급부대” 편성이 명확히 분리되어야 한다.

### 보급부대 규칙

| 항목 | 규칙 |
|---|---|
| 편성 위치 | 출전 화면에서 전투부대와 별도 탭 또는 별도 버튼 |
| 사용 병종 | 어떤 병종이든 보급부대로 사용 가능 |
| 병력 | 기존 보급부대 상한 규칙 유지 |
| 전투력 | 보급부대는 전투에 부적합 |
| 비용 감각 | 비싼 병종을 보급부대로 쓰면 그만큼 손해 |
| 역할 | 주변 전투부대 보급 유지 |

예를 들어 기병을 보급부대로 쓸 수는 있다. 하지만 기병은 비싸고 전투력이 좋은 병종이므로 보급부대로 소모하면 손해다. 반대로 값싼 병종은 보급부대에 적합하다.

이 선택은 좋은 전투 고민이다.

- 빠른 보급부대가 필요한가?
- 싼 보급부대로 충분한가?
- 위험 지역을 통과해야 하므로 강한 병종을 넣을 것인가?
- 보급부대를 호위할 것인가?

## 2-5. 병종 연구 유지 방향

병종 연구는 기존 시스템을 유지한다. 다만 UI와 의미는 전투 중심으로 재정리한다.

권장 방향:

- 연구는 도시 내정이 아니라 세력 전투 교리
- 병종 연구 UI는 복잡도를 낮춰 한 화면에서 관리
- 공방 조건은 유지 가능
- 연구는 장기 목표로 남기되, 매턴 누르는 내정 버튼처럼 느껴지지 않게 한다

병종 연구를 유지하면 장수 숙련 성장과 함께 두 축이 생긴다.

| 성장 축 | 대상 | 의미 |
|---|---|---|
| 병종 연구 | 세력 전체 | 이 세력이 해당 병종을 얼마나 잘 운용하는가 |
| 장수 숙련 | 장수 개인 | 이 장수가 해당 병종을 얼마나 잘 다루는가 |

이 둘은 함께 적용하되, 수치 폭주는 막아야 한다.

추천:

- 병종 연구는 기존 공격/방어 보정 유지
- 장수 숙련은 적성 등급 상승 중심
- 둘 다 곱셈 폭주가 아니라 flat 또는 등급 보정으로 처리

## 2-6. 도시 계략 유지 방향

도시 계략은 유지하되 “이간”은 제거한다.

이간은 충성 시스템과 강하게 연결되어 있다. 충성을 제거하면 이간도 자연스럽게 사라진다.

유지 후보:

- 정찰
- 방화
- 성벽파괴
- 선동
- 절취

다만 도시 계략은 전투 집중도를 흐릴 수 있으므로 다음 원칙을 둔다.

- 전투 준비에 직접 연결되는 계략만 유지
- 장기 인사·충성 조작 계략은 제거
- 효과는 명확하고 짧게
- UI에서는 “도시 공작”보다 “전선 지원” 느낌으로 표현

예:

| 계략 | v2 의미 |
|---|---|
| 정찰 | 적 성 병력/장수/보급 확인 |
| 방화 | 적 성 식량 감소 |
| 성벽파괴 | 공성 준비 |
| 선동 | 방어 효율 저하 |
| 절취 | 전쟁 자금 확보 |

이간은 제거한다.

## 2-7. 제거 후 남는 핵심 도시 UI

성 클릭 시 최종 UI는 다음 정도가 좋다.

- 출전
- 보급부대
- 생산
- 재편성
- 수리
- 연구
- 계략
- 담당자

여기서 “담당자”는 한 번 열어서 네 슬롯을 지정하는 화면이다. 매번 누르는 명령이 아니다.

담당자 화면:

| 슬롯 | 장수 | 효과 |
|---|---|---|
| 치안 | 장수명 | 월 치안 +N |
| 내정 | 장수명 | 월 금 +N / 식량 +N |
| 병력 | 장수명 | 월 병력 +N |
| 훈련 | 장수명 | 월 훈련도 +N |

이렇게 하면 내정은 남지만, 플레이어의 반복 클릭을 거의 만들지 않는다.

### 기본 루프

1. 전선과 목표 확인
2. 성에서 부대 편성
3. 장수·병종·보급량 선택
4. 이동·공격·후퇴·계략 예약
5. 7일 진행
6. 전투 결과, 경험치, 숙련도, 전리품 확인
7. 보충·재편성 후 다음 공세 결정

### 중기 루프

1. 주변 성과 거점 점령
2. 공방·항구·보급 거점 확보
3. 장수 숙련도 성장
4. 특수 이벤트 출현
5. 강적 사냥 또는 회피
6. 아이템·특수부대 획득
7. 다음 전선으로 확장

이 구조에서는 “도시를 키워서 강해지는 게임”이 아니라 “싸우고 살아남아서 강해지는 게임”이 된다.

## 4. 지도 구조 재정의

도시는 더 이상 복잡한 내정 계산의 중심이 아니다. 전투를 시작하고 유지하는 거점이다.

### 도시가 제공하는 것

- 출전 지점
- 병력 보충
- 군량 보급
- 부상병 회복
- 방어 거점
- 장수 재편성

### 필드 거점

논·밭·마을·공방 같은 시설은 직접 건설하는 대상보다, 지도 위에서 싸워서 차지하는 거점으로 바꾸는 것이 좋다.

| 거점 | 효과 |
|---|---|
| 마을 | 병력 보충량 증가 |
| 논·밭 | 군량 회복 또는 보급 범위 증가 |
| 공방 | 공성 병기 편성 가능 |
| 항구 | 수군 편성 가능 |
| 광산 | 중장비·공성 병기 보너스 |
| 목장 | 기병 편성/회복 보너스 |
| 상원 | 상병 또는 특수 상병 획득 조건 |
| 신수 둥지 | 용·봉황 등 이벤트 강적 출현 |

이렇게 하면 시설은 “클릭해서 키우는 숫자”가 아니라 “전투 목표”가 된다.

## 5. 장수 성장 시스템

v2의 가장 중요한 새 축이다. 장수는 고정 스탯 덩어리가 아니라, 전투를 통해 성장하는 캐릭터가 된다.

### 성장 축

장수 성장에는 세 갈래를 둔다.

1. 경험치 레벨
2. 병종 숙련도
3. 액티브 스킬 레벨

### 5.1 장수 경험치

장수는 전투 참여, 적 부대 격파, 성 공략, 강적 사냥으로 경험치를 얻는다.

추천 경험치 원천:

| 행동 | 경험치 |
|---|---|
| 전투 참여 | 소량 |
| 적 병력 피해 | 피해량 비례 |
| 적 부대 격파 | 보너스 |
| 성벽 파괴 기여 | 보너스 |
| 성 점령 | 큰 보너스 |
| 적장 포획 | 보너스 |
| 용·봉황 사냥 | 매우 큰 보너스 |

경험치 레벨은 전체 능력치를 직접 크게 올리기보다, 성장 선택권을 주는 방식이 좋다.

예:

- 레벨업 시 성장 포인트 +1
- 성장 포인트로 병종 숙련 상승, 액티브 강화, 패시브 해금 중 선택

### 5.2 병종 숙련도

기존 장수의 병종 등급 D/C/B/A/S를 전투 경험으로 올릴 수 있게 한다.

예:

- 도검병 D → C
- 궁병 B → A
- 기병 A → S

다만 모든 장수가 전부 S까지 가면 개성이 사라진다. 성장 한계가 필요하다.

추천 규칙:

| 현재 등급 | 일반 성장 한계 |
|---|---|
| F | D 또는 C까지 |
| D | C까지 |
| C | B까지 |
| B | A까지 |
| A | S까지는 희귀 조건 필요 |
| S 이상 | 이벤트·아이템·전용 퀘스트 필요 |

즉, 약점을 어느 정도 보완할 수는 있지만, 타고난 전문성은 유지한다.

### 5.3 병종 숙련 경험치

전체 장수 경험치와 별도로, 실제 사용한 병종에 숙련 경험치를 준다.

예:

- 도검병 부대를 이끌고 싸우면 도검 숙련 증가
- 궁병으로 성벽을 공격하면 궁병 숙련 증가
- 공성 병기로 성벽 피해를 주면 공성 숙련 증가
- 수군으로 강·항구 전투를 하면 해상 숙련 증가

이 구조는 플레이어가 장수를 “키우는 방향”을 전투 선택으로 정하게 만든다.

### 5.4 액티브 스킬 레벨

장수의 액티브 스킬도 전투 사용으로 성장한다.

예:

| 스킬 레벨 | 변화 |
|---|---|
| Lv.1 | 기본 효과 |
| Lv.2 | 피해량/회복량/지속시간 증가 |
| Lv.3 | 범위 증가 또는 쿨다운 감소 |
| Lv.4 | 추가 효과 |
| Lv.5 | 고유 연출 또는 강화 효과 |

액티브 스킬 경험치는 “발동”만으로 주면 반복 노가다가 생길 수 있다. 실제 전투 기여와 함께 계산하는 편이 좋다.

예:

- 피해 스킬: 실제 피해량 기준
- 회복 스킬: 실제 회복량 기준
- 방어 스킬: 감소시킨 피해량 기준
- 계략 스킬: 성공한 효과 강도 기준

## 6. 아이템 시스템

용·봉황 같은 이벤트 강적을 잡았을 때 아이템을 얻는 구조를 넣으면 전투 목표가 강해진다.

아이템은 복잡한 장비 파밍보다는, 장수의 개성을 강화하는 희귀 보상으로 두는 것이 좋다.

### 아이템 종류

| 종류 | 효과 |
|---|---|
| 무기 | 특정 병종 공격 보정 |
| 방어구 | 방어·피해 감소 |
| 병법서 | 지력·계략·액티브 강화 |
| 군기 | 부대 사거리·이동·보급 보정 |
| 신수의 유물 | 특수부대 해금 또는 고유 스킬 강화 |

### 아이템 설계 원칙

- 수량은 적게
- 효과는 확실하게
- UI는 단순하게
- 장수당 장착 수 제한

추천:

- 장수당 아이템 1개 또는 2개
- 아이템은 세력 공용 창고에 보관
- 출전 편성 시 장착 변경 가능
- 전투 중 변경 불가

## 7. 이벤트 강적: 용, 봉황, 대호, 대왕오징어

이벤트 강적은 v2의 색다른 방향을 만드는 핵심이다.

삼국지 기반 세계에 살짝 판타지/전설 요소를 얹으면, 일반 삼국지 카피 느낌에서 벗어날 수 있다.

### 이벤트 강적의 역할

- 전투 중립 보스
- 특정 지역의 위험 요소
- 고급 보상 원천
- 플레이어의 성장 목표
- 세력 간 경쟁 목표

### 예시 이벤트

| 이벤트 | 출현 조건 | 보상 |
|---|---|---|
| 용 출현 | 산악/강 근처, 중후반 | 용린 갑옷, 용기병/용 소환권 |
| 봉황 출현 | 숲/성역 근처, 큰 전투 후 | 봉황 깃, 부활/회복 계열 스킬 강화 |
| 대호 출현 | 숲·산지 | 기병/보병 특수 패시브 |
| 대왕오징어 | 대하·해상 | 수군 특수부대 해금 |
| 고대 병기 | 폐허·공방 근처 | 공성 병기 강화 |

### 강적 사냥 흐름

1. 지도에 소문 발생
2. 일정 턴 뒤 강적 출현
3. 주변 부대와 도시를 위협
4. 플레이어와 AI가 사냥 가능
5. 마지막 타격 또는 기여도 기준 보상 지급

### 사냥의 전술성

강적은 단순히 체력 많은 적이면 재미없다. 각자 공략법이 있어야 한다.

| 강적 | 공략 특징 |
|---|---|
| 용 | 광역 피해, 성벽도 공격. 산지 방어 높음 |
| 봉황 | 회복·부활. 짧은 시간에 몰아쳐야 함 |
| 대호 | 빠른 기동, 약한 부대 추격 |
| 대왕오징어 | 해상 장악. 육상 부대 접근 제한 |
| 고대 병기 | 느리지만 공성 피해 강함 |

## 8. 특수부대 획득

특수부대는 연구로 해금하기보다 전장 사건과 거점 점령, 강적 사냥으로 얻는 편이 v2 방향에 맞다.

### 획득 방식

| 방식 | 예시 |
|---|---|
| 거점 점령 | 공방 점령 → 투석기/공성탑 편성 |
| 지역 장악 | 목장 지역 장악 → 철기병 |
| 강적 사냥 | 용 사냥 → 용기병 또는 용 소환 |
| 장수 성장 | 특정 장수의 궁병 숙련 A 달성 → 화랑궁병 운용 |
| 이벤트 선택 | 봉황을 처치하지 않고 계약 → 회복형 특수부대 |

### 특수부대 설계 원칙

- 대량 생산보다 제한 운용
- 일반 병종을 완전히 대체하지 않음
- 강력하지만 보급·회복·재편성 비용이 큼
- 특정 장수와 조합하면 더 강함

## 9. 전투 중심 자원 구조

v2에서는 자원을 줄인다.

추천 자원은 2개다.

| 자원 | 역할 |
|---|---|
| 병력 | 부대 편성·보충 |
| 보급 | 출전 유지·회복·공성 지속 |

금은 제거하거나 “전역 보급 구매 자원” 정도로 후퇴시킨다.

광석·말·코끼리는 숫자로 쌓는 자원이 아니라, 거점/조건으로 바꾼다.

예:

- 목장 보유 중이면 기병 편성 가능
- 상원 보유 중이면 상병 편성 가능
- 공방 보유 중이면 공성 병기 편성 가능
- 광산 보유 중이면 중장비 보급 비용 감소

이렇게 하면 플레이어는 재고 숫자가 아니라 지도 목표를 본다.

## 10. 계략 방향

도시 계략은 줄이고, 야전 계략을 강화한다.

### 야전 계략 예시

| 계략 | 역할 |
|---|---|
| 화공 | 숲·등갑·공성 병기 카운터 |
| 교란 | 적 이동/공격 예약 취소 |
| 혼란 | 다음 진행 동안 반격 불가 |
| 유인 | 적을 특정 방향으로 끌어냄 |
| 보급 차단 | 일정 기간 군량 소모 증가 |
| 허보 | 적 탐지 범위 감소 |
| 수공 | 강 근처 광역 피해 |

계략은 전투 지도를 보며 쓰는 것이 핵심이다. 도시 메뉴에서 텍스트로 누르는 계략은 v2의 중심과 맞지 않는다.

예:

```text
관우
```

## 12. 구현 단계 제안

### Phase 1. 전투 중심 모드 UI

목표:

- 기존 Core를 삭제하지 않고 UI에서 내정 과잉을 먼저 숨긴다.

작업:

- 성 명령 팔레트 축소
- 세율/건설/연구/시장/도시계략/등용 숨김
- 출전/재편성/보충/수리 중심으로 재구성

완료 기준:

- 성을 클릭했을 때 전투 준비 외의 버튼이 거의 보이지 않는다.

### Phase 2. 전투 결과 성장 로그

목표:

- 장수 성장의 체감을 먼저 만든다.

작업:

- 전투 참여 장수 경험치 계산
- 병종 숙련 경험치 계산
- 결과 로그에 성장 표시
- 실제 등급 상승은 아직 보류 가능

완료 기준:

- 싸우면 장수가 성장한다는 느낌이 생긴다.

### Phase 3. 병종 숙련 등급 상승

목표:

- D → C 같은 성장 체계를 실제로 적용한다.

작업:

- 장수별 병종 숙련 상태를 GameState에 저장
- 기존 고정 적성 + 성장 보정 분리
- 숙련 경험치 누적 시 등급 상승

완료 기준:

- 특정 장수가 많이 쓴 병종에서 실제로 강해진다.

### Phase 4. 액티브 스킬 레벨

목표:

- 장수의 고유성이 전투 반복으로 깊어진다.

작업:

- 액티브 스킬 경험치 추가
- 스킬 레벨별 효과 테이블 추가
- 발동 결과에 따른 경험치 증가

완료 기준:

- 같은 장수라도 오래 쓴 장수가 더 강한 액티브를 가진다.

### Phase 5. 거점형 시설 전환

목표:

- 시설을 건설/업그레이드 대상에서 점령 목표로 바꾼다.

작업:

- 논·밭·마을·공방을 지도 거점으로 정의
- 건설/업그레이드 UI 제거
- 거점 보유 효과를 보급/병종/회복으로 연결

완료 기준:

- 시설은 누르는 대상이 아니라 싸워서 차지하는 대상이 된다.

### Phase 6. 이벤트 강적 1종 구현

목표:

- v2의 색다른 맛을 가장 작게 검증한다.

추천 첫 강적:

- 대호

이유:

- 육상 유닛으로 구현하기 쉽다
- 기존 기병/이벤트 유닛 틀을 재사용 가능
- 보상도 단순하다

작업:

- 일정 턴 후 대호 출현
- 중립 적대 유닛으로 이동/공격
- 처치 시 아이템 또는 장수 숙련 보상

완료 기준:

- 플레이어가 “저걸 잡을까 말까”를 고민한다.

### Phase 7. 용·봉황 이벤트 확장

목표:

- 고급 이벤트 강적과 희귀 보상을 넣는다.

작업:

- 용: 광역 공격, 성벽 공격, 용린 보상
- 봉황: 회복/부활, 봉황 깃 보상
- 보상으로 특수부대 또는 액티브 강화 제공

완료 기준:

- 일반 공성전 사이에 강한 이벤트 목표가 생긴다.

## 13. 세이브 데이터 방향

v2에서 새로 필요한 상태:

- 장수 경험치
- 장수 레벨
- 병종별 숙련 경험치
- 병종별 성장 등급
- 액티브 스킬 경험치
- 액티브 스킬 레벨
- 보유 아이템
- 장착 아이템
- 이벤트 강적 상태
- 특수부대 해금 상태

기존 내정 데이터는 당장 삭제하지 않는다. 세이브 호환을 위해 유지하되 UI에서 숨기는 순서가 안전하다.

## 14. 이 방향의 장점

### 1. 기존 작업물을 많이 살린다

전투, 병종, 장수, 공성, 보급, 특수 유닛이 이미 있다. 이걸 버리지 않고 중심으로 올린다.

### 2. 삼국지 카피 느낌에서 벗어난다

도시 내정·세율·등용·연구를 따라가면 삼국지11/13의 그림자가 강하다. 반대로 전장 이벤트, 강적 사냥, 장수 성장, 특수부대 보상은 독자적인 맛이 난다.

### 3. 플레이 목표가 선명해진다

“이번 달에 뭘 개발하지?”보다 “저 성을 어떻게 뚫지?”, “저 용을 잡을 수 있나?”가 더 직관적이다.

### 4. 작은 단계로 검증 가능하다

처음부터 전부 갈아엎지 않아도 된다.

- UI 숨김
- 성장 로그
- 숙련도 상승
- 이벤트 강적 1종

이 순서로 가면 체감 변화를 작게 확인할 수 있다.

## 15. 가장 먼저 결정할 것

다음 작업에 들어가기 전에 아래 4개만 정하면 된다.

1. 내정 버튼을 숨기는 “전투 중심 모드”로 갈 것인가, 기존 모드를 완전히 대체할 것인가?
2. 장수 성장 한계를 어디까지 허용할 것인가?
   - 예: D는 C까지만, A 이상은 이벤트 필요
3. 첫 이벤트 강적은 무엇으로 할 것인가?
   - 추천: 대호
4. 금을 남길 것인가, 보급 자원으로 통합할 것인가?

## 16. 개인적 추천안

가장 좋은 첫 방향은 다음이다.

1. 성 UI에서 내정 버튼을 숨긴다.
2. 전투 결과에 장수 경험치와 병종 숙련 로그를 붙인다.
3. 실제 D → C 상승을 구현한다.
4. 대호 이벤트를 넣는다.
5. 대호 처치 보상으로 “호부” 아이템 또는 기병 숙련 보너스를 준다.

이 순서가 좋은 이유는 간단하다. 코드 전체를 뒤집지 않고도 게임의 감각이 바로 달라진다.

내정은 조용해지고, 전투 결과가 달콤해진다.  
그때부터 플레이어는 성을 키우는 사람이 아니라 장수와 부대를 키우는 사람이 된다.
