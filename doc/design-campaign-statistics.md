# 세력 기록과 전략 점수

시스템 팔레트의 `세력 기록`은 현재 세력 상태와 누적 기록을 한 화면에 모은다.
플레이 시간·게임 일수·보유 도시/항구·누적 점령·전사 병력·생산 병력·주둔/출전/부상 병력·연구 레벨/완료 횟수·성공한 계략·금·군량을 표시한다.
총 15개 지표 중 생산·점령·연구 완료·계략 성공·전사 추정은 저장 파일의 `CampaignStats`에 누적하며,
나머지는 현재 저장 상태에서 계산한다. 플레이 시간은 실시간으로 증가해 저장된다.

전사 병력은 현행 교전 결과가 사망/부상 분리 집계를 직접 보고하지 않으므로
교전 피해와 부상 비율로 산출한 **추정치**로 표기한다. 정확한 사망 수 집계가 전투 엔진에 생기면 교체한다.
점수 가중치는 `data/campaign-score.json`에 둔다. 점수는
`도시×city + 연구 레벨×research_level + 누적 점령×captured_city + 계략 성공×stratagem + (생산+주둔+출전 병력)/troops_per_point − 전사 추정/fatalities_per_point`로 계산하며 0 미만은 0으로 표시한다.
과거 저장에는 통계가 없으므로 누적 항목은 불러온 시점부터 시작한다. 이 사실을 모달에 안내한다.
