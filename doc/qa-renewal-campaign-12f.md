# Phase 18D 12F — 실제 캠페인 화면 검수

상태: 자동 검증 완료, 사용자 화면 검수 대기. Phase 18D 전체를 완료로 표시하지 않는다.
기준: [로드맵](plan-v2-implementation-roadmap.md), [상세 규칙·12E 결과](plan-renewal-movement.md#161-12e-자동-통합-검증-기록-2026-10-08).

## 실행과 판정

`rts-slg-clean-probe`의 `run-maptest.bat`를 실행한다. 자동 검증은 `run-maptest.bat qa`, 비교 모드는 `run-maptest.bat --legacy-movement`다. 비교 모드의 타일 이동은 정상이며 신규 기본 모드와 혼동하지 않는다.

각 케이스는 새 게임에서 시작한다. 검수는 이동 궤적·공격·입성의 실제 화면을 대상으로 한다. 아래 체크는 사용자가 실제 확인한 뒤에만 완료한다.

| 확인 | 절차 | 합격 기준 |
|---|---|---|
| ⬜ | 장안에서 행군으로 열린 평지의 타일 중앙이 아닌 지점 지정; 같은 타일의 다른 지점도 재명령 | 확인 1회로 정확한 목표 적용; 목표가 타일 중앙으로 바뀌지 않음 |
| ⬜ | 두 부대를 서로 다른 남서/남동 목표로 예약 | 두 번째 목표도 확인 1회로 적용; 앞 부대의 목표·경유지가 섞이지 않음 |
| ⬜ | 두 부대를 같은 방향으로 출격 | 아군 중첩을 허용하되 엉뚱한 출구로 바뀌거나 순간이동하지 않음; 적이 막으면 대기 |
| ⬜ | 진행을 두 번 실행하여 14일 관찰 | 연속 보행; 공격턴/진행 종료에 과거 위치 또는 타일 중앙으로 튀지 않음; 행군은 도달 또는 합당한 봉쇄 안내 |
| ⬜ | 전진으로 한중 부근의 적과 접적 | 원래 목표와 교전 정지를 구분; 적이 사라지면 목적지로 재개 |
| ⬜ | 보급·수송·집단군을 각각 이동/복귀 | 동일한 연속 궤적; 복귀 목적 성에 입성; 집단군은 주둔 병종으로 분해 |
| ⬜ | 항구 출항 후 바다의 보이지 않는 지역 지정·아군 항구 복귀 | 해상 경로를 따라 이동하며 육지 관통 없음; 복귀 시 입성 |
| ⬜ | 유적/적 건축물을 공격; 성·항구 점령 | 점유 타일 관통 없음; 이동 마지막 위치에서 공격; 공격 정산 후 즉시 제거/소속 변경·입성 |
| ⬜ | 보루/진법에 입성 후 전투·건축물 파괴 관찰 | 주둔·노출 전환이 올바르고 이동/공격 위치가 흔들리지 않음 |
| ⬜ | 이동 중 진행 종료 후 저장·불러오기·다음 진행 | 정확한 위치·목표·경유지 유지; 처음부터 경로를 반복하지 않음 |
| ⬜ | 실제 화면에서 모션·시야·보급범위·스킬원 관찰 | 이동 토큰과 표시가 일치; 사망/입성은 공격과 구분; 남은 깜빡임은 별도 기록 |

## 문제를 기록하는 방법

도시, 병종, 장수, 모드, 출구 방향, 목표 위치, 몇 번째 진행/날짜인지와 예상/실제 행동을 함께 전달한다. 가능하면 `SanguoSLG.Game/deploy-debug.log`와 해당 저장 슬롯을 보존한다. 단순히 다음 진행을 눌러 증상이 사라진 경우도 실패로 기록한다.

자동 QA는 화면 품질이나 모든 건축물 주둔 조합을 대신하지 않는다. 전체 Core 테스트의 기존 5개 실패도 미해결 상태이며 상세 계획에 목록이 있다. 사용자 합격 확인 후 체크표와 Phase 18D 상태를 갱신한다.
