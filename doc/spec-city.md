## 속성 (City 레코드 = cities.json 스키마, 2026-08-13 구현)

| 필드 | JSON 키 | 의미 | 기본값 |
|---|---|---|---|
| `Id` / `Name` | `id` / `name` | 식별자·이름 | — |
| `Position` | `q`, `r` | 헥사 좌표(axial) | — |
| `Owner` | `owner` | 소유 세력 | — |
| `Provisions` | `provisions` | 군량 비축 — 부대 휴대 보급·수비 군량의 원천 | — |

| `Ore` | `ore` | 광석 비축 — **모든 병력 생산의 하드 캡**(병사 1명당 1) | 0 |

| `Elephants` | `elephants` | 코끼리 비축 — 상병 생산(1000명당 1) | 0 |
| `Region` | `region` | 지역 코드(regions.json) — 자원 산출·맵 배치가 적용받는다 | "" |

- 성벽 연구 5단계: 총 수치의 20/40/60/80/100%. 성 반격 사거리는 무조건 1.
- 함락(수비 0): 근접 공격군 자동 입성 점거, 비근접 공격모드는 멈춤 — design-combat "함락 처리".
