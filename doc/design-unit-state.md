# 설계 노트 — 부대 상태 시스템: 사기·훈련·군량 (2026-08-13 작성 · 2026-08-17 대부분 구현 ✅)

> 전투 축의 마지막 큰 조각. 병력(양)만 있던 부대에 **질(사기·훈련)과 보급(군량)**을 붙인다.
> 피해 공식·행동 규칙은 [design-combat.md](./design-combat.md)·[design-movement.md](./design-movement.md),
> 성 입성/출격·함락은 이동 규칙 7·8과 "함락 처리" 절이 전제다.
> **❓ 표시는 미확정 — 구현 전 사용자 확정 필요.** 확정 수치는 전부 `data/balance.json`으로.

## 왜 셋을 같이 보나

```
훈련도 ──(초기값·저항)──▶ 사기 ──(공/방 보정·패주)──▶ 전투
                          ▲
군량 ──(0이면 급락·이탈)──┘        군량 소모 ◀── 이동·주둔(일수)
```

- **군량**이 기반이다: 일수 기반 소모라 기존 "진행(최대 7일)" 루프에 자연스럽게 붙고,
  사기의 가장 큰 트리거(굶주림)가 된다. 공성전의 **농성·보급 차단**이 여기서 나온다.
- **사기**는 전투 성과·상태의 누적을 공/방 보정과 **패주**로 되돌려주는 되먹임 고리다.
- **훈련도**는 내정(도시)과 전투를 잇는 다리다 — 병력의 질을 만들고, 사기의 바닥을 정한다.

## 구현 순서 (Core 우선 원칙)

### 1단계 — 군량 (기반) ✅ 부대 소모·고갈 구현(2026-08-16)

부대가 군량을 **휴대**하고 야전 일수만큼 소모한다.

| 항목 | 확정 규칙 | 상태 |
|---|---|---|
| 휴대량 | 출전 시 성 비축(`City.Provisions`)에서 떼어 감 — min(**요청량**, 적재 상한 = 한 달치 × 병력 비례, 비축). `DeployService`. **요청량은 출전 GUI의 "군량 일수" 슬라이더**로 지정(0~적재상한 일수, 음수면 상한까지 자동). `DeployRequest.Provisions` | ✅ |
| 소모 | **병력 비례 × 경과일** — 1만 명당 **10/일**. `AdvanceOrchestrator`가 `move.Days`만큼 차감 | ✅ |
| 고갈(0) | 사기 −10(2단계 연동) + 병력 이탈 **5%/일**(굶주림 — 부상 없이 소실) | ✅ |
| 보급 | 보급부대 자동 보충(반경 6, 하루치씩). **성 보급(2026-08-20)**: 아군 성 반경 `city_resupply_radius`(기본 3) 안의 아군 야전 부대는 매 진행 성 비축에서 최대치까지 채운다(성 비축 감소) — 성문 앞 대기·수비 부대가 굶지 않는다. 입성 시엔 대기 병력으로 편입 | ✅ |
| 노획 | 시설 약탈 군량도 **휴대 최대치까지만**(초과 소실). 금은 무제한. 입성 시 성에 예치(2026-08-13 확정) | 확정(약탈 구현 대기) |
| 데이터 | 병종별 `provisions_capacity`(적재). 소모량·이탈률은 Orchestrator 파라미터(10·5) — ❓balance.json 키 승격은 후속 | — |

- **성에서는 군량이 닳지 않는다(2026-08-16 확정)** — 성 비축은 순수 창고. **소모는 오직 야전 부대**가
  짊어진 휴대 군량에서만 일어난다(성 밖). 이전 "수비 군량 소모(농성)" ❓는 폐기.
- **최대 휴대 = 한 달치**. 병종마다 **적재능력**이 달라(`provisions_capacity`, 10k당 ≈ 1개월치):
  보병·궁병 300, 기병·상병 250, 공성 200, 해상 400~500. 병력 비례로 스케일.
- Core: `CombatUnit.Provisions`(−1=미추적=무한)·`ProvisionsCapacity`, `AdvanceOrchestrator`가
  `move.Days`만큼 차감(병력 비례), 고갈 시 이탈(부상 없이 소실). ✅ 구현.

### 편성 모델 (2026-08-16 사용자 확정)

- **일반 부대 = 단일 병종**(삼국지11식) — 적성·지형 보정·병종 공/방 등 기존 전투 시스템 그대로.
- **보급부대만 혼합 병종** — 병종별 구성 목록을 가진 특수형(병력보충·균일 피해의 전제).
- **병종은 모집 시 지정** — 모병/징병 명령에 병종 파라미터, 그때 광석+말/코끼리 소비.
  도시 대기 병력은 **GameState의 별도 목록(GarrisonForce: 도시·병종·병력·훈련도)** —
  City 레코드에 컬렉션을 넣으면 값 동등성(결정론 검증)이 깨져서 분리한다.
- **캠페인 진행 = 7일 고정** — 이동+전투가 그 안에서 자동 연속(design-movement 캠페인 해석).

### 1단계-보급 — 보급부대 (2026-08-16 사용자 확정)

부대 편성에서 **보급부대**를 만들 수 있다. 군량을 대량 수송하고 아군을 자동 보급하는 수레 부대.

- **적재 5배**: 자기 병종 적재능력의 **×5**(`supply_carry_multiplier`)를 휴대한다.
- **이동속도 무조건 1.**
- **혼합병종 편성 가능** → 그래서 **액티브·패시브 스킬 미발동**.
- **공격력·방어력은 병종별 최하 단계 고정 + 연구 미반영**(적성·특기 배수도 없음) — 싸우라고 만든 게 아님.
- **자동 보충(이동 선행)**: 매 진행, 이동보다 **먼저** — 보급부대 주위 **6칸(`resupply_radius`) 이내
  아군 부대** 중 군량이 최대치 미만인 부대에 **하루치씩** 채워준다(보급부대 재고 한도). 저군량 부대
  순서는 id 오름차순(결정론).
- **최대 편성 = 2만**(`supply_max_troops`). 일반 부대(1만)의 2배까지 수송대로 묶을 수 있다.
- **교전 피해는 모든 병종에 균일**하게 분배된다(혼합병종 편성 전제) — 한 병종만 갈려나가지 않는다.
- 구현: 자동 보충 스텝·적재 5배·`IsSupply`는 Core에 ✅. 혼합병종 편성·최하 스탯·2만 상한·균일 피해
  ✅ 구현됨(2026-08-16, 10b — `DeployService.DeploySupply` + `SupplyComponent`):
  - 편성: 병종별 줄(SupplyLine) 목록, 총원 ≤ `supply_max_troops`(2만), 훈련 게이트는 일반 출전과 동일.
  - 스탯: 공/방 = 구성 병종 **최하 기본치**(연구·적성·특기 미반영), 스킬 미발동. 탐지·사거리도
    구성 최소치, **성 공격 불가(RangeCastle 0)** — 문서 미기재분은 구성 최소치로 정함.
  - 적재 = 병종별 적재능력 **가중 평균** × 병력 비례 × 5. 출전 시 성 비축에서 min(상한, 비축) 휴대.
  - 균일 피해: 진행 손실(전투·DoT·굶주림)을 병종 구성에 **병력 비례** 분배(잔여는 병종 코드
    정렬 순서로 1씩 — 결정론). "균일"의 해석 = 머릿수당 균일 — 한 병종만 갈려나가지 않는다.
  - 입성: 병종별 구성 그대로 도시 대기 병력에 편입(훈련도 보존·가중평균 합류).

#### 병력보충 명령 (2026-08-16 사용자 확정 — 10단계 구현)

보급부대는 군량뿐 아니라 **병력 자체를 인접 아군에 충원**한다(둔전병·보충대 개념).

- **조건**: 보급부대 **1칸 이내에 아군**이 있을 때, 별도 명령 **병력보충**으로 대상 부대 지정.
- **발동 시점**: **전투 단계 이후**(그 진행의 교전 정산이 끝난 뒤 충원).
- **같은 병종만**: 보급부대가 보유한 병종 중 대상과 **같은 병종**만 이동한다.
- **1회 이동량**: 보급부대가 가진 그 병종의 **20%**가 대상으로 넘어간다.
- **상한**: 대상 부대의 **총원(MaxTroops)을 넘길 수 없다**(초과분은 이동 안 함).
- ✅ 구현됨(2026-08-16, 10b): `CombatUnit.ReinforceTarget`(상시 명령 — 대상 지정, 조건이 맞는
  진행마다 발동), 오케스트레이터가 교전 정산·사기 이후에 처리. 충원분은 대상 훈련도에
  가중 평균으로 섞이고, 보급부대 구성·총병력이 함께 줄어든다. 보고는 `AdvanceTurn.Reinforced`.

- 하베스트/샌드박스 케이스(후속): 원정군에 보급부대를 붙여 장기 행군에도 안 굶는 것,
  보급부대 없으면 먼 원정에서 고갈 이탈, 전투 후 병력보충으로 전선 부대 재충원.

### 2단계 — 사기 (되먹임) ✅ 구현(2026-08-16)

| 항목 | 확정 규칙 | 상태 |
|---|---|---|
| 범위 | 0~100. 초기값 50 | ✅ |
| 상승 | 교전 우세(피해율<10%) **+5** / 적 부대 격파 **+10** / 무전투 휴식 **+2** — 성 함락 ❓+15는 함락 구현과 함께 | ✅ |
| 하락 | 진행당 **피해율 × 1/2** / **군량 0: −10** — 아군 전멸 목격·혼란/교란 피격 하락은 후속(⏳) | ✅ |
| 효과 | 공/방 배수 `(사기 − 50) × 2/5%` (0이면 −20%, 100이면 +20%) — 기존 배수 층에 한 겹 추가 | ✅ |
| **패주** | 사기 **20 미만** 진입 → 공격 불가 + **가장 가까운 적 반대로 강제 후퇴 2칸**(PushAway). **40 이상**에서 해제(히스테리시스). **패주 시 명령(목표) 취소** — 회복해도 스스로 재진군하지 않고, 재출동은 플레이어가 다시 명령한다(2026-08-20) | ✅ |
| 초기값 | **출전(편성) 시 사기 100** — 성에서 갓 나온 부대는 만땅(입성의 거울) | ✅ |
| 회복 | 성 복귀(입성) 시 **사기 100 + 패주 해제**, 야전 무전투 주둔 시 **+2/진행** | ✅ |
| 연동 | 액티브 **고무(Rally)** → 실제 사기 회복 교체, **사기충천** 하락 저항 재정의 | ⏳ |

- ✅ 구현(2026-08-16): `CombatUnit.Morale`(0~100)·`Routed`. 공/방 배수 = (사기−50)×2/5 → ±20%
  (ApplyDebuffs, 공격·방어 양쪽). 진행 정산 끝(전투 이후)에 증감 일괄: 피해율×1/2 하락, 교전 우세
  +5, 격파 +10, 굶주림 −10, 무전투 휴식 +2. 입성 시 사기 100·패주 해제. 패주: 사기<20 진입·
  ≥40 해제(히스테리시스), 패주 부대는 공격 불가 + 적 반대로 강제 후퇴(PushAway). `MoraleConfig`.
- **진행당 1회 tick(2026-08-20)**: 사기 증감·지속 상태(DoT) tick은 **진행(주) 한 번에 1회**만
  적용된다. 전원 목표 도착 등 야전에 아무 일이 없는 진행은 이동 시뮬이 남은 일수를 한 번에
  소진해(진행이 하루짜리 여러 번으로 쪼개지지 않음), 무전투 휴식이 +2/진행으로만 오른다
  (이전엔 idle 진행이 7번으로 쪼개져 +14가 되던 문제).
- **후속(⏳)**: 고무(Rally)→사기 회복·사기충천 패시브(하락 저항) 배선, 세부 트리거(아군 전멸 목격·
  혼란/교란 피격 사기 하락). MoraleConfig json 배선.

### 3단계 — 훈련도 + 병사 모집 (질·수급)

**내정 전체가 아니라 최소 조각만 앞당긴다(2026-08-13 결정)**: 모병·징병 명령 + 금 차감 +
도시 대기 부대의 훈련 틱 + 투입 가능 판정. 세금·개발·치안 등 나머지 내정은 별도.

#### 모집 (2026-08-13 사용자 확정)

| | 모병 | 징병 |
|---|---|---|
| 비용 | **자원 비용만**(2026-08-13 확정 — 인건비 없음. 광석 1/명 + 말·코끼리) | **금 무료 — 치안 하락 병력 1000당 5**(`conscript_security_drop_per_1000`) ✅ |
| 병력 산출 | 인구 × **1%** × 동원율(유효 정치/100) | 인구 × **3%** × 동원율(모병의 3배 — 많이·빨리 뽑는 대신 아래 페널티) ✅ |
| 초기 훈련도 | **50** ✅ | **0** ✅ |
| 전쟁 투입 | **즉시 가능** ✅ | **불가 — 훈련도 50 도달까지**(출전 게이트 `deploy_min_training`) ✅ |
| 훈련 | 도시 훈련 명령(유효 무력÷10, 7일) — 필요 없음(이미 50) ✅ | **훈련 명령으로 50까지 올려야 투입**(자동 상승 없음, 2026-08-17 확정). 이 훈련 부담이 징병의 실질 페널티 ✅ |

- 치안(Security)은 이 조각에서는 **수치 필드만** 둔다(징병이 깎는 대상). 치안이 낳는
  효과(반란·수입 감소 등)와 회복 수단은 내정 본편에서 설계한다.
- **생산 자원(2026-08-13 확정)**: 모병·징병 공통으로 **광석**이 들고(1/명, 전 병력 생산의 하드 캡),
  **기병은 말**(3명당 1), **상병은 코끼리**(1000명당 1)가 추가로 든다 — 자원이 없으면 그 병종은
  생산 불가. 발행 시 즉시 예약(차감), 완료일에 병력 지급. ✅ 구현.

- **보충 희석**: 기존 부대에 병력을 합치면 훈련도는 **가중 평균, 반올림**
  (예: 훈련 80 × 6000 + 신병 50 × 4000 = 68). ✅ 구현.
- **징병 투입까지**: 훈련도 0 → 훈련 명령(유효 무력÷10/7일)으로 50까지. 무력 100 장수 단독이면
  회당 +10 → 5회(35일), 무력 70이면 회당 +7 → 8회(56일). 그동안 수행 장수가 잠긴다.

#### 훈련도 효과 ✅ 공/방 배수 구현(2026-08-16)

| 항목 | 계획 | 상태 |
|---|---|---|
| 범위 | 0~100 | 확정 |
| 효과 | **A안 확정·구현**: 공/방 배수 (훈련−50)×1/5 → ±10%(ApplyDebuffs) | ✅ |
