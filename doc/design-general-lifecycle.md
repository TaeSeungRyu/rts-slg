# 설계 노트 — 장수 라이프사이클 v2

> v2 전투 중심 전환 기준 문서다. 기존 충성·급여·배신·포로교환 축은 제거하고, 장수 수급은 **세력·도시형 위인 해금**, **등용**, **성 함락**, **세력 멸망**으로 단순화한다. 탐색은 인재 수급에서 분리해 자원·아이템·이벤트 단서 보상으로 재정의한다. 확률 판정은 모두 시드 `IRandomSource`로 처리해 테스트와 리플레이 결정론을 유지한다.

## 1. 제거된 축

다음 기능은 v2 기준에서 제거한다.

| 제거 대상 | 처리 |
|---|---|
| 충성 | `General.Loyalty`, `generals.json`의 `loyalty`, UI 충성 표시 제거 |
| 급여 | 월 급여 지출과 미지급 충성 하락 제거 |
| 배신 | 월말 배신·재야화 이벤트 제거 |
| 포상 | 자금 포상으로 충성을 올리는 흐름 제거 |
| 포로교환 | 외교 기능에서 제거 |

이 제거의 목적은 장수 관리 부담을 줄이고, 전투·출전·성 공략에서 보상이 발생하도록 흐름을 압축하는 것이다.

## 2. 장수 상태

장수는 크게 세 상태 중 하나다.

| 상태 | 의미 |
|---|---|
| 주둔 | 특정 세력 소속이며 특정 도시에 배속 |
| 출전 | 특정 세력 소속이며 야전 부대 선봉/부관으로 출전 중 |
| 재야/미배속 | 세력 배속이 없음 |
포로 상태는 사용하지 않는다. 전투 패배·부대 전멸을 이유로 장수를 제거하거나 억류하지 않는다.

### 야전 패배·복귀 시 귀환

- 부대가 전멸하거나 패배하면 선봉·부관은 해당 부대의 `OriginCityId`로 귀환한다.
- 원 소속 성을 잃었거나 더 이상 자기 세력 도시가 아니면 현재 위치에서 가장 가까운 자기 세력 도시로 귀환한다. 거리 동률은 도시 ID 오름차순이다.
- 자기 세력 도시가 하나도 없으면 세력 멸망 규칙을 적용하되 장수를 조용히 삭제하지 않는다.
- 사용자가 복귀 명령을 내린 경우에는 지정한 복귀 도시로 들어가며 다른 도시로 임의 변경하지 않는다.
- 장수의 업무·부대 참조는 귀환 정산에서 한 번만 해제한다. 같은 장수가 두 도시에 존재하거나 전체 장수 목록에서 사라져서는 안 된다.

## 3. 성 함락 시 장수 획득

성벽 0 + 수비 0 상태에서 근접 공격모드 부대가 있으면 성이 함락된다.

함락된 성에 주둔하던 옛 소유 세력 장수는 장수별로 판정한다.

| 상황 | 처리 |
|---|---|
| 30% 성공 | 점거 세력에 합류하고 함락된 성에 주둔 |
| 실패 | 옛 소유 세력의 가장 가까운 보유 도시로 후퇴 |

후퇴 도시는 함락 성 위치 기준 헥사 거리 최소, 동률이면 도시 id 오름차순으로 정한다.

## 4. 세력 멸망 시 장수 획득

함락 결과로 옛 소유 세력의 보유 도시가 0개가 되면 세력이 멸망한다. 이때 남은 소속 장수 전체를 장수 id 오름차순으로 판정한다.

| 상황 | 처리 |
|---|---|
| 70% 성공 | 점거 세력에 합류하고 함락된 성에 주둔 |
| 점거 세력 합류 실패 후 70% 성공 | 점거 세력이 아닌 타 세력 도시로 편입 |
| 둘 다 실패 또는 타 세력 도시 없음 | 재야/미배속 |

타 세력 편입 도시는 함락 성 위치 기준으로 점거 세력이 아닌 가장 가까운 도시를 고른다. 동률이면 도시 id 오름차순이다.

## 5. 등용

등용은 탐색과 별개다.

| 항목 | 규칙 |
|---|---|
| 대상 | 정찰된 적 성 주둔 장수, 출전중 적 부대 장수 |
| 성공 확률 | 수행 장수 정치 수치 `%` |
| 성공 효과 | 성 주둔 장수는 수행 도시로 합류, 출전중 장수는 부대째 전향 |
| 실패 효과 | 추가 페널티 없음 |
| 소요일 | 도시 계략과 같은 거리 비례 공식 |

군사 예측 UI는 이 확률을 미리 보여주는 조언 역할만 하며 실제 판정은 완료 시점의 시드 난수로 결정한다.

## 6. 세력·도시형 위인 잠금 해제와 탐색

인재 수급은 탐색에서 분리한다. 미등록 장수를 랜덤 탐색으로 찾는 대신 시나리오가 세력·도시·지역별 위인/고유 장수 후보 목록을 미리 정한다. 후보가 된 뒤의 영입 조건은 해금년도·영입 포인트·금으로 통일한다.

| 장수 수급 | 역할 |
|---|---|
| 성 함락 | 해당 성 소속 장수 30% 획득 |
| 세력 멸망 | 남은 장수 70% 획득, 미획득 장수는 70% 타 세력 편입 |
| 세력형 위인 | 시나리오가 해당 세력의 영입 후보로 등록 |
| 도시형/지역형 위인 | 시나리오가 도시·지역 분류가 붙은 영입 후보로 등록 |
| 유랑 위인 | 원 세력 멸망 후 다른 세력의 후보 목록으로 이동 |
| 문과시험·무과시험 | 장수가 부족한 세력이 도시별 1년 1회 범용 장수를 생성하는 보조 수급 |

위인 상태는 다음 흐름을 따른다.

| 상태 | 의미 |
|---|---|
| 잠김 | 해금 가능 년도에 도달하지 않았거나 포인트·금이 부족함 |
| 해금됨 | 해금년도에 도달했고 포인트·금을 지불해 영입할 수 있음 |
| 소속됨 | 어느 세력에 합류 완료 |
| 유랑 | 원 세력이 멸망해 잠긴 세력형 위인이 세계에 재배치됨 |
| 제외 | 시나리오상 등장하지 않거나 이벤트로 제거됨 |

세력이 멸망하면 이미 소속된 장수는 기존 70% 규칙을 따른다. 아직 잠긴 세력형 위인은 삭제하지 않고 유랑 상태로 바꾼다. 유랑 위인은 다른 세력의 인재 영입 목록으로 이동한다. 세력형·도시형·지역형은 후보 분류와 시나리오 목록 구성용으로 유지한다.

탐색은 인재를 제외하고 다음 3개 축으로 유지한다.

| 탐색 대상 | 계획 |
|---|---|
| 금/군량 | 초반 운영 보조 자원 획득 |
| 이벤트 단서 | 신수, 유물, 호족, 도적/반란, 재난, 소문 이벤트 발견 |
| 아이템 단서 | 장수 성장·스킬 숙련·특수부대 보상으로 연결 |

탐색 이벤트는 위인의 별도 업적 조건을 올리지 않고 세력 공용 영입 포인트를 지급한다.

### 6.1 인재 영입 포인트 (2026-09-29 개정)

기존 위인 영입의 세력 수·특정 장수·업적·능력치 등 동적 조건은 제거한다. 시나리오가 어떤 인재를 어느 영입 목록에 노출할지만 정하고, 목록에 노출된 인재의 실제 영입 조건은 아래 세 가지뿐이다.

1. 해금 가능 년도 도달
2. 세력 공용 영입 포인트 충족 및 소비
3. 금 비용 충족 및 소비

인재별 데이터에는 `recruit_point_cost`, `recruit_gold_cost`, 기존 `unlock_year`를 둔다. 영입 포인트는 도시가 아니라 **세력별 단일 자원**이며 저장/불러오기에 포함한다.

| 획득 활동 | 영입 포인트 | 중복 방지 기준 |
|---|---:|---|
| 유적 점령 | +100 | 해당 세력이 해당 유적에 최초로 이름을 등록할 때 1회. 재점령 반복 보상 없음 |
| 탐색 완료 | +3 | 명령 1회 완료당 1회. 결과 없음도 정상 완료면 지급 |
| 담당 업무 7일 완료 | +5 | 장수 1명·7일 결산당 1회 |
| 생산 투입 | +5 | 500명 생산 부대가 대상 시설에 도착해 채집 상태로 전환될 때 1회 |
| 도시 계략 수행 | +5 | 성공·실패와 무관하게 결과가 확정될 때 1회. 취소·무효 명령은 미지급 |

- 포인트나 금이 부족하면 영입 버튼을 비활성화하고 부족량을 표시한다.
- 영입 확정 시 포인트와 금을 원자적으로 차감하고 인재를 세력에 편입한다. 어느 하나라도 실패하면 둘 다 차감하지 않는다.
- AI도 같은 잔액과 비용을 사용하며 무료 영입 경로를 두지 않는다.
- 세력형·도시형·지역형 표시는 분류와 시나리오 후보 목록 구성용으로 유지하되 목록에 노출된 뒤 추가 업적 조건으로 다시 잠그지 않는다.

### 6.2 문과시험·무과시험

위인 해금은 고유 장수 수급이고, 시험은 범용 장수 수급이다. 시험은 장수가 너무 적은 세력이 게임에서 말라 죽지 않도록 하는 안전장치로 둔다.

규칙:

- `인재` 명령에 `문과시험`, `무과시험`을 둔다.
- 도시별 1년 1회 실행 가능하다.
- 처음에는 실행 가능 상태이며, 완료일 기준으로 다음 실행 가능일을 저장한다.
- 주최 장수와 소비금 100~1,000금을 선택한다.
- 7일 후 신규 장수 1명을 생성한다.
- 주최 장수 능력치의 90%가 생성 장수 능력 상한이다.
- 주최 장수의 병종 적성보다 한 단계 낮은 등급이 생성 장수 적성 상한이다.

확률:

- 1,000금을 써도 상한값 도달 확률은 1%로 제한한다.
- 소비금은 상한값 자체의 확률보다 평균 품질을 올리는 방향으로 작동한다.
- 상한에서 0, -1, -2, -3~-5, -6~-10, -11~-20, -21 이하 구간을 뽑고, 소비금이 높을수록 위쪽 구간 가중치를 올린다.
- 병종 적성도 같은 패턴으로 판정한다. 주최 장수의 병종별 적성을 한 단계 낮춘 값을 생성 상한으로 잡고, 상한, 상한 -1단계, 상한 -2단계, 상한 -3단계, 최저 등급 구간 중 하나를 뽑는다.
- 1,000금 기준 병종 적성 상한 도달 확률은 1%로 제한한다. 소비금이 높을수록 상한 근처 확률을 올리고, 낮을수록 최저 등급 비중을 높인다.
- 문과시험은 지력/정치와 궁병·공성·보급/내정형 적성에, 무과시험은 무력과 보병·기병·궁병 등 전투형 적성에 가중치를 준다.

생성 장수는 시나리오 고유 장수와 구분되도록 `generated` 상태 또는 별도 태그를 가진다.

## 8. 구현 검증 기준

- `General.Loyalty`와 관련 JSON/밸런스 키가 없다.
- 월 급여·배신 이벤트가 없다.
- 위인/인재 영입은 해금년도·영입 포인트·금만 사용한다.
- 야전 패배·복귀 시 장수가 원 소속 성 또는 최근접 아군 성으로 귀환하며 포로 상태가 생성되지 않는다.
- 함락 시 주둔 장수 30% 합류 규칙이 동작한다.
- 세력 멸망 시 남은 장수 70% 합류, 미획득 장수 70% 타 세력 편입 규칙이 동작한다.
