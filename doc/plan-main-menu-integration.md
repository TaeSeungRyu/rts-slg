# 메인 화면 통합 계획 (Phase 21E)

상태: 21E-0~6 코드 연결 및 자동 QA 완료. 21E-7 실제 창 왕복·동영상 재생 검수 예정.

구현 기록: `run.bat`은 여섯 항목의 메인 메뉴를 연다. 배경은 시간에 따라 천천히 움직이는 셰이더이며, `SanguoSLG.Game/assets/video/intro.ogv`가 존재하면 영상을 먼저 재생하고 완료 또는 건너뛰기 후 메뉴를 표시한다. 영상 파일은 아직 제공되지 않았다. 새 게임은 시작 전 시나리오를 검증하고 숨은 세력을 제외한다. 불러오기는 메인에서 20개 슬롯을 열고 정상 슬롯을 선택한 뒤 캠페인을 만든다. 캠페인의 시스템 팔레트에서 시작 화면으로 복귀할 수 있다. 지도·시나리오 편집기의 시작 화면 복귀는 미저장 변경을 확인한다.

2026-11-03 메뉴 검수 보완: 에디터와 새 게임·불러오기 화면의 복귀 버튼을 `← 메인 메뉴`로 통일했다. 지도 편집 중에는 화면 상단 `← 지도 목록`으로 돌아가고 목록에서 메인으로 복귀한다. 메인에서 에디터에 진입하면 창 닫기 요청도 다시 받는다. 새 게임에는 공식 시나리오 6개를 카드로 보여주며 임시 제목 `새 시나리오`와 중복 기본 항목은 시작 목록에서 제외한다. 시작/불러오기 뒤 캠페인이 구성되는 동안 로딩 화면을 유지하고, 게임이 열리면 군주가 있는 거점에서 줌인한다. `--menulaunchqa`는 실제 메뉴 시작 경로에서 시나리오 적용, 로딩 화면과 카메라 위치를 자동 확인한다.

## 목표와 화면 이동

`run.bat`으로 게임 창을 한 번만 연다. 메인 화면, 시나리오·세력 선택, 저장 슬롯 선택, 네 종류의 에디터, 캠페인은 동일한 Godot 프로세스와 창 안에서 씬을 전환한다. 여기서 '한 화면'은 창을 여러 개 띄우지 않는다는 뜻이며, 각 기능을 하나의 거대한 씬에 넣을 필요는 없다.

| 메인 항목 | 진입 화면 | 닫기·취소·뒤로가기 |
| --- | --- | --- |
| 새 게임 시작하기 | 시나리오 → 시작 가능한 세력 → 난이도 → 캠페인 | 시작 전에는 메인으로 복귀 |
| 저장된 게임 시작하기 | 메인에서 저장 슬롯 20개 조회 → 선택한 슬롯의 캠페인 복원 | 슬롯 선택 취소 시 메인 유지 |
| 신규장수 등록 | 기존 장수 생성 화면 | 메인으로 복귀 |
| 장수 에디터 | 기존 장수 편집 화면 | 메인으로 복귀 |
| 지형 에디터 | 지도 목록 → 지도 편집 화면 | 목록의 ×와 편집 뒤로가기 모두 메인으로 복귀 |
| 시나리오 에디터 | 시나리오 목록·편집 화면 | 닫기·뒤로가기 모두 메인으로 복귀 |

에디터로 직접 들어가는 기존 BAT 파일은 개발·검수용으로 유지한다. 같은 닫기 버튼이라도 메인에서 진입했으면 메인으로 복귀하고, 독립 BAT로 진입했으면 종료한다. 메인으로 복귀할 때는 목록을 다시 읽어 방금 저장한 지도·시나리오·장수를 새 게임 선택 화면에 반영한다.

## 현재 구현과 보완 지점

- 메인 화면과 캠페인, 장수 생성·편집, 지도·시나리오 편집기는 같은 Godot 프로세스에서 씬으로 전환한다. 독립 BAT의 종료 동작은 유지한다.
- 지도 목록의 ×는 메인에서 왔을 때 메인으로 복귀한다. 불러오기는 메인에서 슬롯 선택을 완료한 뒤 캠페인을 만든다.
- 메인 복귀 시 시작 요청과 선택 상태를 초기화한다. 네 종류의 에디터는 미저장 변경을 감지해 저장·버리기·계속 편집을 선택하게 한다.

## 데이터 경계

새 게임은 선택한 시나리오가 참조하는 지도 버전과 세력·장수·거점 배치를 읽는다. `run-newmap.bat`의 무작위 QA 배치를 호출하지 않는다. 불러오기는 선택 슬롯에 저장된 지도 스냅샷과 진행 상태를 복원한다. 에디터에서 원본 데이터를 고쳐도 진행 중이거나 저장된 게임이 바뀌면 안 된다. 지도에서 시나리오가 참조하는 성·항구를 삭제하지 못하게 하는 기존 보호 규칙도 메인 경유 편집에서 유지한다.

## 구현 순서

1. **21E-0 이동 기반:** 메인 출발/독립 BAT 출발을 구분하는 진입 정보를 정리하고 같은 창 씬 전환과 복귀 상태 초기화를 검증한다.
2. **21E-1 새 게임:** 시나리오·시작 세력·난이도 선택과 사전 유효성 검사를 완성한 뒤 실제 캠페인을 생성한다.
3. **21E-2 불러오기:** 저장 슬롯 조회와 선택을 메인 화면으로 옮기고 유효한 슬롯을 고른 경우에만 캠페인을 생성한다.
4. **21E-3~4 장수 화면:** 생성·편집 후 저장 결과를 반영하며 메인으로 복귀한다.
5. **21E-5 지도 화면:** 지도 목록의 ×와 편집 화면의 뒤로가기를 출처에 따라 처리하고 미저장 변경을 확인한다.
6. **21E-6 시나리오 화면:** 닫기·뒤로가기와 미저장 변경 처리를 통일한다.
7. **21E-7 통합 QA:** 모든 경로를 실제 창에서 왕복하고 저장·재진입·캠페인 시작을 확인한다.

## 통합 QA 기준

| 상황 | 기대 결과 |
| --- | --- |
| 각 에디터에 메인에서 진입 후 닫기, 뒤로가기, 목록의 × | 프로세스와 창이 유지되고 메인 화면 표시 |
| 지도 목록에서 아무 지도도 선택하지 않고 × | 메인 복귀; 게임 종료 없음 |
| 독립 BAT에서 에디터 닫기 | 해당 도구만 종료 |
| 에디터 변경 후 저장하지 않고 나가기 | 저장·버리기·계속 편집 중 선택; 취소 시 데이터 유지 |
| 에디터 저장 후 메인에 복귀해 다시 진입 | 새 목록이 표시되고 이전 선택 상태가 새 작업에 섞이지 않음 |
| 빈 슬롯, 손상된 슬롯, 정상 슬롯으로 불러오기 | 앞의 둘은 메인에서 오류 표시; 정상 슬롯만 캠페인 생성 |
| 지도·시나리오 수정 후 새 게임과 기존 저장 게임 실행 | 새 게임만 수정된 원본을 사용; 저장 게임은 저장된 스냅샷 사용 |
| 새 게임 시작 후 7일 진행, 메인 복귀 후 다른 시나리오 시작 | 지도·세력·장수 상태가 시나리오 사이에 섞이지 않음 |

작업 완료 판정은 버튼 표시만이 아니라 위 이동 경로, 복귀, 데이터 격리와 독립 BAT 호환성까지 실제 창에서 확인한 뒤 내린다.

자동 검증: Game 빌드, `--startmenuqa`, `--generalcreatorqa`, `--generaleditorqa`, `--editmapqa`, `--scenarioeditorqa`, 저장 슬롯 Core 테스트 5건 통과. 전체 Core 테스트는 기존 AI·시나리오 관련 실패 141건으로 통과하지 못했다. 실화면 왕복, 실제 영상 재생, 저장 게임과 새 게임의 장기 데이터 격리는 후속 검수 대상이다.
