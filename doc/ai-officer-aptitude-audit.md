# AI 출전 장수 적성 점검 (2026-10-25)

## 현재 선발 규칙

- 공세 묶음은 병종별로 현재 출전 가능한 장수를 적성 내림차순, 무력 내림차순으로 선발한다 (`AiOffensePlanner.TryBundle/DeployLine`). 지원 병종 자체도 남은 장수의 최고 적성을 우선해 순회한다.
- 빈 거점 점령, 해상 공세, 공성 증원, 수성 출격, 지원군, 유적 공략도 해당 병종 적성을 먼저 비교한다. 집단군은 보병·궁병·공성 적성의 평균을 사용한다.
- 적성 S 이상인 장수가 다른 임무 중이거나 이미 출전했거나, 해당 병종에 S 이상인 장수가 없으면 남은 장수 중 최고 등급이 C일 수 있다. 일부 부대는 성에 남길 장수 수 조건도 적용된다.

## 확인 결과와 후속 QA

현재 주요 전투 출전 경로에서 C 장수가 같은 병종의 출전 가능한 S 장수를 제치고 선봉에 배치되는 경로는 발견되지 않았다. C 선봉을 다시 발견하면 출전 시점의 성, 병종, 주둔 장수의 병종별 적성 및 담당·출전 상태를 함께 기록해 재현한다. 이는 데이터 부족이나 장수 예약 여부를 구분하는 데 필요하다.
