# 개발 계획 05 — UI 셸 (삼국지11 지향, 아트 최소)

> 사용자 피드백: 현재 비주얼이 "저사양·초기 2000년대" 수준. 최소 삼국지11 수준의 GUI 형태를 원함.
> 결론: 엔진(Godot .NET)은 충분히 가능. 병목은 아트. **아트 투자는 병행 결정**하되, 우선
> **아트 없이도 Godot 테마로 만들 수 있는 UI 골격**(상태바·패널·정보창·명령 메뉴)을 세워 "게임 UI다운" 인상을 확보한다.

## 목표 재정의 (사용자 명확화)

**일러스트(그림)는 불필요.** 원하는 것은 **화면 구성·레이아웃·정돈된 UI 완성도**다. 즉 무장 초상·채색 맵 같은 아트가 아니라, **깔끔한 패널·상태바·정보창·타이포·여백·정렬**이 목표. 이건 아트 소싱 없이 Godot 테마/레이아웃만으로 달성 가능하다.

## 확정된 설계 결정

- **UI는 Godot `Control` + 테마**로 구성(StyleBox 프레임, Pretendard 폰트, 일관된 색·여백·정렬). 이미지 아트 의존 없음
- **Core 연결**: Godot 앱에 `GameState` + `TurnEngine`을 물려 날짜·자원이 UI에 실시간 반영(턴 진행 버튼)
- **분리 원칙 유지**: UI는 Game 계층. Core 규칙 변경 없음
- 맵 아트(삼국지11급 지형·초상)는 별도 아트 전략에서 결정 — 이 계획 범위 밖

## 단계 세분화 (각 단계 스크린샷 확인 🔍)

- [x] Step 1 — HUD 골격 + 테마 🔍: 상단 상태바(연/월·세력 자금), "다음 달" 버튼(→ AdvanceMonth로 날짜·자금 갱신), 하단 정보 패널 자리 — 렌더 확인
- [ ] Step 2 — 선택 정보 패널 🔍: 도시/유닛 클릭 선택 → 패널에 정보(도시명·소유·군량 / 유닛)
- [ ] Step 3 — 무장 정보 패널 🔍: 오6능력치(통솔·무력·지력·정치·매력)를 정돈된 표/바로 표시(초상 없음)
- [ ] Step 4 — 명령 메뉴 골격 🔍: 이동/내정 등 명령 버튼 레이아웃(동작은 이후 연결)
- [ ] Step 5 — 프레임·팔레트 폴리시 🔍: 장식 StyleBox·색·레이아웃 정리로 완성도
- [ ] Step 6 — 마무리 + 회고: 헤드리스 빌드 점검, 스크린샷 회고, 아트 전략 결정
