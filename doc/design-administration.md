# 설계 노트 — 내정 (2026-08-13 작성, 설계 초안)

> CLAUDE.md 진행 순서 2단계. 전투 축(이동·전투·공성)이 안정된 지금, 그 축을 받치는
> 내정부터 정의한다 — **도시가 금·군량·병력을 만들어 부대에 공급하는 흐름**.
> 부대 쪽 소비(군량 소모·사기·훈련 효과)는 [design-unit-state.md](./design-unit-state.md),
> 모집(모병/징병) 확정 규칙도 그 문서 3단계 참조. **❓ = 미확정, 구현 전 사용자 확정 필요.**

## 범위 (1차)

전투 축이 요구하는 것만 담는다. 외교·인사·이벤트·상인은 후속.

```
도시: 금 ── 세금(수입) ──▶ 모병 비용, (후속: 개발·시설)
      군량 ── 수확(수입) ──▶ 부대 휴대 군량, 수비 군량
      인구 ──▶ 모집 가능 병력의 원천
      치안 ──▶ 징병이 깎음. 낮으면 페널티(후속: 반란·수입 감소)
      대기 부대 ──▶ 훈련(모병만)·징병 훈련도 자동 상승·투입 판정
```

## 시간 축 — 일(日) 단위로 통일 (2026-08-13 확정)

전투 진행(1~7일), 계략 예약(2일), 징병 훈련(7일 +10), 액티브 게이지(5일)가 전부
**일 단위**다. 내정도 일 단위 세계 시계 하나에 태우고, 주기만 달리한다:

| 틱 | 주기 | 내용 |
|---|---|---|
| 일 틱 | 1일 | 부대 군량 소모(unit-state 1단계), ❓치안 자연 회복 |
| 훈련 틱 | 7일 | 징병 부대 훈련도 +10, ❓도시 훈련 명령 효과 |
| 수입 틱 | 30일(월) | 금·군량 = **성 규모 기본치 + 시설(논·밭·마을) 가산**, 인구 성장(✅), ❓자원 산출(광석·말·코끼리) |

- 기존 `balance.json`의 `monthly_tax_per_city: 100`이 수입 틱의 시작점.
- **확정(2026-08-13)**: A안 — 명령은 자유 시점, 시간은 진행 버튼으로만 흐른다
  (전투 하베스트와 동일한 감각). 월 명령 페이즈는 두지 않는다.

## 도시 속성 (1차)

| 속성 | 역할 | 초기값/범위 |
|---|---|---|
| 금 `Gold` | 자원 구매(시장), (후속) 개발·시설 | **도시별 소유(2026-08-13 확정)** — 수송·약탈이 전략 요소 |

| 인구 `Population` | 모집 상한의 원천 — 모집 1명 = 인구 −1. **최대치: 소성 10만·중성 25만·대성 50만, 성장: 매월 말 +1% × 치안/100(내림)** (2026-08-13 확정, ✅ 구현) | 확정 |
| 치안 `Security` | 0~100 ❓. 징병 시 대폭 하락(❓폭). 낮을 때 페널티는 후속 | ❓ |
| 대기 부대 | 성 안 수비대(입성 부대 포함)와 신규 모집 부대가 머무는 곳 — 훈련·보충·재보급 지점 | 구현됨(_garrison) |
| 광석 `Ore` | **모든 병력 생산에 필요**(2026-08-13 사용자 확정) | 아래 "생산 자원과 시장" |
| 말 `Horses` | **기병 생산에 필요** | 〃 |
| 코끼리 `Elephants` | **상병 생산에 필요** | 〃 |

## 생산 자원과 시장 (2026-08-13 사용자 확정)

- **산출**: 광석·말·코끼리는 **지역에 따라 자동으로 생산되는 곳과 안 되는 곳이 있다**.
  어느 지역이 무엇을 내는지는 맵 데이터에서 지정(❓제안: 말=북방(량주·병주·유주),
  코끼리=남중, 광석=산지 도시. regions.json에 특산 필드 추가). ❓생산량/틱.
- **시장**: 산출이 없는 도시는 내정 시스템의 **시장에서 금으로 구매**한다.

| 자원 | 소모 비율 | 시장 단가 | 1000명당 자원 비용(시장가) |
|---|---|---|---|
| 군량 | — (구매 품목, 2026-08-13 추가) | ❓제안: 1금 = 4량 | — |
| 광석 | 병사 1명당 1 | 1금 | 1,000금 |
| 말 | 병사 3명당 1 | 6금 | 약 2,000금 (334마리) |
| 코끼리 | 병사 1000명당 1 | **3,000금** | 3,000금 |

- 1000명 생산 총액(시장가): 보병류 1,000 / 기병 3,000(3×) / 상병 4,000(4×) —
  성능 순서(보병 < 기병 < 상병)와 비용 순서가 일치한다.
  **조정 이력**: 코끼리 단가 원안 1,000금은 상병(공14·방14)이 기병(3×)보다 싸지는
  역전이 생겨 3,000금으로 조정(2026-08-13, 사용자 위임).
- ❓시장 판매(자원→금 환전) 허용 여부, ❓시장가 변동(수급) 여부 — 1차는 고정가 구매만 제안.

## 시설 건설 — 논·밭·마을 (2026-08-13 사용자 확정, 수치는 제안)

성 주변 타일에 시설을 건설해 수입을 늘린다. **수입 = 성 규모 기본치 + 건설된 시설의 가산**.
지형 타일(Paddy·Farm·Village)이 이미 있어 맵 표현은 타일 배치로 그대로 이어진다.

**기본 수입(월, 성 규모별) — ❓제안:**

| 등급 | 금(세금) | 군량(수확) |
|---|---|---|
| 소성 | 100 | 500 |
| 중성 | 200 | 1,000 |
| 대성 | 300 | 2,000 |

- 기존 `monthly_tax_per_city`(일괄 100)를 성 규모별 기본치로 대체한다.

**시설 가산(월, 시설 1개당) — ❓제안:**

| 시설 | 효과 | 건설 비용·기간 ❓ |
|---|---|---|
| 논(Paddy) | 군량 +300 | 300금 · 30일 |
| 밭(Farm) | 군량 +150 | 200금 · 20일 |
| 마을(Village) | 금 +50 | 400금 · 30일 |

**건설 수 제한(성 규모별 총 슬롯, 자유 조합) — ❓제안:** 소성 3 / 중성 6 / 대성 9.

**공방(Workshop) — 성별 1개 한정 (2026-08-13 사용자 확정):**

| 기능 | 내용 |
|---|---|
| 공성 병기 생산 게이트 | **투석기·공성탑·충차는 공방이 있는 도시에서만 생산** — 공성 전력의 전략 거점화 |
| 병종 연구 거점 | 병종 공/방 연구(9단계)는 공방에서 진행 — 공방을 잃으면 연구 중단 |
| 성벽 수리 가속 | 성벽 회복 속도 +❓50% (내정 스킬 축성과는 합산) |

- 위 슬롯(논·밭·마을)과 **별도 1칸**. ❓건설 비용·기간(제안: 800금 · 60일).
- 시설 파괴·약탈 규칙 동일 적용 — 공방 파괴 노획은 ❓금 환산.
- 배(해상 병종) 생산 게이트는 항구(Port 지형)로 별도 — 후속.

**시설 파괴·약탈 (2026-08-13 사용자 확정):**

- 적 시설을 파괴하면 **시설 가치의 N%를 노획**한다 — 논·밭은 **군량**으로,
  마을은 **금**으로. ❓N 기본값과 기준액(제안: 건설 비용의 50% — 논 150·밭 100은
  군량 환산 ❓배율, 마을 200금). `balance.json` 키로.
- **군량 노획은 부대 휴대 최대치까지만**(초과분은 소실 — 불태운 것). 휴대 한도는
  unit-state 1단계의 군량 휴대량과 같은 값.
- **금 노획은 무제한**(부피 없음).
- **복귀 예치**: 노획물을 지닌 부대가 아군 성에 입성하면 **그 성 비축에 자연스럽게
  합산**된다(군량→Provisions, 금→Gold) — 기존 입성 훅(EnteredCastle)에 붙는다.
- ❓연동 후보: 전투 패시브 약탈(plunder) 보유 부대는 N% 가산.
- 구현: 내정 ②(수입 틱)에서 기본치+가산 계산, 건설 명령은 ③과 함께, 파괴·노획은
  전투 축 연결(⑤)에서. 도시 상태에 시설 목록(종류·위치) 추가.

## 세율 (2026-08-13 사용자 확정, ✅ 구현)

성 명령 팔레트의 **세율** 설정(0~최대 50%, 기본 20%). 매월 말 정산에서 **금·군량 수입
전체에 배율(세율/20%)**로 곱해지고, 민심(치안으로 통합 — 2026-08-13 확정)을 움직인다:

| 세율 | 수입 배율 | 치안 변동/월 |
|---|---|---|
| 0% | 0× | +4 |
| 10% | 0.5× | +2 |
| 20% (기본) | 1.0× | 0 |
| 30% | 1.5× | −2 |
| 40% | 2.0× | −4 |
| **50% (최대)** | 2.5× | **−10** (가혹 — 크게 하락) |

- 치안은 인구 성장(+1%×치안/100)에 물려 있어, 고세율은 단기 수입 ↔ 장기 성장의 트레이드오프.
- balance 키: `tax_rate_base`(20)·`tax_rate_max`(50)·`tax_max_security_penalty`(10). 세율 설정
  명령 UI는 ③에서.

## 명령 실행 공통 규칙 (2026-08-15 사용자 확정)

명령 팔레트의 **모든 명령은 수행 장수 1명 + 기간이 필요**하다.

- **수행 장수는 기간 동안 잠긴다** — 그 사이 다른 명령·출전 불가. 장수 수가 곧 도시의 내정
  처리량이 되어, 인재 확보·배치가 핵심 전략이 된다(삼국지11식).
- **효율 = 명령당 산출량**(기간은 고정). 효율을 정하는 능력치는 명령별로 다르다.
- 해당 내정 스킬(모병관·교관·상재 등)이 그 능력 위에 추가로 곱해진다.
- **진행 중 명령**은 세계 시계에 얹혀, 완료일(시작일 + 기간)에 효과가 정산된다.

| 명령 | 기간 | 효율 능력 | 전제 | 산출·효과 |
|---|---|---|---|---|
| 모병 | 7일 | 정치 | — | 정치 비례 병력(자원·인구 1%·월상한 캡 안). 훈련도 50, 즉시 투입 |
| 징병 | 7일 | 정치 | — | 정치 비례 병력(인구 3% 캡), 치안 하락. 훈련도 0(7일 +10 자동) |
| 훈련 | 7일 | 무력 | — | 무력 비례 훈련도 상승(모병 부대·교관 스킬 가산) |
| 건설 | 30일 | 정치 | **정치 > 70** | 논·밭·마을·공방 1채 완공(슬롯 캡 안) |
| 세율 | 7일 | — | — | 7일 뒤 새 세율 적용(효율 무관) |
| 시장 | 7일 ❓ | — | — | 금으로 자원 구매(교역 할인). 즉시 구매 예외 여부 ❓ |
| 보충 | 7일 ❓ | 정치 ❓ | — | 대기 부대 병력 합류(훈련도 가중 평균) |

- ❓ 효율 계수(제안): 모병 병력 = 정치 × 15 /7일, 징병 = 정치 × 15(인구 3% 캡),
  훈련도 상승 = 무력/10 /7일, 징병 치안 하락 = 병력 1000당 −N. 전부 balance.json 키.
- ❓ 시장·보충이 정말 장수·기간을 요구하는가(즉시 처리 예외)? — 구현 시 확정.

## 내정 심화 — 재미·다양성 (2026-08-15 설계, A 확정 / 나머지 제안)

명령이 "장수 1명·수치 하나"로 끝나지 않게, **이미 있는 데이터**(장수 출신지·내정 스킬·치안)를
살려 결정의 결을 만든다.

### A. 주관·보좌 — 명령당 장수 2명 (확정 컨셉, 전투 선봉·부관의 내정판)

- 각 명령에 **주관(필수) + 보좌(선택)** 장수를 지정.
- **유효 능력 = 주관 능력 + 보좌 능력 × 보좌계수(❓ 50%)**. 두 장수의 **내정 스킬은 모두** 적용
  (전투에서 선봉·부관 스킬이 둘 다 붙는 것과 같은 규칙).
- **두 장수 모두 기간 동안 잠긴다** → "장수 2명을 한 명령에 몰아 크게 vs 두 명령에 나눠"가
  매번의 고민. 장수가 귀할수록 무겁다.
- 예: 모병에 정치 90(주관)+70(보좌) → 유효 125, 산출 대폭↑. 대신 7일간 둘 다 묶임.

### B. 출신지 보너스 — 고향에서 일하면 잘한다 (확정 2026-08-15, 배지 UI 필수 조건)

- 장수가 **자기 출신 지역**(general.region = city.region) 도시에서 명령하면 효율 +❓20%.
- 이미 넣은 출신지 데이터(마초=량주, 김유신=신라, 노부나가=오와리…)가 그대로 살아난다.
- 재미: "금마초를 서량에 두면 서량이 산다" — 장수 배치에 지리·역사 맥락이 생긴다.
- **GUI 필수 조건(2026-08-15 확정)**: 보너스가 숨은 함정이 되지 않도록, 명령 배정 화면에서
  주관·보좌가 고향이면 **"🏠 [지역] 출신 +N%" 배지**를 반드시 표시하고, 장수 토큰에 고향 마커를
  둔다. 이 배지가 없으면 B를 켜지 않는다(위키 지식이 되어버림) — Core 계산은 지금 넣되
  효과 발동은 배지와 한 몸. design-ui.md에 요구사항 등록.
- 성격: 지배적 메커닉이 아니라 **향신료**(정치도 좋으면서 그 지역 출신인 장수 배치를 가르는
  동점 브레이커). 결정을 무겁게 하지 않으면서 지리·역사 맛을 얹는다.

### C. 치안 구간 효과 — 세율↔치안을 실질 긴장으로 (제안)

세율(수입↔치안)이 실제로 무섭도록, 치안을 구간으로 나눠 효과를 준다:

| 치안 | 효과 |
|---|---|
| 80~100 | 인구 성장 정상 + **수입 +10%**(호황) |
| 50~79 | 정상 |
| 20~49 | 수입 −10% · **도적 출현 위험**(시드 난수) |
| 0~19 | **반란 위험**(도시 중립화·이탈) · 수입 −30% |

- 세율 50% 남발 → 치안 급락 → 도적·반란 → 도시 상실. 위험/보상이 눈에 보인다.
- 도적·반란은 시드 기반 `IRandomSource`로만(결정론 규칙 4).

### D. 역사 콤비 시너지 (제안, 데이터 테이블)

- 특정 장수쌍을 주관·보좌로 함께 쓰면 추가 보너스. 예: 유비+제갈량, 손책+주유, 조조+순욱,
  김유신+김춘추, 노부나가+히데요시. `data/combos.json`.
- 재미: 숨은 콤비를 찾는 맛 — 명단 152명이 관계망으로 살아난다.

### E. 충성도 (제안, 큰 변경 — 후반 단계 권장)

- 장수별 충성도(용어집 `Loyalty`). 낮으면 등용에 넘어가거나 배신. 포상·출신지·연승으로 ↑,
  박봉·패전으로 ↓. 등용(외부 인재 영입)과 짝.
- **주의**: 장수 상태가 가변이 된다(현재 roster는 불변). 충성도는 roster가 아니라 GameState의
  세이브 상태로 둔다. 규모가 커 로드맵 후반(등용·외교와 함께) 권장.

> **적용 계획**: **A(주관·보좌)는 확정** — 7단계 명령 계층에 바로 반영. B·C는 데이터·리스크가
> 작고 효과가 커 7~8단계에 함께. D는 데이터만 만들면 되니 여유될 때. E는 후반(외교·등용) 단계.

## 부대와의 연결 (이미 있는 훅)

- **출전**: 성 비축에서 군량을 떼어 휴대(unit-state 1단계) — 케이스의 `Unit()` 생성이 아니라
  도시에서 부대가 나오는 흐름으로 바뀐다.
- **입성**: `EnteredCastle` 훅(구현됨) — 재보급·훈련 재개·보충이 여기 붙는다.
- **함락**: 점거 시 도시 소유 전환(구현됨 — `_castleOwner`) → 도시 속성(금·군량·인구)도 넘어간다 ❓약탈 규칙.

## 구현 순서 제안

1. **도시 상태 + 세계 시계** ✅ 구현됨(2026-08-13) — `City`에 금·치안·인구·광석·말·코끼리·
   지역 코드 추가. `GameState`가 일 단위(1개월=30일, 1년=360일, 연·월·일은 절대 일수에서 유도),
   `WorldEngine.AdvanceDays`가 매월 말(30일) 세금을 **도시 금고**로 징수. 도시 id 순 처리(결정론).
   Sandbox 검산: 12개월 → 도시당 +1,200.
2. **수입 틱** ✅ 구현됨(2026-08-13) — 매월 말: 금 = 성 규모 기본치(100/200/300) + 마을 ×50,
   군량 = 기본치(500/1000/2000) + 논 ×300 + 밭 ×150, 자원 산출(산출 도시만: 광석 +500·
   말 +100·코끼리 +2). 전부 balance.json 키. 시설은 City의 개수 필드(위치는 Game 몫).
3. **명령 계층** ✅ 1차 구현(2026-08-15) — CityCommand + CommandService(발행: 검증·자원 예약·
   장수 잠금) + CommandEfficiency(주관+보좌×50%+고향 +20%, 정수 연산) + WorldEngine 완료일 정산.
   모병·징병(자원·인구 캡·훈련도 50/0·치안 하락)·훈련(무력/10)·건설(정치>70·슬롯·30일)·세율.
   병력은 도시 대기 풀(Troops·TrainingLevel, 보충 희석은 가중평균). command-balance.json.
   **후속**: 병종별 모집(말·코끼리), 내정 스킬(모병관·교관) 적용, 시장·탐색·등용·도시 계략,
   태수 상주 패시브, 월 누적 상한, 장수↔세력·도시 배속.
4. **치안** — 필드 + 징병 하락 + ❓자연 회복. 페널티는 후속.
5. **전투 축 연결** — 출전 시 군량 휴대(unit-state 1단계와 접합), 하베스트에 도시 패널 표시.

각 단계마다 xUnit 검산 + Sandbox 대량 일수 검증(1000턴 밸런스의 전신).
