# 설계 노트 — 전투 액티브 스킬 목록 (초안, 2026-08-10)

> 스킬 메커니즘(5일 충전·공격 대체·부대당 1발동)은 [design-skill.md](./design-skill.md),
> 산출 순서는 [design-combat.md](./design-combat.md), 연동 시각효과는 [design-effect.md](./design-effect.md) 참조.
> **수치는 초안이다** — Sandbox 튜닝 후 확정(미결).

## 공통 규칙

- 액티브는 **야전 5일 충전 → 자동 발동**, 발동 시 그 교전의 **행동을 대체**한다. 부대당 1발동(선봉 우선),
  1회 소비 또는 성 복귀로 초기화([design-skill.md](./design-skill.md)).
- **4유형**과 발동 시 동작:
  | 유형 | 개수 | 발동 시 |
  |---|---|---|
  | **타격형** | 10 | 일반 공격을 **특수 공격(강타·관통 등)으로 대체** — 피해를 준다 |
  | **계략형** | 10 | 공격을 **디버프/상태 부여로 대체** — 시각효과와 연동(아래) |
  | **방어형** | 5 | **일반 공격은 그대로 하고**, 이번 교전 **방어 효과가 추가로 발휘** |
  | **회복형** | 5 | **일반 공격은 그대로 하고**, 병력·사기 **회복 효과가 추가로 발휘** |
  - 즉 타격·계략은 공격을 *바꾸고*, 방어·회복은 공격을 *유지한 채 효과를 더한다*(2026-08-10 사용자 정정).
- **스탯 연동(위력이 스탯에 비례)**: 타격·방어형 = **무력**, 계략·회복형 = **지력**.
  (타격=무력·계략=지력은 2026-08-10 확정. 방어=무력·회복=지력은 내 제안 — 바꿔도 된다.)
  이로써 지금 "용도 추후"였던 무력·지력이 전투에서 살아난다(지장 vs 용장).
- **계략형은 [design-effect.md](./design-effect.md) 12종 시각효과와 연동** — 효과가 곧 디버프의 표현이다.
  붕괴(Tear/Shatter)는 유닛 전용 효과라 **대상이 유닛일 때만**.
- **국가(중/한/일)는 이름·연출 톤에만** 반영한다. 기계는 공용 풀 하나(같은 스킬을 국가별로 복제하지 않음).
  전설 장수 전용 **시그니처**(예: 이순신 학익진)는 그 캐릭터 고유로 별도(추후).
- **경험 단계 없음** — 패시브와 달리 액티브는 스킬별 고정값(희소·강력·부대당 1이라 단계까지 얹지 않음).
- 결정론: 난수 없음. 지속 효과(N교전/N진행)는 결정 상태값으로만.

## 타격형 (10) — 무력 연동

| 이름 | 코드 | 효과(대체 공격) |
|---|---|---|
| 무쌍(無雙) | `Peerless` | 단일 대상에 평타 **×2.5**(무력 비례↑) 폭딜 |
| 일섬(一閃) | `Flash` | 방어(df) **무시** 관통 강타 |
| 분쇄(粉碎) | `Crush` | 건물·성벽에 **추가 피해**(공성 특화) |
| 맹호격(猛虎擊) | `TigerStrike` | 큰 단일 피해 + 이번 교전 적 **반격 -50%** |
| 연환격(連環擊) | `ChainStrike` | **2연타**(합산 대폭) |
| 파갑(破甲) | `ArmorBreak` | 적 df **절반 무시** + 피해 |
| 돌파(突破) | `Breakthrough` | 돌격 강타 — **기병 분류면 위력↑** |
| 참(斬) | `Reap` | 적 **병력 비례 처형**(적이 많을수록 총량↑, 상한) |
| 포화(砲火) | `Barrage` | 원거리(사거리2) 강타 — **공성·궁 분류 증폭** |
| 일기당천(一騎當千) | `OneManArmy` | **무력 차를 크게 반영**하는 초강타 |

## 계략형 (10) — 지력 연동 · 시각효과 연동

| 이름 | 코드 | 연동 효과 | 디버프 |
|---|---|---|---|
| 화계(火計) | `FireAttack` | `Fire` | 지속 **화상 피해**(몇 진행) |
| 수공(水攻) | `FloodAttack` | `Flood` | 대상 **이동·공격 약화** + 피해 |
| 혼란(混亂) | `Confuse` | `Daze` | 대상 **공격 -X%**(몇 교전) |
| 이간(離間) | `Discord` | `Confusion` | 대상 **적성·스킬 효과 무효/저하** |
| 역병(疫病) | `Plague` | `Flies` | 대상 **지속 병력 감소** |
| 공포(恐怖) | `Terror` | `Skulls` | 대상 **사기 저하 → 공/방 하락**(사기 시스템 추후) |
| 독무(毒霧) | `PoisonMist` | `Bubbles` | 대상 **지속 독 피해** |
| 연막(煙幕) | `Smokescreen` | `Haze` | 적 **원거리 명중 저하** / 자군 **은폐(받는 피해↓)** |
| 폭파(爆破) | `Detonate` | `Burst` | **즉발 광역 피해**(다대일 전원) |
| 붕괴(崩壞) | `Sunder` | `Shatter`/`Tear`(유닛 전용) | 대상 **df 급감** + 파괴 연출 |

## 방어형 (5) — 무력 연동 · 일반 공격 유지 + 방어 효과

| 이름 | 코드 | 효과(이번 교전, 공격은 정상 수행) |
|---|---|---|
| 철벽(鐵壁) | `IronWall` | 받는 피해 **-50%** |
| 반격진(反擊陣) | `Riposte` | 받는 피해 **-30%** + 받은 피해 **일부 반사** |
| 귀갑진(龜甲陣) | `TurtleFormation` | 방어 대폭 + **다대일 포위 피해 추가 경감** |
| 회피술(回避術) | `Evasion` | **원거리(사거리2) 피해 대폭 감소/무효** |
| 사수(死守) | `HoldTheLine` | 성·항구 주둔 시 **성벽 방어 강화(붕괴 지연)** |

## 회복형 (5) — 지력 연동 · 일반 공격 유지 + 회복 효과

| 이름 | 코드 | 효과(공격은 정상 수행) |
|---|---|---|
| 응급치료(應急) | `FieldMedic` | 병력 **15% 회복** |
| 정비(整備) | `Regroup` | 병력 **25% 회복**(대신 재충전이 길다) |
| 고무(鼓舞) | `Rally` | **사기 회복·상승**(사기 시스템 추후, 잠정 공/방 소폭↑) |
| 보급(補給) | `Resupply` | 병력 즉시 소폭 + **몇 진행 지속 회복** + 군량 |
| 불사(不死) | `SecondWind` | 병력 **50% 이하일 때 큰 회복**(위기 특화) |
