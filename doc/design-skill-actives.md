# 설계 노트 — 전투 액티브 스킬 목록 (초안, 2026-08-10)

> 스킬 메커니즘(5일 충전·공격 대체·부대당 1발동)은 [design-skill.md](./design-skill.md),
> 산출 순서는 [design-combat.md](./design-combat.md), 연동 시각효과는 [design-effect.md](./design-effect.md) 참조.
> **수치는 초안이다** — Sandbox 튜닝 후 확정(미결).

## 공통 규칙

- 액티브는 **야전 5일 충전 → 자동 발동**, 발동 시 그 교전의 **행동을 대체**한다. 부대당 1발동(선봉 우선),
  1회 소비 또는 성 복귀로 초기화([design-skill.md](./design-skill.md)).
- **3유형**과 발동 시 동작(계략은 별도 시스템으로 분리 — [design-stratagem.md](./design-stratagem.md)):
  | 유형 | 개수 | 발동 시 |
  |---|---|---|
  | **타격형** | 10 | 일반 공격을 **특수 공격(강타·관통 등)으로 대체** — 피해를 준다 |
  | **방어형** | 5 | **일반 공격은 그대로 하고**, 이번 교전 **방어 효과가 추가로 발휘** |
  | **회복형** | 5 | **일반 공격은 그대로 하고**, 병력·사기 **회복 효과가 추가로 발휘** |
  - 즉 타격은 공격을 _바꾸고_, 방어·회복은 공격을 _유지한 채 효과를 더한다_(2026-08-10 사용자 정정).
- **스탯 연동(위력이 스탯에 비례)**: 타격·방어형 = **무력**, 회복형 = **지력**.
  (타격=무력은 2026-08-10 확정. 방어=무력·회복=지력은 내 제안 — 바꿔도 된다.)
  이로써 지금 "용도 추후"였던 무력·지력이 전투에서 살아난다(지장 vs 용장 — 지력의 주 무대는 계략).
- **국가(중/한/일)는 이름·연출 톤에만** 반영한다. 기계는 공용 풀 하나(같은 스킬을 국가별로 복제하지 않음).
  전설 장수 전용 **시그니처**(예: 이순신 학익진)는 그 캐릭터 고유로 별도(추후).
- **경험 단계 없음** — 패시브와 달리 액티브는 스킬별 고정값(희소·강력·부대당 1이라 단계까지 얹지 않음).
- **대상 조건이 붙은 액티브는 조건 불충족 시 발동 보류** — 예: 분쇄(건물 전용)가 유닛과 교전하면
  발동하지 않고 그 교전은 평타로 넘어가며 게이지를 유지한다(소비 안 함). 계략의 캔슬/보류와 같은 결.
- 결정론: 난수 없음. 지속 효과(N교전/N진행)는 결정 상태값으로만.

## 위력 연동 공식 (초안, 2026-08-10)

액티브 위력은 **부대 선봉 장수**의 스탯에 비례한다(적성과 같은 기준). 아래 표의 기본값은
**무력/지력 60**을 기준으로 하고, 실제 값은 연동 배수를 곱한다:

```
M_무 = clamp(1 + (무력 − 60) / 100, 0.5, 1.5)      (무력 60 → 1.0, 100 → 1.4, 30 → 0.7)
M_지 = clamp(1 + (지력 − 60) / 100, 0.5, 1.5)
```

- 타격·방어형은 **M\_무**, 회복형은 **M\_지**를 곱한다.
- 피해 배수는 "**정상 공격 피해 대비**" 배수다(정상 산출 피해 × 배수 × M\_무). df 하락·반격 감소 등은
  산출식([design-combat.md](./design-combat.md))의 해당 자리를 수정해 반영한다.
- 감소율·회복률에도 M을 곱하되 표의 **상한**을 넘지 않는다. 수치는 전부 초안.

## 타격형 (10) — 무력 연동

값은 무력 60 기준, 실제 = 값 × M\_무.

> **하향(2026-08-10)**: 한 번의 "진행"으로 부대가 통째로 사라지지 않고 최소 2진행은 버티도록
> 배수를 전반적으로 낮췄다(무쌍 ×2.5→×1.6 등). 방어·회복형은 데미지가 아니라 생존을 돕는 쪽이라 그대로.

| 이름               | 코드           | 효과(무력 60 기준)                                                                         |
| ------------------ | -------------- | ------------------------------------------------------------------------------------------ |
| 무쌍(無雙)         | `Peerless`     | 단일 대상 피해 **×1.6**                                                                    |
| 일섬(一閃)         | `Flash`        | 이번 타격에 대상 **df −30%** + 피해 ×1.0(관통)                                             |
| 파갑(破甲)         | `ArmorBreak`   | 대상 **df −20%를 3진행 지속** + 피해 ×1.1                                                  |
| 분쇄(粉碎)         | `Crush`        | **건물 대상 피해 ×2.0**. 대상이 건물이 아니면 **발동 보류**(그 교전 평타, 게이지 유지)     |
| 맹호격(猛虎擊)     | `TigerStrike`  | 피해 **×1.4** + 이번 교전 적 **반격 −50%**                                                 |
| 연환격(連環擊)     | `ChainStrike`  | **2타** 각 ×0.8(다대일이면 서로 다른 2대상, 단일이면 같은 대상 2타)                        |
| 돌파(突破)         | `Breakthrough` | 피해 **×1.3**(기병 분류면 **×1.8**)                                                        |
| 참(斬)             | `Reap`         | 대상 **병력의 5% 즉시 처형**(상한 10%, atk 무관·건물 제외)                                 |
| 포화(砲火)         | `Barrage`      | 사거리2 피해 **×1.4**(공성·궁 분류면 **×1.8**)                                             |
| 일기당천(一騎當千) | `OneManArmy`   | 피해 **×(1.4 + (내 무력 − 적 선봉 무력)/70)**, 범위 ×1.1~×2.2 (자체 무력식 — M\_무 미적용) |

## 방어형 (5) — 무력 연동 · 일반 공격 유지 + 방어 효과

값은 무력 60 기준(감소율 × M\_무, 상한 −75%). 공격은 정상 수행.

| 이름           | 코드              | 효과(이번 교전)                                            |
| -------------- | ----------------- | ---------------------------------------------------------- |
| 철벽(鐵壁)     | `IronWall`        | 받는 피해 **−30%**                                         |
| 반격진(反擊陣) | `Riposte`         | 받는 피해 **−15%** + 받은 피해의 **15% 반사**(반사율 고정) |
| 귀갑진(龜甲陣) | `TurtleFormation` | 받는 피해 **−20%**(다대일로 포위당하면 **−40%**)           |
| 회피술(回避術) | `Evasion`         | **원거리(사거리2) 피해 −30%**(근접 피해엔 효과 없음)       |
| 사수(死守)     | `HoldTheLine`     | 성·항구 주둔 시 **성벽 피해 −50%**(붕괴 지연)              |

## 회복형 (5) — 지력 연동 · 일반 공격 유지 + 회복 효과

값은 지력 60 기준(회복률 × M\_지, 상한 40%). 회복은 **최대 병력** 대비 %. 공격은 정상 수행.
회복은 **부상 풀에서만** 되돌린다(피해의 70%만 부상 — design-combat.md "피해 구성"). 부상 풀을
초과하는 회복은 풀까지만 적용된다.

| 이름           | 코드         | 효과                                                    |
| -------------- | ------------ | ------------------------------------------------------- |
| 응급치료(應急) | `FieldMedic` | 병력 **5% 회복**                                        |
| 정비(整備)     | `Regroup`    | 병력 **15% 회복**                                       |
| 고무(鼓舞)     | `Rally`      | **공/방 +10% 3진행**(확정 — 사기 시스템 폐지 2026-08-21) |
| 보급(補給)     | `Resupply`   | 즉시 **5%** + **3진행간 매 진행 5%** 회복 + 군량 소량   |
| 불사(不死)     | `SecondWind` | 병력 **20% 회복** — **방 +10% 3진행** (희귀: 1~2명만 보유) |

## 하위 액티브 (저급 무장, 4종)

하위 무장용 저효과 액티브. 위 20종(상위 무장)과 **충전·발동 규칙은 동일**(5일 충전·1회 소비·
성 복귀 초기화·부대당 1발동)하되 위력만 작다. 값은 스탯 60 기준, 실제 = 값 × M(타격·방어=M*무, 회복=M*지).

| 이름       | 코드        | 유형 | 효과(스탯 60 기준)                           |
| ---------- | ----------- | ---- | -------------------------------------------- |
| 강타(强打) | `HeavyBlow` | 타격 | 단일 대상 피해 **×1.3**                      |
| 연타(連打) | `DoubleHit` | 타격 | **2타** 각 ×0.6(합 ×1.2)                     |
| 방비(防備) | `Brace`     | 방어 | 이번 교전 받는 피해 **−20%**(공격 정상 수행) |
| 수습(收拾) | `Patch`     | 회복 | 병력 **8% 회복**(공격 정상 수행)             |

## 적용 우선순위 (2026-08-10 사용자 정의)

한 전투 페이즈에서 여러 부대(양측·다대일)가 각자 액티브를 발동하면, **유형 우선순위**대로
적용한 뒤 피해를 정산한다:

> **방어 > 회복 > 계략 > 공격(타격)**

1. **방어형** — 이번 교전 피해 경감·반사 태세를 **먼저** 세운다.
2. **회복형** — 병력·사기를 회복한다(피해 정산 전이라 늘어난 병력으로 교전에 임한다).
3. **계략**(별도 시스템 — [design-stratagem.md](./design-stratagem.md)) — 명령 페이즈에서 시전한
   디버프(공/방 하락·지속 피해 등)가 여기서 반영된다 → 이어질 피해 계산에 반영.
4. **공격(타격형)·일반 공격** — 위에서 세운 방어·회복·디버프가 모두 반영된 상태로 **마지막에** 정산.

즉 방어·회복·계략이 상태를 만든 뒤, 타격/일반 공격이 그 위에서 판정된다. 이 순서는
[design-combat.md](./design-combat.md) "전투 페이즈 발동"의 스킬 반영(4단계)→피해 판정(5단계)
사이에 적용된다.
