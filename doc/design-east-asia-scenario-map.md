# 동아시아 시나리오 기본 지형

## 범위와 자료

- 경도 91°E~133°E, 위도 18°N~54°N을 100×70 육각형 격자(7,000타일)로 근사한다. 서부 고원 대부분을 잘라 중국 중심부가 화면을 더 많이 차지하도록 한다.
- 중국 본토·대만·몽골·한반도와 일본의 서쪽 일부만 포함한다. 일본의 동부는 화면에 넣지 않는다.
- 해안선과 섬의 기본 윤곽은 공개 자료 [Natural Earth 1:50m land](https://www.naturalearthdata.com/downloads/50m-physical-vectors/)를 사용한다. 해안과 국경은 게임용 해상도로 단순화한다.
- 산맥·하천·숲·사막은 게임 진행을 위한 손 배치/근사다. 실제 고도·식생·하천 중심선을 정밀하게 복제한 지도가 아니다.
- 촉 진입로는 [UNESCO의 촉도 설명](https://whc.unesco.org/en/tentativelists/5994)과 [한중 지역 지형 설명](https://hzdqw.hanzhong.gov.cn/hzdfz/dlwz/202106/bdf66a6595874ac29d713ef9f205b8d3.shtml)을 참고해 성도 분지·한중 분지, 북쪽 진령산맥·남쪽 대파산맥 사이의 좁은 통로로 단순화한다. 이 지도에서 험산(`rock_mountain`)은 모든 부대가 통과하지 못하며, 촉도/장강 협곡 방향만 산악 통로로 남긴다.
- 삼국지 시리즈의 광역 지형 구분을 참고하되, 게임 원본 지도·이미지를 복제하지 않는다. 지형은 기존 게임의 평야·숲·산악·험산·사막·하천·연안·해역 종류에 맞춘다.
- `land_routes`는 주요 거점 간 육상 이동선을 지형 통행 규칙과 이동비용으로 계산한 검수용 경로다. 평야·숲·산악·사막·소하천만 통과하며, 모든 병종이 통과하지 못하는 험산과 바다는 제외한다. 무당비군의 산 지물 특별 통행은 이 일반 부대 경로에 반영하지 않는다. 모든 통행 가능 칸을 도로로 그리는 방식이 아니라, 대표적인 육상 연결을 얇은 선으로 표시한다.

## 파일과 검수

| 파일 | 역할 |
| --- | --- |
| `SanguoSLG.Game/assets/maps/east-asia-map.json` | 지형 종류별 행 데이터와 경위도 범위. 시나리오 배치의 기초 자료 |
| `tools/gen_east_asia_map.py` | Natural Earth 해안선과 게임용 지형 배치를 재현하는 생성기 |
| `SanguoSLG.Game/EditMap.tscn` | 독립 지형 검수 화면 |
| `run-editmap.bat` | Game 빌드 후 검수 화면 실행. `qa` 인자로 데이터/씬 검증 |

검수 화면에서 상단 라디오 버튼으로 지형을 강조하고 `육상 동선` 체크로 대표 이동선을 켜고 끈다. 마우스 휠로 확대·축소, 드래그로 이동, 타일 클릭으로 대략적인 경위도와 지형을 확인한다. 이번 단계는 **지형 조회용**이다. 도시·항구·관문·세력 배치, 타일 편집과 시나리오 저장은 다음 시나리오 작업에서 연결한다. 기존 `run-maptest.bat`의 지도와 캠페인 세이브는 이 파일로 바뀌지 않는다.

`rows`는 화면의 열/행 순서로 저장한다. 캠페인의 axial `HexMap`은 직사각형 q/r 경계이므로 이 데이터를 바로 `data/map.json`으로 복사하지 않는다. 시나리오 연결 시 열/행→axial 좌표 변환과 지도 밖 칸을 제외하는 유효 타일 마스크가 필요하다.
