# 로드맵 — 전체 현황과 단계 계획 (2026-08-15 작성, 살아있는 문서)

> **이 문서가 진행의 기준이다.** 단계가 끝나면 ✅로 바꾸고, 계획이 바뀌면 여기를 고친 뒤
> 진행한다. 규칙 원본은 각 design/spec 문서(CLAUDE.md 문서 맵), 여기는 순서와 현황만.

## ✅ 완료 (구현 + 테스트 잠금, 393개)

**전투 축 (Core + 하베스트 16케이스)**
- 이동: 탐지·추격·사거리 정지(그 날 완료 후)·국소/측면 우회·지형 패널티·결정론
- 전투: 피해 공식·병종 공/방·지형 보정(이동 후 위치)·연구 곡선·적성 배수
- 특기: 패시브 버킷(조건부)·액티브(게이지 5일, 선봉 우선)
- 계략 11종: 즉발·지속(DoT)·디버프·혼란·교란(강제 후퇴)·수공·광역·시전 사거리·정화
- 공성: 성벽→붕괴 2단계·반격 사거리 1·성 접적 정지(선착 부대 단독 공성)
- 성 출입: 입성=이동 마지막 스텝(수비 합류·복귀 초기화)·출격 게이트 스텝·복귀 중단·함락 점거(근접 입성·비근접 멈춤)
- 장수: 병종별 통솔 6등급, 선봉·부관 부대 조립, **명단 152명**(중국 112·한국 30·일본 10, 출생·출신지·소개), 내정 스킬 13종 데이터
- 도구: `run-combattest.bat`(전투 16케이스), `roster.bat`(장수 명감)

**내정 ①②③-1차 (Core + Sandbox 검산)**
- 도시 상태: 금(도시별)·치안·인구·광석/말/코끼리·시설 수(논밭마을·공방)·산출 플래그·세율·지역 코드
- 일 단위 세계 시계(1월=30일), 월말 정산: 수입(성 규모 기본치+시설 가산)×세율 배율, 자원 산출, 인구 성장(치안 비례·등급별 최대치), 세율→치안 변동
- 명령 계층(1차): 모병·징병·훈련·건설·세율 — 수행 장수+기간+잠김, 효율=주관+보좌×50%+고향, 완료일 정산. 도시 대기 병력 풀(훈련도 가중평균). 모집 병력 = 인구×상한%×동원율(정치/100 — 2026-08-17 개선). 취소 명령 없음
- 소유·배속 기반: 장수→세력·주둔 도시(GeneralPosting), 명령은 그 도시 소유 세력 소속·주둔 장수만. postings.json 시작 배치. 출전·AI·등용의 키스톤
- 경제 밸런스 ~5배 rescale + 인구 충원율 수입 배율(바닥 50%~100%) + 치안 자연 회복·저치안(<20) 수입 −30% + 부대 군량(경과일 소모·고갈 이탈) + 보급부대(적재 5배·자동 보충)
- 사기(공/방 ±20% 배수·전투 성과 증감·패주 적반대 후퇴) + 훈련도 공/방 ±10% 배수

**캠페인 축 (10a·10b — Core + Sandbox 데모)**
- 진행 = 7일 고정(CampaignEngine.AdvanceWeek — 이동+전투 자동 연속·내정 한 시계), 병종별 모집(말·코끼리 자원 게이트)·대기 병력(GarrisonForce)
- 출전(DeployService): 대기 병력+선봉·부관 → 야전, 군량 휴대(적재 상한·비축 차감), 훈련도 50 게이트, 입성 시 대기 편입+장수 복귀
- 보급부대(DeploySupply): 혼합 병종·2만 상한·최하 스탯·적재 가중×5, 균일 피해(병력 비례), 병력보충(20%·총원 상한)
- 캠페인 공성(CampaignSiege): City.Wall(등급별 3000/6000/10000), 성벽 타격→수비 병력 비례 손실→성 반격(사거리 1만)

## 🔧 설계 확정 — 구현 대기 (수치 ❓는 각 문서 참조)

- **내정 ③ 명령 후속**: 내정 스킬 적용(모병관·교관·인망·병참·축성·교역), 시장 구매(교역 할인), 탐색·등용(판정 ❓), 도시 계략 6종(이간=충성 저하 포함, 거리 비례 소요일 ❓), 태수 상주 패시브, 월 누적 상한
- **부대 상태 후속**: 징병 훈련 방식 확정(⚠️ 문서-구현 불일치 — design-unit-state), 고무(Rally)→사기·전투 성장·MoraleConfig json
- **전투-내정 연결(10b 남은 것)**: 함락 처리(소유 전환·자원=전부 승계+인구 페널티 ❓폭), 약탈(시설 N%❓·휴대 한도·입성 예치), 도시 계략 배선

## 단계 계획 (앞으로 — 위에서 아래로)

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **7. 내정 ③ 명령** ✅ 1차 | 명령 계층(CityCommand): 모든 명령 = **수행 장수 + 기간**, 장수는 기간 동안 **잠김**, 효율 = 능력별 산출량(모병·징병·건설·세율=정치, 훈련=무력). 모병 7일/징병 7일/훈련 7일/건설 30일(정치>70)/세율 7일. 진행 중 명령을 세계 시계에 얹어 완료일 정산. 탐색·등용·도시 계략은 판정 설계 후 | xUnit + Sandbox에서 모병(장수 지정·잠김·7일 완료)→훈련→투입 흐름 검산 |
| **8. 내정 ④ + 군량** ✅ | 경제 ~5배 rescale + 인구 충원율 수입 배율 + 치안(회복·페널티) + 내정담당관(태수) + 부대 군량(병종별 적재·경과일 소모·고갈) + 보급부대(5배 적재·속도1·자동 보충) | ✅ WorldEngine·Orchestrator 테스트 |

| **10a. 캠페인 통합(선결)** ✅ | 결정 확정: 진행=7일 고정(이동+전투 자동 연속, 판단은 주 단위), 일반 부대=단일 병종(보급만 혼합), 병종은 모집 시 지정. GameState에 Garrisons(병종별 대기 병력)·Armies(야전 부대), CampaignEngine.AdvanceWeek(야전·내정 한 시계), 모집 병종 지정+말·코끼리 자원 게이트, 입성→대기 병력 편입, 유령 태수 수정 | ✅ CampaignEngineTests |
| 10b. 전투-내정 연결 | ✅출전(DeployService). ✅보급부대 편성(DeploySupply: 혼합·2만·최하 스탯·균일 피해·병력보충). ✅캠페인 공성(CampaignSiege: City.Wall·성벽 타격·수비 손실·반격). **남음은 아래 10c~10e로 분리** | ✅DeployServiceTests·SupplyUnitTests·CampaignSiegeTests |

- 원칙: 단계마다 **설계 ❓ 확정 → Core+테스트 → 하베스트/Sandbox 검증 → 문서 갱신 → 커밋**.
- 끼어드는 아이디어는 우선 해당 design 문서에 ❓로 기록만 하고, 구현은 이 표의 순서를 따른다.
