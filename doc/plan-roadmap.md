## ✅ 완료 (구현 + 테스트 잠금, 335개)

**전투 축 (Core + 하베스트 16케이스)**
- 이동: 탐지·추격·사거리 정지(그 날 완료 후)·국소/측면 우회·지형 패널티·결정론
- 전투: 피해 공식·병종 공/방·지형 보정(이동 후 위치)·연구 곡선·적성 배수
- 특기: 패시브 버킷(조건부)·액티브(게이지 5일, 선봉 우선)
- 계략 11종: 즉발·지속(DoT)·디버프·혼란·교란(강제 후퇴)·수공·광역·시전 사거리·정화
- 공성: 성벽→붕괴 2단계·반격 사거리 1·성 접적 정지(선착 부대 단독 공성)
- 성 출입: 입성=이동 마지막 스텝(수비 합류·복귀 초기화)·출격 게이트 스텝·복귀 중단·함락 점거(근접 입성·비근접 멈춤)
- 장수: 병종별 통솔 6등급, 선봉·부관 부대 조립, **명단 152명**(중국 112·한국 30·일본 10, 출생·출신지·소개), 내정 스킬 13종 데이터
- 도구: `run-combattest.bat`(전투 16케이스), `roster.bat`(장수 명감)

**내정 ①②③-1차 (Core + Sandbox 검산)**
- 도시 상태: 금(도시별)·치안·인구·광석/말/코끼리·시설 수(논밭마을·공방)·산출 플래그·세율·지역 코드
- 일 단위 세계 시계(1월=30일), 월말 정산: 수입(성 규모 기본치+시설 가산)×세율 배율, 자원 산출, 인구 성장(치안 비례·등급별 최대치), 세율→치안 변동
- 명령 계층(1차): 모병·징병·훈련·건설·세율 — 수행 장수+기간+잠김, 효율=주관+보좌×50%+고향, 완료일 정산. 도시 대기 병력 풀(훈련도 가중평균)

## 🔧 설계 확정 — 구현 대기 (수치 ❓는 각 문서 참조)

- **내정 ③ 명령**: 모집(모병 1%/징병 3%·자원 게이트·인구 차감), 훈련 틱(7일 +10), 시장 구매(군량·광석·말·코끼리, 교역 할인), 시설 건설(슬롯 소3/중6/대9·공방 1), 세율 설정, 탐색·등용(판정 ❓), 도시 계략 5종(수치 ❓)
- **내정 ④ 치안**: 징병 하락 폭 ❓·자연 회복 ❓·저치안 페널티
- **부대 상태(unit-state)**: ①군량(휴대·소모·고갈 이탈·재보급) ②사기(증감·공방 배수·패주) ③훈련도 효과(A/B안 ❓)
- **전투-내정 연결**: 출전(도시에서 부대 편성·군량 휴대), 약탈(시설 N%❓·휴대 한도·입성 예치), 함락 시 도시 자원 이전

## 단계 계획 (앞으로 — 위에서 아래로)

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **7. 내정 ③ 명령** ✅ 1차 | 명령 계층(CityCommand): 모든 명령 = **수행 장수 + 기간**, 장수는 기간 동안 **잠김**, 효율 = 능력별 산출량(모병·징병·건설·세율=정치, 훈련=무력). 모병 7일/징병 7일/훈련 7일/건설 30일(정치>70)/세율 7일. 진행 중 명령을 세계 시계에 얹어 완료일 정산. 탐색·등용·도시 계략은 판정 설계 후 | xUnit + Sandbox에서 모병(장수 지정·잠김·7일 완료)→훈련→투입 흐름 검산 |
| 8. 내정 ④ + 군량 | 치안 마무리(징병 하락·회복) + 부대 군량(휴대·소모·고갈) — 내정과 부대의 첫 연결 | 장기 포위·원정 고갈 케이스 |
| 9. 사기·훈련 효과 | 사기(증감·배수·패주) + 훈련도 전투 효과 | 소모전 사기 붕괴·고무 케이스 |
| 10. 전투-내정 연결 | 도시에서 출전(편성+군량), 약탈·노획·예치, 함락 자원 이전, 도시 계략 배선 | 하베스트에 도시 포함 시나리오 |
| 11. 연구 | 병종/성벽 연구 명령(공방 게이트) | 연구 진행·중단 검산 |
| 12. AI + 밸런스 | 세력 AI 최소(모집·출전·공성 판단) → Sandbox 1000턴 | 1000턴 무예외·수렴 확인 |
| 13. 게임 씬(Godot) | 도시 클릭 명령 팔레트 + design-ui 4건 + 효과(영혼·번개 등) | run.bat에서 도시 운영→전투 한 사이클 |
| 14. 맵·시나리오 | 실지역 맵(regions 특산)·세력 배치·152명 배속 | 시나리오 시작→플레이 가능 |

- 원칙: 단계마다 **설계 ❓ 확정 → Core+테스트 → 하베스트/Sandbox 검증 → 문서 갱신 → 커밋**.
- 끼어드는 아이디어는 우선 해당 design 문서에 ❓로 기록만 하고, 구현은 이 표의 순서를 따른다.
