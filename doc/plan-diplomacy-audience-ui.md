# 외교 교섭 대화 UI 개선안 (구상 단계)

> 동맹·동맹 파기 명령의 현재 판정·비용·기간은 바꾸지 않는다. 이 문서는 연출과 조작 흐름만 제안하며 구현 완료를 뜻하지 않는다.

## 제안 화면

기존 하단 대화 카드의 틀을 유지하되, 외교 결과에는 `교섭 장면` 변형을 사용한다. 화면 너비의 약 75%를 차지하는 하단 패널에 왼쪽 사절, 오른쪽 상대 군주의 초상화를 놓고, 참모가 있으면 군주 뒤에 작은 원형 초상으로 배치한다. 현재 발화자의 초상만 밝게 하고 대사 영역에는 `이름 · 직책`과 1~2줄 대사를 표시한다. 각 대사마다 `다음`으로 넘기고 마지막은 `확인` 하나만 둔다. 결과에 새 선택지는 넣지 않는다.

| 장면 | 내용 | 연출 |
| --- | --- | --- |
| 사절 도착 | 상대 군주가 있는 성과 사절을 표시 | 지도에서 해당 성을 짧게 강조한 뒤 하단 패널 열기 |
| 교섭 | 사절 → 군주 → 참모(있을 때) → 군주 순으로 말하기 | 말하는 초상만 0.15초 안에 약간 앞으로 이동·밝아짐. 다른 초상은 어둡게 유지 |
| 결말 | 실제 도착 시 계산된 동맹 성공·실패 또는 동맹 파기 완료를 알림 | 결과 문장에만 가벼운 금색/회색 강조. `확인`으로 닫기 |

동맹의 기존 군주 단독 성공·실패 각 3종, 군주·참모 참여 성공·실패 각 3종 대사를 그대로 사용한다. 참모는 해당 성의 군사를 우선하고, 없으면 주둔 장수 중 지력이 가장 높은 1명을 택하며, 대화 가능한 사람이 군주뿐이면 2인 화면으로 축소한다. 동맹 파기는 즉시 효력이 발생하는 현행 규칙을 유지하고, 사절과 상대 군주가 서로 결별을 알리는 짧은 2~3페이지 대사를 별도로 준비한다. 동맹 파기를 외교관 이동 명령으로 바꾸지 않는다.

## 움직이는 이미지 범위

새 3D 에셋 없이 현재 장수 초상화에 UI Tween만 적용하는 1차안을 추천한다. 패널 등장 시 두 초상이 서로 반대쪽에서 12~16px 이동하며 0.2초에 자리 잡고, 발화 전환 때 현재 화자만 4~6px 전진·밝기 변화, 참모가 처음 말할 때만 작은 초상이 페이드 인한다. 초상화 자체를 흔들거나 끊임없이 움직이지 않는다. `다음` 연타 중 애니메이션은 중첩하지 않고 즉시 최종 위치로 정리한다.

## 구현 전 확인·QA 기준

1. 기존 `GeneralStoryEvent`와 보고 다시 보기에서 동일한 대사 순서·화자 초상화를 재생하되, 다시 보기에는 외교 효과를 재적용하지 않는다.
2. 동맹 실패·성공·동맹 파기 결과가 7일 진행 내 다른 사건과 겹쳐도 누락되지 않도록 결과 우선순위 또는 보고 다시 보기를 확인한다.
3. 상대 군주/참모 부재, 저장 후 재개, 창 크기·배율 변경, Esc·우클릭 닫기, 빠른 `다음` 입력을 검증한다.
4. Godot headless에서는 화자·대사·결과·버튼·초상화 배치를 확인하고, 실제 초상화 움직임·가독성은 `run-maptest.bat`에서 사람이 검수한다.
