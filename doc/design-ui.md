# 설계 노트 — 게임 UI/상호작용 (2026-08-11 작성 · 2026-08-21 현황 갱신)

> 본 게임 씬의 클릭·명령·정보 표시 상호작용 명세. 전투/계략/이동 규칙은
> [design-combat.md](./design-combat.md)·[design-stratagem.md](./design-stratagem.md)·[design-movement.md](./design-movement.md),
> 전투 정산 진입점은 Core `AdvanceOrchestrator`(구현됨).
> **현황(2026-08-21)**: §1 부분 구현(팔레트 모양+정보만) · §2 구현 · §3 미구현 ·
> §4 내정 씬 구현(캠페인 씬은 진행 애니메이션으로 대체) · §5 대부분 구현(보좌 슬롯 남음).

> **v2 전환 기준(2026-09-01):** 앞으로의 UI 작업은 [v2 전투 중심 전환 작업 로드맵](./plan-v2-implementation-roadmap.md)을 우선한다.
> 기존 도시 내정 팔레트는 구현 이력으로 보존하되, 신규 UI는 전투·보급·성장·탐색·생산 중심으로 축소한다.

## v2 UI 우선순위

1. 성 명령 팔레트 축소: 출전, 보급부대, 생산, 재편성, 보충, 수리, 연구, 계략, 탐색, 담당자 중심.
2. 담당자 4슬롯 화면: 치안/내정/병력/훈련 담당자를 지정하고 월 예상 효과를 표시.
3. 보급부대 편성 UI 분리: 전투부대와 보급부대를 별도 탭 또는 별도 버튼으로 구분.
4. 생산 작전 UI: 논·밭·마을 대상 선택, 장수/병종 선택, 채집 상태 표시.
5. 장수 성장 UI: 레벨, 경험치, 병종 숙련도, 액티브 스킬 레벨과 전투 후 성장 로그.
6. 액티브 스킬 효과 UI: 발동 배너, 장수 컷인, 대상 이펙트, 피해/회복 숫자 팝업.
7. 유닛별 사진/카드: 출전·보급부대·생산 병종 선택 화면에 병종별 이미지 표시.
8. 장수 초상 UI: 장수 상세, 출전 편성, 훈련/레벨업 결과에 초상 표시.

## 1. 부대 클릭 → 명령 팔레트  — 🔶 대부분 구현(2026-08-21, 캠페인 씬)

> 구현: 유닛 좌클릭 팔레트 — **정보**(병종·병력·선봉/부관·훈련·모드·목표·군량),
> **이동 재지정**(행군/전진/공격 선택 → **지점을 순서대로 클릭 = 경유지**, 각 지점 위 ✕로 삭제
> (중간 삭제 시 남은 지점으로 경로 자동 재계산) → '확인' 확정, 적 성=공격 전환·자기 성=복귀,
> 경로 프리뷰), **정지**(목표 해제·그 자리 대기). 아군·평시에만 명령
> 노출(적/재생 중엔 정보만). 경유지는 출전 목표 지정에도 동일 적용. 남음: **계략 예약**·로그 보기.
> 성 팔레트에 **시장** 버튼(2026-08-24): 이번 달 시세로 광석·말·코끼리·군량 즉시 매입(교역 태수 할인, 군량=비상 보급).
> 단일 명령인 **계략**은 중간 플라이아웃을 생략하고 버튼에서 계략 모달을 바로 연다(2026-08-30).
> **군사 임명**(내정 팔레트)·**등용** 버튼(2026-08-24): 등용 = 대상(내 포로·정찰된 적 성 장수·출전중 적 장수) → 수행 장수 → 군사 지력% 예측·확인.

부대를 클릭하면 명령 팔레트가 열린다. 구성:

- **정보 표시** — 등급, 병력 현황(활성/부상), 병종 등 부대 요약.
- **이동 선택**
  - 정의된 **3가지 이동 모드**(공격 / 전진 / 행군 — [design-movement.md](./design-movement.md))를 고르는 창이 먼저 뜬다.
  - 모드 선택 후 **이동할 타일을 지정**한다(✅ 2026-08-23 구현):
    - **지점을 순서대로 클릭**해 경유지를 이어 붙인다 — 각 구간은 A*(Core `HexPathfinder`)로 자동 연결.
    - 각 경유지 위에 **✕(취소) 버튼**이 떠, 누르면 그 지점만 삭제하고 **남은 지점으로 경로를 다시 잇는다**
      (중간 지점 삭제 시 자동 재계산).
  - 버튼: **✓확인** = 그 경로로 확정(마지막 지점=최종 목표, 나머지=경유지). 우클릭 = 취소.
  - 배선: `FieldUnit.Waypoints`·`DeployRequest.Waypoints` → `MovementSimulator` 구간 이동([design-movement.md](./design-movement.md)).
- **계략 선택**
  - 그 부대가 **사용 가능한 계략** 목록이 뜬다(숙달 레벨·모략력·지형 조건 만족분 — [design-stratagem.md](./design-stratagem.md)).
  - 계략을 고르고 **목표 부대를 지정**한다. **종료** = 예약 확정(2일 뒤 발동).
- **로그 보기**
  - 그 부대가 **교전한 로그**를 본다. 단 **부대가 성에 있으면(주둔) 로그가 안 나온다**.

## 2. 맵/성 클릭 → 정보 표시  — ✅ 구현(2026-08-21, 캠페인 씬)

> 구현: 지형 클릭 = 클릭 지점 위 2단 카드(상단 **3D 에셋 회전 미리보기**+한글 이름,
> 하단 이동 비용·병종별 공방 보정). 성 클릭 = 정보 카드(주둔·병력·자금 등) +
> **상세 모달**(2026-08-23): 타이틀에 **태수** 표기 · 도시 수치 · **대기 병력**(옆에 총 병력수,
> 병종 카드형=엠블럼+병종+훈련도, 카드 많으면 가로 스크롤) · **주둔 장수 표**(이름/무/지/정/상태,
> 태수는 ◆·금색·상태="태수", 행 클릭 = **장수 상세 카드**: 상단 초상 영역
> (assets/portraits/general_NNN.png 생기면 자동 표시) / 타이틀 = 이름 / 하단 능력치·병종 적성 6열·
> 특기 2열 그리드 정렬, 충성은 "??"). 아래 3개 섹션은 **탭**으로 전환(주둔 장수 N / 진행 명령 N /
> 출전 예약 N, 탭별 개수 배지·활성 탭 금색·재열림 시 활성 탭 유지): **진행 중 명령**(시작 전만 취소,
> 환불 없음, 재생 중 취소 불가) · **출전 예약**(취소). 긴 명령/예약 줄은 자동 줄바꿈(가로 스크롤 제거).
> 정보 카드는 대기=**총 병력만**, 주둔 대신 **태수 이름만** 표기. 내정 팔레트에 **태수 임명** 추가
> (주둔 장수 표에서 선택 → 즉시 임명, 무력→반격·정치→수입 예고).

지금은 맵을 클릭하면 부대가 이동하지만, **부대 미선택 상태에서**는 클릭 대상의 정보를 표시한다.

- **맵(지형) 클릭** — 지형 정보 패널을 2단으로:
  - **상단**: 간단한 지형 그림 + 이름.
  - **하단**: 그 지형의 **추가 표시 효과**(이동 보정·공방 보정 등 — design-combat/movement의 지형 규칙) 기술.
- **성 클릭** — 성 정보 패널:
  - 성 이름 + **주둔 장수 설명**, **병력 현황**, **자금 현황**을 간단히.
  - **상세 버튼** → 나중에 정의할 **성 인터페이스 모달** 실행(내정 등, 별도 설계).

## 3. 부대 유닛 에셋 표기 (병력 규모별)  — ✅ 구현(2026-08-21, 캠페인 씬)

> 구현: 병력→편대원 수 매핑 9천↑=9 / 7천↑=7 / 5천↑=5 / 3천↑=3 / 그 밑=1
> (`UnitController3D.SetFormationSize`). 진행 재생 중에도 교전 정산 시점에 갱신,
> 전멸·입성 부대는 즉시 제거(소멸 연출은 design-effect 후속).

부대 토큰의 유닛 에셋 수를 **병력에 따라 1·3·5·7·9**로 표시한다(이미 `TroopFormation.Build`가 이 규모를 지원).

| 표기 유닛 수 | 병력 |
|---|---|
| 1 | 1,000 |
| 3 | 3,000 |
| 5 | 5,000 |
| 7 | 7,000 |
| 9 | 9,000 이상 |

(구간 경계·1,000 미만 처리는 구현 시 확정.)

## 4. 진행 버튼 → 컨펌 후 진행  — ✅ 구현(내정 씬 + 캠페인 씬 2026-08-21)

"진행" 버튼을 누르면 **바로 진행하지 않고 확인(컨펌) 창**을 띄운 뒤, 확인해야 진행한다.

> 캠페인 씬: 진행 버튼 → **게임 스타일 커스텀 컨펌창**(금테·잉크·한글 확인/취소,
> 날짜·출전 예약 수·목표 미지정 경고 표시) → 확인 시 7일 재생 애니메이션 시작.
> 명령 컨펌도 같은 커스텀 창 사용(시스템 ConfirmationDialog의 영문 OK/Cancel 대체).
> 내정 씬은 시스템 다이얼로그 유지하되 버튼 한글화.

## 5. 도시 명령 배정 화면 — 주관·보좌 + 고향 배지 (2026-08-15 요구사항)  — 🔶 대부분 구현(보좌 슬롯 남음)

> 구현(12b): 고향 배지 🏠·유효 능력·예상 산출·잠김/전제 미충족 비활성.
> 남음: **보좌(선택) 슬롯**.

도시 명령(모병·징병·훈련·건설·세율 등)을 걸 때의 배정 화면. 규칙 원본은
[design-administration.md](./design-administration.md) "명령 실행 공통 규칙"·"내정 심화".

- **주관·보좌 슬롯**: 주관(필수)·보좌(선택) 장수를 각각 지정. 선택 즉시 **유효 능력**과
  **예상 산출**(예: "모집 1,395명 / 7일")을 계산해 보여준다.
- **고향 배지(필수)**: 주관·보좌가 그 도시의 출신 지역이면 **"🏠 [지역] 출신 +N%"** 배지를
  반드시 표시한다(design-administration B의 발동 전제 — 배지 없이는 B를 켜지 않는다).
  장수 토큰/초상에도 고향 마커를 둔다.
- **잠김 표시**: 다른 명령에 배정돼 잠긴 장수는 목록에서 비활성 + 완료 예정일 표기.
- **전제 미충족 표시**: 건설(정치 > 70) 등 전제를 못 넘는 장수는 사유와 함께 비활성.

## 구현 메모

- 명령 팔레트·정보 패널·컨펌은 **표현 계층**(Godot UI)이다. 판정·경로·전투는 전부 Core가 소유한다.
- 이동 명령 확정 = 부대에 목표·모드·(선택) 경로를 심는 것. 진행 시 `AdvanceOrchestrator.Run`이 소비.
- 계략 예약 확정 = `UnitCombatState.ReserveStratagem`. 사용 가능 목록은 숙달/모략력/지형으로 필터.
- 로그는 부대별 교전 기록을 누적 보관하고, 성 주둔 시 숨긴다.
- 우선순위·착수 시점은 사용자와 별도 협의(현재는 `--combattest` 하베스트로 전투를 검증 중).
