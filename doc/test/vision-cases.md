# Phase 10C — 정찰 표시와 전장의 안개 검증

실행: 루트 `run-maptest.bat`. 스크린샷 자동 생성 및 게임 창 자동 실행은 하지 않는다.

| 확인 | 작업 | 기대 결과 |
|---|---|---|
| ⬜ | 새 게임 시작 | 장안(중형) 중심 5칸은 정상 밝기, 시야 밖은 어둡게 표시 |
| ⬜ | 시야 밖 성/시설 클릭 | 성 이름과 소속은 남고, 성 상세 수치와 시설 생산 정보는 숨김 |
| ⬜ | 전체 도시 목록에서 시야 밖 적 성 상세 열기 | 맵 클릭과 동일하게 수치가 가려짐 |
| ⬜ | 성도 정찰 성공 후 진행 종료 | 성도 위 `정찰완료 · 남은 일수`가 부유하며 중형성 5칸 주변 공개 |
| ⬜ | 정찰 표시가 있는 상태로 카메라 확대·축소·이동 | 성과 정찰 표시가 함께 이동하고 우측 패널은 화면 밖으로 잘리지 않음 |
| ⬜ | 정찰 후 다시 성공 | 잔여 기간이 새 성공일 기준 60일로 갱신되고 표시가 중복 생성되지 않음 |
| ⬜ | 정찰 성공일에서 60일 이상 진행 | 표시와 정찰 시야가 사라짐. 아군 부대 시야와 겹치는 타일은 유지 |
| ⬜ | 정찰한 성을 점령 | 정찰 표시는 제거되고 아군 성의 상시 시야로 전환 |
| ⬜ | 보병·기병을 각각 출전해 진행 | 보병 3칸, 기병 4칸이 이동 위치를 따라 공개되고 지나간 지역은 다시 어두워짐 |
| ⬜ | 기병을 보급부대로 편성 | 정보에 시야 2칸 표시, 주변도 2칸만 공개 |
| ⬜ | 시야 경계에서 적 부대 접근·이탈 | 적 모델이 나타났다 사라지며 시야 밖에서는 클릭/상세 열람 불가 |
| ⬜ | 생산 파견 이동→채집 및 전멸 | 파견 병종의 시야가 유지되고 전멸 시 해당 시야가 제거됨 |
| ⬜ | 시야 밖의 적끼리 전투 | 피해 숫자·해골·반격 화살로 위치가 노출되지 않음 |
| ⬜ | 저장·불러오기 | 정찰 남은 기간, 시야, 부대 표시가 저장된 현재 상태에서 다시 계산됨 |

자동 검증: `BattlefieldVisionTests` 17개, 기존 정찰 성공/만료 테스트, Core·Game 빌드.
현재 테스트 지도는 모든 성이 중형이다. 소형 4칸/대형 6칸 및 경계 합산은 자동 테스트로 검증한다.
