# QA 수동 테스트 체크리스트 (2026-08-24 배치)

이번 세션에서 추가·변경한 기능을 손으로 확인하는 목록. **`run-maptest.bat`** 으로 캠페인 맵을 띄워서 진행.
확인란(☐→☑)에 표시하고, 어긋나면 "기대 결과"와 실제를 함께 적어 알려줄 것.

> 시작 시나리오: 장안(1,2) 위(플레이어) · 성도/한중 촉(AI). 좌상단 ☰ = 시스템 팔레트.

## A. 성 상세 · 명령

| # | 기능 | 어떻게 | 기대 결과 | 확인 |
|---|---|---|---|---|
| A1 | 상세 모달 열기 | 아군 성 클릭 → 우측 카드의 "▶ 상세" | 도시 수치 + 대기 병력 카드 + 탭 3개 | ☐ |
| A2 | 탭 모양 | 상세에서 주둔 장수/진행 명령/출전 예약 탭 클릭 | 활성 탭이 아래 패널과 이어진 **폴더 탭** 모양, 개수 배지, 재열림 시 같은 탭 | ☐ |
| A3 | 대기 병력 카드 | 상세 상단 | 병종 엠블럼+병종+훈련도 카드, 옆에 총 병력수, 많으면 가로 스크롤 | ☐ |
| A4 | 명령 취소(시작 전) | 명령 하나 발행 → 상세 진행 명령 탭 → 취소 | 취소 버튼 보이고 눌리면 사라짐 | ☐ |
| A5 | 명령 취소(진행 후) | 명령 발행 → **진행 1회** → 상세 열기 | 그 명령은 "(진행중)"이고 **취소 버튼 없음** | ☐ |
| A6 | 재생 중 취소 차단 | 진행(재생) 중 성 상세 열기 | 취소 버튼이 아예 없음 | ☐ |
| A7 | 명령 모달 스크롤 | 모병 등 명령 → 수행 장수 표 | **세로 스크롤 하나만**(2중 스크롤 없음) | ☐ |

## B. 장수 · 태수 · 군사 · 등용 · 충성

| # | 기능 | 어떻게 | 기대 결과 | 확인 |
|---|---|---|---|---|
| B1 | 주둔 장수 표 | 상세 → 주둔 장수 탭 | 이름/무/지/정/상태, **태수는 ◆·금색** | ☐ |
| B2 | 장수 상세 카드 | 주둔 장수 행 클릭 | 상단 초상 영역 + 이름 타이틀 + 능력치·적성 6열·특기 2열 | ☐ |
| B3 | 태수 임명 | 내정 팔레트 → 태수 임명 → 장수 선택 | 즉시 임명, 상세 타이틀·정보 카드에 태수 표기 | ☐ |
| B4 | 군사 임명 | 내정 팔레트 → 군사 임명 → 장수 선택(지력★) | 즉시 임명 | ☐ |
| B5 | 포상 | 장수 상세 카드 → "포상 (100금)" | 금 −100, (충성은 숨김이라 값은 안 보임), 잔금 부족 시 실패 | ☐ |
| B6 | 등용 대상 목록 | 성 팔레트 → 등용 | 내 포로 · 정찰된 적 성 장수 · 출전중 적 장수가 목록에 뜸 | ☐ |
| B7 | 등용 예측 | 등용 → 대상 → 수행 장수 선택 | 군사 있으면 "성공 유력/반반/어려움 · 신뢰도 N%", 없으면 "예측 불가" | ☐ |
| B8 | 등용 진행 | 등용 발행 후 진행 | 성공 시 대상이 우리 세력으로(출전중이면 부대째), 실패 시 로그 | ☐ |
| B9 | 공성 반격(태수) | 태수(무력 높음) 있는 성을 적이 공격 | 태수 무력이 높을수록 성 반격이 셈(로그/병력 감소) | ☐ |
