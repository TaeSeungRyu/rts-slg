# 설계 노트 — 물/강 체계 (사용자 요구, 2026-08-04)

## 두 종류의 강

| 구분 | 소하천 (구현됨) | 대하(큰 강) (예정) |
|---|---|---|
| 형태 | 지형 타일 위를 흐르는 좁은 물길 | **타일 전체가 물** (장강·황하급) |
| 데이터 | `R`(river) / `B`(bridge) | 별도 지형 타입 (예: `W` 얕음 / `V` 깊음 — 미정) |
| 렌더 | grass 기반 채널 모델, 연결 방향 자동 | 물 타일 + **깊이 표현** 필요 |
| 통행(예정) | 다리로만 도하 | 도보 불가, 수군/배 필요 (삼11 방식) |

## 대하의 깊이 표현 (요구사항)

깊이가 시각적으로 구분되어야 한다. 후보 접근:

1. **깊이 단계별 지형 타입 + 색 변조** — 얕은 물/깊은 물 2~3단계, 깊을수록 어두운 색(머티리얼 틴트). 데이터 주도, 구현 간단 (추천 시작점)
2. **지오메트리 깊이** — 깊은 타일일수록 수면 아래 바닥을 낮추고 반투명 수면 렌더. 더 사실적, 셰이더 작업 필요
3. 1→2 순서로 점진 개선 가능

## 게임플레이 함의 (이후 단계)

- 대하는 부대 통행 불가 → A* 통행 판정에 지형 개입 (이미 seam 있음: `HexPathfinder` 통행 조건 주입)
- 수군/수상 유닛, 도하 지점(나루터/다리)이 전략 요소가 됨
- 깊이는 수군 이동/전투 보정에 쓸 수 있음 (밸런스 설계 영역 — 임의로 정하지 않음)
