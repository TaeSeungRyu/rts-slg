# 도시 계략 대상 선택 UI 계획

기존 적 성 선택 표를 지도상의 대상 지정 흐름으로 교체했다. 계략 카드와 수행 장수를 고르면 모달이 닫히고, 현재 시야·정찰·선전 포고로 위치가 알려진 적 성만 금색 고리로 표시한다. 지도 클릭 후 기존 장수 컨펌과 명령 발행 검증을 사용한다.

| 단계 | 상태 | 검증 |
| --- | --- | --- |
| 1. 대상 표 제거·지도 선택 상태 | ✅ | 게임 빌드, 다중 타일 성 클릭 경로 |
| 2. 시야·동맹 대상 제한 | ✅ | 숨겨진 성 제외, 동맹에는 정찰만 허용 |
| 3. 확인·취소·재검증 | ✅ | 기존 발행 검증 재사용, Esc·우클릭 취소 |
| 4. 실기기 시각 QA | ⬜ | `run-maptest.bat`에서 표식·마우스 조작 확인 필요 |

1. 성의 `계략` 명령에서 계략 종류와 수행 장수를 고르면 모달이 닫힌다. 확인 가능한 적 성만 금색 테두리로 표시한다. 위치가 알려지지 않은 성은 노출하지 않는다.
2. 지도에서 대상 성을 클릭하면 기존 장수 확인창에 `계략 종류 → 대상 성 → 수행 장수 → 소요일수`를 요약한다. 성공 확률이나 정찰 전 정보는 표시하지 않는다. 무효 대상을 클릭하면 상단에 이유를 표시한다.
3. 확인을 승인할 때 소유권·동맹·장수 상태·거리·예약 중복을 다시 검사한다. 실패하면 명령은 생성하지 않고 대상 선택 화면에 이유를 표시한다. 취소·Esc·우클릭은 명령을 만들지 않고 원래 성 팔레트로 돌아간다.
4. 성이 다중 타일이어도 성의 어느 점을 클릭해도 한 대상만 선택한다. 일반 지도 클릭·부대 명령·카메라 이동과 충돌하지 않도록 전용 대상 선택 상태를 둔다. 지도 이동과 줌은 허용하고, 이 상태에서는 다른 명령 팔레트를 열지 않는다.
5. QA: 단일/복수 적 성, 가려진 성, 정찰된 성, 동맹 성, 점령 직후 소유권 변경, 모달 취소·뒤로가기, 7일 진행 중 클릭, 해상 건너편 성을 확인한다. 기존 계략 판정·비용·도착 시점은 변경하지 않는다.
